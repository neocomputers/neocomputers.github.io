GRILLE SHUTTER SYSTEM, Diagnostic DTC:U129387

DTC Code DTC Name
U129387 Lost Communication between Hybrid Powertrain Control Module and Active Grille Air Shutter Missing Message

DESCRIPTION

This DTC is stored if a communication malfunction occurs between the hybrid vehicle control ECU and swing grille actuator assembly.

DTC No. Detection Item DTC Detection Condition Trouble Area
U129387 Lost Communication between Hybrid Powertrain Control Module and Active Grille Air Shutter Missing Message CAN communication malfunction between the hybrid vehicle control ECU and swing grille actuator assembly. (1 trip detection logic*)

  • CAN communication system

  • Swing grille actuator assembly

  • Radiator shutter sub-assembly

  • *: This malfunction is only detected when the power switch is on (IG).
