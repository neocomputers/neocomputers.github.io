POWER STEERING SYSTEM, Diagnostic DTC:C1511, C1512, C1513, C1514, C1517

DTC Code DTC Name
C1511 Torque Sensor1
C1512 Torque Sensor2
C1513 Torque Sensor Deviation Excessive
C1514 Torque Sensor Power Supply Voltage
C1517 Torque Hold

DESCRIPTION

The torque sensor converts the rotational torque received from the steering wheel into electric signals and sends them to the power steering ECU assembly.
