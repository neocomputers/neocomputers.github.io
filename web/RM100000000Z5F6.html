FRONT WIPER MOTOR INSTALLATION

CAUTION / NOTICE / HINT

Note

Make sure to hold the front wiper arm while lifting it as lifting the front wiper arm by the front wiper blade may damage or deform the front wiper blade.

PROCEDURE


  1. INSTALL WINDSHIELD WIPER MOTOR ASSEMBLY (for LHD)


    1. Install in this Direction (1)
      Install in this Direction (2)

      Push the windshield wiper motor assembly in the direction indicated by the arrow (1), then move the windshield wiper motor assembly in the direction indicated by the arrow (2) shown in the illustration to temporarily install it to the windshield wiper link assembly.

    2. Install the windshield wiper motor assembly with the 3 bolts.

      Torque:
      5.39 N*m  { 55 kgf*cm, 48 in.*lbf }

    3. Apply MP grease to the pivot of the windshield wiper motor assembly.

    4. *a Pivot of Windshield Wiper Motor Assembly

      Connect the No. 1 windshield wiper link rod to the pivot of the windshield wiper motor assembly.

  2. INSTALL WINDSHIELD WIPER MOTOR ASSEMBLY (for RHD)


    1. Install the windshield wiper motor assembly to the windshield wiper link assembly with the 3 bolts.

      Torque:
      5.39 N*m  { 55 kgf*cm, 48 in.*lbf }

  3. INSTALL FRONT WIPER CRANK SUB-ASSEMBLY (for RHD)


    1. Connect the windshield wiper motor assembly connector.

    2. Turn the power switch on (IG).

    3. Operate the windshield wiper motor assembly and stop it at the automatic stop position.

    4. Turn the power switch off.

    5. Disconnect the windshield wiper motor assembly connector.

    6. Temporarily install the front wiper crank sub-assembly to the windshield wiper motor assembly with the nut.

    7. Set the No. 1 windshield wiper link rod on the pivot of the front wiper crank sub-assembly.

    8. Align the pivot of the front wiper crank sub-assembly with the shaft of the windshield wiper motor assembly and No. 1 windshield wiper link rod as shown in the illustration.

      *a No. 1 Windshield Wiper Link Rod *b Shaft of Windshield Wiper Motor Assembly
      *c Pivot of Front Wiper Crank Sub-assembly - -
    9. *a Protective Tape

      Using a screwdriver, hold the front wiper crank sub-assembly as shown in the illustration.

      Tech Tips

      Tape the screwdriver tip before use.

    10. Tighten the nut.

      Torque:
      17.2 N*m  { 175 kgf*cm, 13 ft.*lbf }

    11. Apply MP grease to the pivot of the front wiper crank sub-assembly.

    12. *a Pivot of Front Wiper Crank Sub-assembly

      Connect the No. 1 windshield wiper link rod to the pivot of the front wiper crank sub-assembly.

  4. INSTALL WINDSHIELD WIPER MOTOR AND LINK ASSEMBLY (for LHD)


    1. Connect the connector.

    2. *a Motor Grommet

      Engage the motor grommet as shown in the illustration.

      Note

      Be careful not to damage the windshield glass when installing the windshield wiper motor and link assembly.

    3. Install the windshield wiper motor and link assembly with the 2 bolts.

      Torque:
      5.5 N*m  { 56 kgf*cm, 49 in.*lbf }

  5. INSTALL WINDSHIELD WIPER MOTOR AND LINK ASSEMBLY (for RHD)


    1. Connect the connector.

    2. *a Motor Grommet

      Engage the motor grommet as shown in the illustration.

      Note

      Be careful not to damage the windshield glass when installing the windshield wiper motor and link assembly.

    3. Install the windshield wiper motor and link assembly with the 2 bolts.

      Torque:
      5.5 N*m  { 56 kgf*cm, 49 in.*lbf }

  6. INSTALL COWL TOP VENTILATOR LOUVER SUB-ASSEMBLY


    1. Engage the 4 guides as shown in the illustration.

      Install in this Direction - -

      Note

      When installing the cowl top ventilator louver sub-assembly, it may contact the brake master cylinder reservoir filler cap assembly and cause it to fall off. Check the installation condition of the brake master cylinder reservoir filler cap assembly after installing the cowl top ventilator louver sub-assembly.

    2. Engage the cowl top ventilator louver sub-assembly to the windshield glass as shown in the illustration.

    3. Install the 2 clips.

  7. INSTALL COWL WATER EXTRACT SHIELD LH


    1. Install in this Direction

      Temporarily install the cowl water extract shield LH as shown in the illustration.

      Tech Tips

      Make sure the claw is set at the engagement position.

    2. Engage the cowl water extract shield LH to the windshield glass.

    3. Engage the guide and 2 claws to install the cowl water extract shield LH.

  8. INSTALL COWL WATER EXTRACT SHIELD RH

    Tech Tips

    Use the same procedure as for the LH side.

  9. INSTALL FRONT WIPER ARM AND BLADE ASSEMBLY RH


    1. When reusing the front wiper arm and blade assembly RH:


      1. *a Serration

        Clean the wiper arm serrations to remove any burrs, dirt, etc.

        Note

        Do not grind down the wiper arm serrations.

    2. When reusing the windshield wiper motor and link assembly:


      1. Clean the wiper pivot serrations with a wire brush.

    3. Turn the power switch on (IG).

    4. Operate the windshield wiper motor assembly and stop the windshield wiper motor and link assembly at the automatic stop position.

    5. Turn the power switch off.

    6. *a Alignment Mark

      Install the front wiper arm and blade assembly RH with the nut to the position shown in the illustration.

      Torque:
      23 N*m  { 235 kgf*cm, 17 ft.*lbf }

      Tech Tips

      Hold the wiper arm by hand while tightening the nut.

      Reference Measurement
      Area Measurement
      A 7.5 mm (0.295 in.)

  10. INSTALL FRONT WIPER ARM AND BLADE ASSEMBLY LH


    1. When reusing the front wiper arm and blade assembly LH:


      1. *a Serration

        Clean the wiper arm serrations to remove any burrs, dirt, etc.

        Note

        Do not grind down the wiper arm serrations.

    2. When reusing the windshield wiper motor and link assembly:


      1. Clean the wiper pivot serrations with a wire brush.

    3. *a Alignment Mark

      Install the front wiper arm and blade assembly LH with the nut to the position shown in the illustration.

      Torque:
      23 N*m  { 235 kgf*cm, 17 ft.*lbf }

      Tech Tips

      Hold the wiper arm by hand while tightening the nut.

      Reference Measurement
      Area Measurement
      A 7.5 mm (0.295 in.)

    4. Turn the power switch on (IG).

    5. Operate the windshield wipers while spraying washer fluid onto the windshield glass. Make sure that the windshield wipers function properly and the wipers do not contact the vehicle body.

    6. Turn the power switch off.

    7. Lift each wiper arm twice after the wipers stop and check the wiper set position.

  11. INSTALL FRONT WIPER ARM HEAD CAP


    1. Engage the 3 claws to install the front wiper arm head cap.

      Tech Tips

      Use the same procedure for the RH side and LH side.
