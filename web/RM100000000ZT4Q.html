GRILLE SHUTTER SYSTEM, Diagnostic DTC:B1333

DTC Code DTC Name
B1333 Shutter Control State Maintenance Mode

DESCRIPTION

This DTC is stored when the grille shutter system is changed to maintenance mode.

DTC No. Detection Item DTC Detection Condition Trouble Area
B1330 Shutter Control Malfunction The grille shutter system is changed to maintenance mode. Swing grille actuator assembly

CAUTION / NOTICE / HINT

Note
