REAR TURN SIGNAL LIGHT ASSEMBLY REASSEMBLY

CAUTION / NOTICE / HINT

Tech Tips


  • Use the same procedure for the RH side and LH side.

  • The following procedure is for the LH side.

PROCEDURE


  1. INSTALL REAR TURN SIGNAL LIGHT LENS AND BODY

  2. INSTALL REAR FOG LIGHT GASKET (w/ Rear Fog Light)


    1. Install a new rear fog light gasket.

  3. INSTALL REAR FOG LIGHT LED (w/ Rear Fog Light)


    1. Install in this Direction

      Turn the rear fog light LED as shown in the illustration to temporarily install it.

    2. Using a T20 "TORX" socket wrench, install the rear fog light LED with the screw.

  4. INSTALL BACK-UP LIGHT SOCKET

  5. INSTALL BACK-UP LIGHT BULB


    1. Install the back-up light bulb to the back-up light socket.

    2. Install in this Direction

      Turn the back-up light socket with the back-up light bulb as shown in the illustration to install them as a unit.
