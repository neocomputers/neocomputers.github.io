HEADLIGHT ASSEMBLY INSTALLATION

CAUTION / NOTICE / HINT

Tech Tips


  • Use the same procedure for the RH side and LH side.

  • The following procedure is for the LH side.

PROCEDURE


  1. INSTALL HEADLIGHT ASSEMBLY


    1. Install in this Direction

      Engage the guide to temporarily install the headlight assembly as shown in the illustration.

    2. *a Bolt
      *b Screw

      Install the headlight assembly with the bolt and 3 screws.

      Torque:
      Bolt
      12.5 N*m  { 127 kgf*cm, 9 ft.*lbf }
    3. *a Connector Lock Lever
      Connect in this Direction

      Connect the connector and raise the connector lock lever to engage the claw and lock the connector as shown in the illustration.

    4. Remove the protective tape.

  2. INSTALL FENDER APRON MUDGUARD SEAL SUB-ASSEMBLY


    1. Install in this Direction

      Engage the clip as shown in the illustration.

    2. Install the fender apron mudguard seal sub-assembly with the clip.
