SEAT POSITION SENSOR INSTALLATION

PROCEDURE


  1. INSTALL SEAT POSITION AIRBAG SENSOR


    1. *a Pin
      *b Installation Hole

      Insert the pin into the installation hole and temporarily install the seat position airbag sensor to the seat rail bracket with the "TORX" bolt as shown in the illustration.

    2. *1 Seat Position Airbag Sensor
      *a Feeler Gauge
      *b 1.3 mm (0.0512 in.)
      *c Seat Track Bracket

      Using a T30 "TORX" socket wrench and a 1.3 mm (0.0512 in.) feeler gauge, install the seat position airbag sensor with the "TORX" bolt.

      Torque:
      8.0 N*m  { 82 kgf*cm, 71 in.*lbf }

      Note


      • If the seat position airbag sensor has been dropped, or there are any cracks, dents or other defects in the case or connector, replace the seat position airbag sensor with a new one.

      • When installing the seat position airbag sensor, make sure that the SRS wiring does not interfere with or is pinched between other parts.

    3. Make sure that the clearance between the seat position airbag sensor and seat track bracket is 1.3 mm (0.0512 in.).

    4. Check that there is no looseness in the installed parts of the seat position airbag sensor.

  2. INSTALL SEAT SLIDE POSITION SENSOR PROTECTOR


    1. *a Seat Rail Bracket
      *b Pin
      *c Installation Part
      Install in this Direction (1)
      Install in this Direction (2)

      Insert the seat slide position sensor protector to the seat rail bracket and engage the pin to the installation part of the seat slide position sensor protector.

    2. Connect the connector and engage the clamp.
