BACK DOOR GLASS ON-VEHICLE INSPECTION

PROCEDURE


  1. INSPECT GLASS BREAKAGE SENSOR (BACK WINDOW FIX GLASS)


    1. *1

      Back Window Fix Glass

      (View from inside the vehicle)
      *a Terminal B
      *b Terminal C

      Measure the resistance according to the value(s) in the table below.

      Standard Resistance
      Tester Connection Condition Specified Condition
      Terminal B - Terminal C Always Below 1 Ω

      If the result is not as specified, replace the glass breakage sensor (back window fix glass).

  2. INSPECT GLASS BREAKAGE SENSOR (BACK DOOR GLASS)


    1. *1

      Back Door Glass

      (View from inside the vehicle)
      *a Terminal D

      Measure the resistance according to the value(s) in the table below.

      Standard Resistance
      Tester Connection Condition Specified Condition
      Terminal D - Body ground Always Below 1 Ω

      If the result is not as specified, replace the glass breakage sensor (back door glass).
