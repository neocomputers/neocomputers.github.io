SPEED LIMITER SYSTEM SYSTEM DESCRIPTION


  1. SPEED LIMITER SYSTEM


    1. Using this system, the driver can set a limit speed so that the vehicle speed does not exceed the set speed while driving. The hybrid vehicle control ECU regulates the vehicle speed so as not to exceed the set speed even if the driver attempts to accelerate the vehicle by using the accelerator pedal. During kick-down operation (on sudden acceleration), however, the vehicle can be accelerated beyond the set speed.


      1. If the actual vehicle speed is higher than the set speed, the hybrid vehicle control ECU operates the throttle motor to close the throttle valve or the motor generator to decrease the motor drive force by the appropriate amount, decreasing the vehicle speed.

      2. The hybrid vehicle control ECU receives speed limiter system on/off signals from the speed limiter switch.

      3. The hybrid vehicle control ECU receives -SET, +RES and CANCEL signals from the cruise control main switch.

      4. When the hybrid vehicle control ECU receives an on signal from the speed limiter switch, the hybrid vehicle control ECU will illuminate the speed limiter indicator on the main display.

      5. When a limit speed is set, the hybrid vehicle control ECU displays the set speed on the main display.

        Control Operation Content
        Set Control Turn the speed limiter switch on and press the cruise control main switch to -SET while driving at 30 km/h or 20 mph or more The hybrid vehicle control ECU stores the vehicle speed when the cruise control main switch is released, and limits the vehicle speed to the set speed*1
        Coast Control Press the cruise control main switch to -SET and hold it in that position while the speed limiter system is operating The hybrid vehicle control ECU decreases the limit speed by 5 km/h or 5 mph*2
        Tap-down Control Press the cruise control main switch to -SET and then release it (after approximately 0.6 seconds) while the speed limiter system is operating The hybrid vehicle control ECU decreases the limit speed by 1 km/h or 1 mph each time the switch is tapped
        Acceleration Control Press the cruise control main switch to +RES and hold it in that position while the speed limiter system is operating The hybrid vehicle control ECU increases the limit speed by 5 km/h or 5 mph*2
        Tap-up Control Press the cruise control main switch to +RES and then release it (after approximately 0.6 seconds) while the speed limiter system is operating The hybrid vehicle control ECU increases the limit speed by 1 km/h or 1 mph each time the switch is tapped
        Override Control Fully depress the accelerator pedal while the speed limiter system is operating The hybrid vehicle control ECU determines that acceleration is needed and permits acceleration beyond the set speed*3
        Cancel Control

        While the speed limiter system is operating, any of the following operations occur:


        • Pulling the cruise control main switch to CANCEL

        • VSC is turned off

        The hybrid vehicle control ECU cancels speed limiter system operation

        (The stored vehicle limit speed in the hybrid vehicle control ECU is maintained)

        While the speed limiter system is operating, any of the following operations occur:


        • Turning the speed limiter switch off

        • Turning the cruise control main switch on

        • Malfunction in the hybrid control system is detected

        • Problem with speed sensor signal circuit is detected

        • Communication between skid control ECU (brake booster with master cylinder assembly) and hybrid vehicle control ECU stops

        The hybrid vehicle control ECU cancels speed limiter system operation

        (The stored vehicle limit speed in the hybrid vehicle control ECU is not maintained)
        Resume Control After the speed limiter system control of vehicle speed is canceled by pulling the cruise control main switch to CANCEL or VSC being turned off, press the cruise control main switch to +RES The hybrid vehicle control ECU resumes speed limiter system control using the vehicle limit speed set when control was canceled
        Interrupt Control Move the shift lever to R while the speed limiter system control is operating The limit speed cannot be changed by using the cruise control main switch
        Other Control Turn the power switch off The limit speed stored in the hybrid vehicle control ECU is cleared

        *1: If the cruise control main switch is pressed to -SET while the vehicle is being driven at 30 km/h or 20 mph or less, or the vehicle is stopped, the hybrid vehicle control ECU limits the vehicle speed to 30 km/h or 20 mph.

        *2: The hybrid vehicle control ECU stores the vehicle speed when the cruise control main switch is released and limits the vehicle speed to that stored speed.

        *3: After acceleration, if the vehicle speed drops below the limit speed, the hybrid vehicle control ECU resumes limiting the vehicle speed to the limit speed.
