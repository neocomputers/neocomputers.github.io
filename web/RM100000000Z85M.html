NAVIGATION SYSTEM(for Radio and Display Type), Diagnostic DTC:B1550, B158D, B15A0, B15B0, B15B3

DTC Code DTC Name
B1550 DAB Tuner Malfunction
B158D Video Signal Stoppage
B15A0 LAN Master Malfunction
B15B0 Display Screen Malfunction
B15B3 Radio Tuner Malfunction

DESCRIPTION

These DTCs are stored when a malfunction occurs in the radio and display receiver assembly.

DTC No. Detection Item DTC Detection Condition Trouble Area
B1550 DAB Tuner Malfunction

When any of the following conditions is met:


  • DAB tuner decoder malfunction

  • DAB tuner audio output section malfunction

  • DAB tuner decoder RF/IF malfunction

  • DAB tuner control communication error

  • DAB tuner OFDM error

  • DAB tuner memory error

 Radio and display receiver assembly
B158D Video Signal Stoppage The internal video signal of the radio and display receiver assembly is interrupted Radio and display receiver assembly
B15A0 LAN Master Malfunction

When either of the following conditions is met:


  • Bus malfunction

  • EEPROM error

 Radio and display receiver assembly
B15B0 Display Screen Malfunction Picture circuit (TFT unit) malfunction Radio and display receiver assembly
B15B3 Radio Tuner Malfunction

When any of the following conditions is met:


  • AM tuner PLL is unlocked

  • FM tuner PLL is unlocked

  • Tuner malfunction

 Radio and display receiver assembly
