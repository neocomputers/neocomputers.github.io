ADAPTIVE HIGH BEAM SYSTEM, Diagnostic DTC:B2492, B2493

DTC Code DTC Name
B2492 Left Headlight Driver Module Circuit
B2493 Right Headlight Driver Module Circuit

DESCRIPTION

The headlight light control ECU sub-assembly receives high beam control signals from the No. 1 headlight ECU sub-assembly which it uses to control the current and pattern of the LED array via LIN communication. If an abnormal LED array current is detected, No. 1 headlight ECU sub-assembly LH stores DTC B2492 and B2493.

DTC No. Detection Item DTC Detection Condition Trouble Area
B2492 Left Headlight Driver Module Circuit

  • LED array LH abnormal

  • Headlight light control ECU sub-assembly LH abnormal

  • Headlight unit LH

  • Headlight unit assembly LH

  • Headlight light control ECU sub-assembly LH
B2493 Right Headlight Driver Module Circuit

  • LED array RH abnormal

  • Headlight light control ECU sub-assembly RH abnormal

  • Headlight unit RH

  • Headlight unit assembly RH

  • Headlight light control ECU sub-assembly RH
