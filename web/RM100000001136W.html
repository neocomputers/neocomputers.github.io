    1. Bolt
      Screw

    1. Engage the 21 clips and install the front door weatherstrip.

  18. INSTALL FRONT DOOR CHECK ASSEMBLY


    1. Apply MP grease to the sliding parts of the front door check assembly.

    2. Clean the bolt hole in the vehicle body.

    3. Clean the threads of the bolt (B).

    4. Apply adhesive to the threads of the bolt (B).

      Adhesive
      Toyota Genuine Adhesive 1324, Three Bond 1324 or equivalent

    5. Install the front door check assembly with the 3 bolts.

      Torque:
      Bolt (A)
      5.5 N*m  { 56 kgf*cm, 49 in.*lbf }
      Bolt (B)
      30 N*m  { 306 kgf*cm, 22 ft.*lbf }

  19. INSTALL FRONT DOOR LOCK OPEN ROD

      Install in this Direction (2)

      *B Inside

  29. INSTALL FRONT DOOR WINDOW REGULATOR ASSEMBLY


    1. Apply MP grease to the sliding parts of the front door window regulator assembly.

    2. Temporarily install the temporary bolt to the front door window regulator assembly.

    3. *a Temporary Bolt

      Temporarily install the front door window regulator assembly with the 5 bolts.

    4. Tighten the temporary bolt and 5 bolts to install the front door window regulator assembly.

      Tech Tips

      Tighten the bolts in the order shown in the illustration.

      Torque:
      8.0 N*m  { 82 kgf*cm, 71 in.*lbf }

    5. Connect the connector.

    6. Engage the 2 claws to install the front door No. 2 service hole cover.

  30. INSTALL FRONT DOOR GLASS SUB-ASSEMBLY


    1. for Driver Side:


      1. Connect the multiplex network master switch assembly.

    2. for Front Passenger Side:


      1. Connect the power window regulator switch assembly.

    3. Connect the cable to the negative (-) auxiliary battery terminal.

    4. Turn the power switch on (IG).

    5. Move the front door window regulator assembly so that the door glass bolt holes can be seen.

    6. Turn the power switch off.

    7. Disconnect the cable from the negative (-) auxiliary battery terminal.

    8. for Driver Side:


      1. Disconnect the multiplex network master switch assembly.

    9. for Front Passenger Side:


      1. Disconnect the power window regulator switch assembly.

    10. Install in this Direction (1)
      Install in this Direction (2)

      Insert the front door glass sub-assembly into the front door panel along the front door glass run as shown in the illustration.

    11. Install the front door glass sub-assembly with the 2 bolts.

      Torque:
      8.0 N*m  { 82 kgf*cm, 71 in.*lbf }

    12. Install the hole plug.
