VEHICLE PROXIMITY NOTIFICATION SYSTEM DIAGNOSIS SYSTEM


  1. INPUT SIGNAL CHECK (Switch Illumination Check)


    1. *1 Pattern Select Switch Assembly (Vehicle Approaching Speaker Switch)
      *a Blinking

      Turn the power switch on (IG) and check the pattern select switch assembly (vehicle approaching speaker switch) indicator light.

    2. If the vehicle approaching speaker controller stores a DTC, the pattern select switch assembly (vehicle approaching speaker switch) indicator light will blink for 16 seconds and then illuminate.

      Tech Tips

      When the vehicle approaching speaker returns to normal, the pattern select switch assembly (vehicle approaching speaker switch) indicator light will turn off.
