ROOF GARNISH INSTALLATION

PROCEDURE


  1. INSTALL ROOF TOP MOULDING SUB-ASSEMBLY


    1. Install the roof top moulding sub-assembly with the 7 nuts as shown in the illustration.

      Install in this Direction - -
      Torque:
      7.0 N*m  { 71 kgf*cm, 62 in.*lbf }

  2. INSTALL ROOF HEADLINING ASSEMBLY

    Click here

  3. INSTALL REAR ROOF DRIP SIDE FINISH MOULDING SUB-ASSEMBLY LH


    1. Install a new gasket and new cap.

    2. Install 2 new clips to the rear roof drip side finish moulding sub-assembly LH.

    3. Install in this Direction

      Engage the 3 clips as shown in the illustration to install the rear roof drip side finish moulding sub-assembly LH.

  4. INSTALL REAR ROOF DRIP SIDE FINISH MOULDING SUB-ASSEMBLY RH

    Tech Tips

    Use the same procedure as for the LH side.
