HYBRID BATTERY SYSTEM DTC CHECK / CLEAR


  1. CHECK FOR DTCS


    1. Connect the GTS to the DLC3.

    2. Turn the power switch on (IG).

    3. Turn the GTS on.

    4. Enter the following menus: Powertrain / HV battery / Trouble Codes.


      Powertrain > HV Battery > Trouble Codes

    5. Check the DTCs and freeze frame data, and then write them down.

    6. Check the details of the DTCs.

      Tech Tips

      Display Item Description
      Confirmed (Current DTC) DTCs that indicate malfunctions
      Pending (Pending DTC)

      • DTCs that indicate temporary malfunctions

      • Existence of malfunction has not been confirmed but there is a possibility

      • A pending DTC is a DTC that is stored in the battery ECU assembly during the 1st trip when the 2 trip detection logic is used.

      • Both Confirmed (Current DTC) and Pending (Pending DTC) record freeze frame data.


      1. Enter the following menus: Powertrain / HV Battery / Utility / Check Mode.


        Powertrain > HV Battery > Utility
        Tester Display
        Check Mode

      2. Check items on the display and press "Next".

        Note


        • All the stored DTCs and freeze frame data are cleared if the battery ECU assembly is changed from normal mode to check mode. Before changing modes, always check and note any DTCs and freeze frame data.

        • Changing from normal mode to check mode function is not available when the power switch is turned on (READY).

        • If a DTC is stored, check and note the DTC and freeze frame data following the GTS display, then change from normal mode to check mode.

  2. CHECK FREEZE FRAME DATA


    1. If a DTC is present, select it in order to display its freeze frame data.

    2. Read the freeze frame data recorded when the DTC was stored.

  3. CHECK TIME STAMP

    Tech Tips

    By checking Time Stamp, the time and order in which DTCs were stored in an ECU can be checked.


    1. Connect the GTS to the DLC3.

    2. Turn the power switch on (IG).

    3. Enter the following menus: Health Check.

    4. Perform the following steps when the data setting screen is displayed.

    5. Select the systems for which to perform Health Check and check for time stamp data.


        Selectable items:

      • Powertrain

      • Chassis

      • Body

      • Store All Data

    6. Select "Yes" when "Do you want to store time stamp data?" is displayed.

      Tech Tips

      If "Yes" is not selected, time stamp data will not be stored.

    7. After Health Check has completed, select "Time Stamp Data" to display the Time Stamp screen.

    8. Select the desired system from the drop-down list on the bottom of the Time Stamp screen.

    9. Check the order and time which DTCs were stored for the selected system.

  4. CHECK FOR DTCS (SYSTEMS EXCEPT BATTERY ECU ASSEMBLY)

    Tech Tips

    The battery ECU assembly maintains communication with other computers, including the electric vehicle charger assembly, the ECM, and hybrid vehicle control ECU. Therefore, if the battery ECU assembly outputs a warning, it is necessary to check and record the DTCs of all systems.


    1. If DTCs are present, check the relevant systems.

      Tech Tips

      If DTCs for the CAN communication system are present in addition to other DTCs, first troubleshoot and repair any malfunctions in the CAN communication system.

  5. CLEAR DTCS

    Note

    Clearing the DTCs will also clear the freeze frame data.


    1. Connect the GTS to the DLC3.

    2. Turn the power switch on (IG).

    3. Turn the GTS on.

    4. Enter the following menus: Powertrain / HV battery / Trouble Codes.


      Powertrain > HV Battery > Trouble Codes

    5. Clear DTCs and freeze frame data.


      Powertrain > HV Battery > Clear DTCs
