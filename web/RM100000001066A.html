SFI SYSTEM(w/o Canister Pump Module), Diagnostic DTC:P160500

DTC Code DTC Name
P160500 Rough Idling

DESCRIPTION

When the engine is idling stably under a low load, if the idle speed drops or becomes unstable, this DTC will be stored.

DTC No. Detection Item DTC Detection Condition MIL Memory Note
P160500 Rough Idling After 5 seconds or more elapse after starting the engine, with the engine running, the engine speed drops to 400 rpm or less (1 trip detection logic). Does not come on DTC Stored SAE Code: P1605

CAUTION / NOTICE / HINT

Tech Tips


  • DTC P160500


    • In contrast to normal malfunction diagnosis for components, circuits and systems, DTC P160500 is used to determine the malfunctioning area from the problem symptoms and freeze frame data when the user mentions problems such as rough idling.

      As this DTC can be stored as a result of certain user actions, even if this DTC is output, if the customer makes no mention of problems, clear the DTC without performing any troubleshooting and return the vehicle to the customer.

    • If any other DTCs are output, perform troubleshooting for those DTCs first.

    • Since DTC P160500 is different from other DTCs, the following procedure is shown as a reference.

  • FREEZE FRAME DATA


    • Read freeze frame data using the GTS. The ECM records vehicle and driving condition information as freeze frame data the moment a DTC is stored. When troubleshooting, freeze frame data can help determine if the vehicle was moving or stationary, if the engine was warmed up or not, if the air fuel ratio was lean or rich, and other data from the time the malfunction occurred.

    • When confirming the freeze frame data, be sure to check all multi freeze frame data.

      Click here

    • Try to operate the vehicle under the conditions recorded in the freeze frame data which were present when the malfunction occurred. Confirm the data at this time and the data when the engine is idling (engine warmed up and no load) and compare this data with the freeze frame data.

  • PRECAUTIONS


    • Inspections take into account the fact that the malfunction may not have recurred and place emphasis on checking the vehicle conditions present at the time when the malfunction occurred.

    • When performing inspections, jiggle the relevant wire harnesses and connectors in an attempt to reproduce malfunctions that do not always occur.

  2. CHECK FREEZE FRAME DATA

    Tech Tips

    Using freeze frame data, confirm the conditions the moment the DTC was stored and after the DTC was stored. This information can be useful when troubleshooting.


    1. Connect the GTS to the DLC3.

    2. Turn the power switch on (IG).

    3. Turn the GTS on.

    4. Check the following freeze frame data items to check if the engine was cold or warm when the freeze frame data was recorded.


      Powertrain > Engine
      Tester Display
      Coolant Temperature
      Initial Engine Coolant Temperature

    5. Check the following freeze frame data item to check if the vehicle was idling.


      Powertrain > Engine
      Tester Display
      Engine Speed

    6. Check the following freeze frame data item to check purge VSV operation when the freeze frame data was recorded.


      Powertrain > Engine
      Tester Display
      EVAP (Purge) VSV

    7. Check the following freeze frame data items to check engine idle operating conditions recorded.


      Powertrain > Engine
      Tester Display
      Intake Manifold Absolute Pressure
      Throttle Sensor Position
      Idle Spark Advance Control Cylinder #1
      Idle Spark Advance Control Cylinder #2
      Idle Spark Advance Control Cylinder #3
      Idle Spark Advance Control Cylinder #4
      Target EGR Valve Position No.1
      ISC Learning Value

    8. Check the following freeze frame data items to check the engine load and electric load.


      Powertrain > Engine
      Tester Display
      Calculate Load
      Cooling Fan Duty Ratio

    9. Use this information to perform a simulation test.

    10. Compare the "Normal Condition" information in the Data List table with the freeze frame data listed above and with the simulation test results to determine the cause of the malfunction.
