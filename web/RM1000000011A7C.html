HEADLIGHT ASSEMBLY INSPECTION

PROCEDURE


  1. INSPECT HEADLIGHT UNIT ASSEMBLY LH (w/o Adaptive High Beam System)

    *1 Headlight Unit Assembly LH (Headlight Cord) - -
    *a

    Component without harness connected

    (to No. 1 Headlight ECU Sub-assembly LH)

    		 *b

    Component without harness connected

    (to Headlight Unit LH)
    *c

    Component without harness connected

    (to Headlight Leveling Motor)

    		 - -

    1. Measure the resistance according to the value(s) in the table below.


      1. Inspect the headlight leveling motor circuit.

        Standard Resistance
        Tester Connection Condition Specified Condition
        B-7 (ACTBI) - F-1 Always Below 1 Ω
        B-8 (ACTSI) - F-2 Always Below 1 Ω
        B-17 (ACTGI) - F-3 Always Below 1 Ω

        If the result is not as specified, replace the headlight unit assembly LH (headlight cord).

      2. Inspect the high beam headlight circuit.

        Standard Resistance
        Tester Connection Condition Specified Condition
        C-8 (HILED2) - D-1 Always Below 1 Ω
        C-9 (HILED1) - D-2 Always Below 1 Ω

        If the result is not as specified, replace the headlight unit assembly LH (headlight cord).

      3. Inspect the low beam headlight circuit.

        Standard Resistance
        Tester Connection Condition Specified Condition
        B-4 (LOLED2) - D-6 Always Below 1 Ω
        B-5 (LOLED1) - D-5 Always Below 1 Ω

        If the result is not as specified, replace the headlight unit assembly LH (headlight cord).

      4. Inspect the headlight fan circuit.

        Standard Resistance
        Tester Connection Condition Specified Condition
        B-6 (FANB) - D-3 Always Below 1 Ω
        B-15 (FANP) - D-7 Always Below 1 Ω
        B-14 (FANG) - D-4 Always Below 1 Ω

        If the result is not as specified, replace the headlight unit assembly LH (headlight cord).

      5. Inspect the clearance light circuit.

        Standard Resistance
        Tester Connection Condition Specified Condition
        B-19 (CLL+) - D-8 Always Below 1 Ω
        B-2 (CLL-) - D-9 Always Below 1 Ω

        If the result is not as specified, replace the headlight unit assembly LH (headlight cord).

        Tester Connection Condition Specified Condition
        K-2 (AR01) - E-1 Always Below 1 Ω

        K-6 (FL) - E-7 Always Below 1 Ω

  3. INSPECT HEADLIGHT UNIT LH

    *a

    Component without harness connected

    (to Headlight Unit Assembly LH)

    1. Apply auxiliary battery voltage to the headlight unit LH and check that the light illuminates.

      OK
      Condition Specified Condition

      Auxiliary battery positive (+) → Terminal 8

      Auxiliary battery negative (-) → Terminal 9

      		 Clearance light illuminates

      If the result is not as specified, replace the headlight unit LH.
