NAVIGATION SYSTEM(for Navigation Receiver Type), Diagnostic DTC:B158F

DTC Code DTC Name
B158F AV Signal Stoppage (Low Battery Voltage)

DESCRIPTION

This DTC is stored when a video or audio signal is interrupted due to auxiliary battery voltage input to the navigation receiver assembly dropping temporarily.

DTC No. Detection Item DTC Detection Condition Trouble Area
B158F AV Signal Stoppage (Low Battery Voltage) A video or audio signal is interrupted when the auxiliary battery voltage drops. Navigation receiver assembly

WIRING DIAGRAM

*a from Auxiliary Battery
*b RADIO
*c Navigation Receiver Assembly
