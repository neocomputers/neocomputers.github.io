TOYOTA PARKING ASSIST-SENSOR SYSTEM Sensor Frozen Indication (Dirty or Frozen)

DESCRIPTION

When the ultrasonic sensor is dirty or frozen, "Clean Parking Assist Sensor" is displayed on the multi-information display in the meter circuit plate.
