FLOW SHUTTING VALVE INSTALLATION

PROCEDURE


  1. INSTALL FLOW SHUTTING VALVE (WATER VALVE)


    1. Install a new gasket to the flow shutting valve (water valve).

    2. Install the flow shutting valve (water valve) with the 2 bolts.

      Torque:
      10 N*m  { 102 kgf*cm, 7 ft.*lbf }

    3. Remove the water outlet from the vise.

    4. Install a new water outlet gasket to the cylinder head sub-assembly.

    5. Connect the No. 10 water by-pass hose and slide the clip to secure it.

    6. Install the water outlet with the flow shutting valve (water valve) with the 2 nuts.

      Torque:
      28 N*m  { 286 kgf*cm, 21 ft.*lbf }

    7. Connect the No. 9 water by-pass hose and slide the clip to secure it.

    8. Connect the No. 3 radiator hose and slide the clip to secure it.

    9. Engage the clamp to connect the wire harness to the water outlet.

    10. Connect the 3 connectors.
