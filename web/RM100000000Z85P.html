NAVIGATION SYSTEM(for Radio and Display Type), Diagnostic DTC:B15F6

DTC Code DTC Name
B15F6 Main Body ECU Vehicle Information Reading/Writing Process Malfunction

DESCRIPTION

This DTC is stored when items controlled by the main body ECU (multiplex network body ECU) cannot be customized via the navigation system vehicle customization screen.

Tech Tips

The main body ECU (multiplex network body ECU) controls the items for the following systems that are customizable via the navigation system vehicle customization screen:


  • Wireless door lock control system

  • Lighting system (for Interior)

  • Lighting system (for Exterior)

DTC No. Detection Item DTC Detection Condition Trouble Area
B15F6 Main Body ECU Vehicle Information Reading/Writing Process Malfunction Main body ECU (multiplex network body ECU) vehicle setting processing malfunction

  • CAN communication system

  • Wireless door lock control system

  • Lighting system (for Interior)

  • Lighting system (for Exterior)

  • Main body ECU (multiplex network body ECU)

  • Radio and display receiver assembly
