VANITY LIGHT BULB REPLACEMENT

CAUTION / NOTICE / HINT

Tech Tips


  • Use the same procedure for the RH side and LH side.

  • The following procedure is for the LH side.

PROCEDURE


  1. SEPARATE VANITY LIGHT ASSEMBLY


    1. Using a moulding remover, disengage the claw to separate the vanity light assembly.

  2. REMOVE VANITY LIGHT BULB


    1. Remove in this Direction

      Remove the vanity light bulb from the bulb holder as shown in the illustration.

  3. INSTALL VANITY LIGHT BULB


    1. Install in this Direction

      Install the vanity light bulb to the bulb holder as shown in the illustration.

  4. INSTALL VANITY LIGHT ASSEMBLY


    1. Engage the claw to install the vanity light assembly.
