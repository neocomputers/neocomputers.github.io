ACCUMULATOR REASSEMBLY

PROCEDURE


  1. INSTALL VALVE TO CONNECTOR TUBE


    1. Remove the vinyl tape from the valve to connector tube and No. 5 connector tube.

    2. Sufficiently apply compressor oil to a new O-ring and the fitting surface of the No. 5 connector tube.

      Compressor Oil
      ND-OIL 11 or equivalent

    3. Install the O-ring to the No. 5 connector tube.

      Note

      Keep the O-ring and O-ring fitting surface free of foreign matter.

    4. Install the valve to connector tube with the bolt.

      Torque:
      9.8 N*m  { 100 kgf*cm, 87 in.*lbf }

  4. INSTALL NO. 3 CONNECTOR TUBE


    1. Remove the vinyl tape from the No. 3 connector tube.

    2. Sufficiently apply compressor oil to a new O-ring and the fitting surface of the No. 3 connector tube.

      Compressor Oil
      ND-OIL 11 or equivalent

    3. Install the O-ring to the No. 3 connector tube.

      Keep the O-ring and O-ring fitting surface free of foreign matter.

    4. Install the No. 3 connector tube with the bolt.

  5. INSTALL NO. 1 AIR CONDITIONING ACCESSORY ASSEMBLY

    Click here

  6. INSTALL COOLER REFRIGERANT LIQUID PIPE A


    1. Remove the vinyl tape from the cooler refrigerant liquid pipe A.

    2. Sufficiently apply compressor oil to 2 new O-rings and the fitting surfaces of the cooler refrigerant liquid pipe A.

      Compressor Oil
      ND-OIL 11 or equivalent

    3. Install the 2 O-rings to the cooler refrigerant liquid pipe A.

      Note

      Keep the O-rings and O-ring fitting surfaces free of foreign matter.

    4. Bolt (A)
      Bolt (B)

      Temporarily install the cooler refrigerant liquid pipe A with the 2 bolts.

    5. Tighten the bolt (B).

      Torque:
      9.8 N*m  { 100 kgf*cm, 87 in.*lbf }

      Note

      As the cooler refrigerant liquid pipe A may be deformed, do not tighten the bolt (A) until the No. 1 receiver tank bracket and No. 5 cooler bracket have been installed.

  7. INSTALL NO. 1 RECEIVER TANK BRACKET


    1. Install the 2 No. 2 cooler cushions.

    2. Install the 2 No. 1 cooler cushions.

    3. Install the 2 bushes.

    4. Install the No. 1 receiver tank bracket to the No. 5 cooler bracket with the 2 bolts.

      Torque:
      9.8 N*m  { 100 kgf*cm, 87 in.*lbf }

    5. Install the No. 1 receiver tank bracket with No. 5 cooler bracket with the 6 bolts.

      Bolt (A) Bolt (B)
      Torque:
      Bolt (A)
      9.8 N*m  { 100 kgf*cm, 87 in.*lbf }
      Bolt (B)
      3.4 N*m  { 35 kgf*cm, 30 in.*lbf }

      Tech Tips

      Make sure that the wire harnesses are routed as shown in the illustration.

      *1 High Pressure Magnetic Valve *2 No. 1 Air Conditioning Accessory Assembly

    6. Engage the clamp.

    7. Tighten the bolt.

      Torque:
      9.8 N*m  { 100 kgf*cm, 87 in.*lbf }

  8. INSTALL NO. 6 COOLER BRACKET


    1. Install the No. 6 cooler bracket with the bolt.

      Torque:
      9.8 N*m  { 100 kgf*cm, 87 in.*lbf }

  9. INSTALL AIR CONDITIONING RECEIVER TANK

  11. INSTALL NO. 2 RECEIVER TANK BRACKET


    1. Install the 2 No. 2 cooler cushions.

    2. Install the 2 No. 1 cooler cushions.

    3. Install the 2 bushes.

    4. Temporarily install the No. 1 receiver tank bracket and 2 receiver holders with the 4 bolts.

    5. Remove the vinyl tape from the air conditioning receiver tank.

    6. Sufficiently apply compressor oil to a new O-ring and the fitting surface of the air conditioning receiver tank.

      Compressor Oil
      ND-OIL 11 or equivalent

    7. Install the O-ring to the No. 1 connector tube.

      Note

      Keep the O-ring and O-ring fitting surface free of foreign matter.

    8. Install in this Direction

      Temporarily install the air conditioning receiver tank with bracket as shown in the illustration.

    9. Temporarily install the 4 bolts.

    10. Bolt (A)
      Bolt (B)
      Bolt (C)
      Bolt (D)

      Tighten the bolt (A).

      Torque:
      9.8 N*m  { 100 kgf*cm, 87 in.*lbf }

    11. Tighten the bolt (B).

      Torque:
      3.4 N*m  { 35 kgf*cm, 30 in.*lbf }

    12. Tighten the 2 bolts (C).

      Torque:
      9.8 N*m  { 100 kgf*cm, 87 in.*lbf }

    13. Tighten the 4 bolts (D) to install the air conditioning receiver tank with bracket.

      Torque:
      9.8 N*m  { 100 kgf*cm, 87 in.*lbf }

    14. Engage the 2 clamps.

  12. INSTALL NO. 3 RECEIVER TANK BRACKET


    1. Install the No. 3 receiver tank bracket with the 2 bolts.

      Torque:
      9.8 N*m  { 100 kgf*cm, 87 in.*lbf }
