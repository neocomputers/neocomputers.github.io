  1. INSTALL HOOD STAY BRACKET


    1. Engage the guide.

  2. INSTALL HOOD SUPPORT ASSEMBLY


    1. Engage the 3 claws to install the hood support assembly.

  3. INSTALL HOOD STAY HOLDER


    1. Engage the 2 claws to install the hood stay holder.

  4. CONNECT WASHER HOSE ASSEMBLY


    1. Engage the grommet.

    2. Engage the 5 clamps to connect the washer hose assembly.
