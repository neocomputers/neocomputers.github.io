RAIN SENSOR ON-VEHICLE INSPECTION

PROCEDURE


  1. INSPECT RAIN SENSOR


    1. *a

      Front view of wire harness connector

      (to Rain Sensor)

      Disconnect the O1 rain sensor connector.

    2. Measure the voltage according to the value(s) in the table below.

      Standard Voltage
      Tester Connection Condition Specified Condition
      O1-4 (SIG) - O1-2 (ES) Power switch on (IG) 11 to 14 V

    3. Measure the resistance according to the value(s) in the table below.

      Standard Resistance
      Tester Connection Condition Specified Condition
      O1-2 (ES) - Body ground Always Below 1 Ω

      If the result is not as specified, repair or replace the harness or connector.

    4. *a

      Component with harness connected

      (Rain Sensor)

      Connect the O1 rain sensor connector.

    5. Connect an oscilloscope to the rain sensor connector.

    6. Check for pulses.

      OK
      Tester Connection Condition Specified Condition
      3 (MPX) - 2 (ES) Power switch on (IG) Pulse generation

      If the result is not as specified, replace the rain sensor.
