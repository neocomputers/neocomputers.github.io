HYBRID VEHICLE CONTROL ECU INSTALLATION

PROCEDURE


  1. INSTALL HYBRID VEHICLE CONTROL ECU (for LHD)


    1. Engage the 2 claws to install the hybrid vehicle control ECU as shown in the illustration.

      Note

      Make sure that the hybrid vehicle control ECU is securely installed.

  2. INSTALL ECU INTEGRATION BOX RH (for LHD)


    1. Install the ECU integration box RH with the bolt and 2 nuts.

    2. Engage the 3 clamps.

    3. *a Lock Lever

      Connect the 3 hybrid vehicle control ECU connectors and move each lock lever as shown in the illustration to lock the connectors.

    4. Connect each connector.

  3. INSTALL HYBRID VEHICLE CONTROL ECU (for RHD)


    1. Engage the 2 claws to install the hybrid vehicle control ECU as shown in the illustration.

      Note

      Make sure that the hybrid vehicle control ECU is securely installed.

  4. INSTALL ECU INTEGRATION BOX LH (for RHD)


    1. Install the ECU integration box LH with the bolt and nut.

    2. *a Lock Lever

      Connect the 3 hybrid vehicle control ECU connectors and move each lock lever as shown in the illustration to lock the connectors.

    3. Connect each connector.
