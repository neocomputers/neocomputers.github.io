FUEL TANK(w/o Canister Pump Module) INSTALLATION

PROCEDURE


  1. INSTALL CHARCOAL CANISTER OUTLET HOSE


    1. Engage the 2 clamps to install the charcoal canister outlet hose to the fuel tank assembly.

  2. INSTALL FUEL TANK MAIN TUBE SUB-ASSEMBLY


    1. Engage the 3 clamps to install the fuel tank main tube sub-assembly to the fuel tank assembly.

  3. INSTALL NO. 1 FUEL EVAPORATION TUBE SUB-ASSEMBLY


    1. Engage the 3 clamps to install the No. 1 fuel evaporation tube sub-assembly to the fuel tank assembly.

  4. INSTALL FUEL TANK ASSEMBLY

    CAUTION:

    The fuel tank assembly is very heavy. Be sure to follow the procedure described in the repair manual, or the fuel tank assembly may fall off the engine lifter.


    1. Set the fuel tank assembly on an engine lifter.

      Note

      Using height adjustment attachments and plate lift attachments, keep the fuel tank assembly horizontal.

    2. Using the engine lifter, slowly raise the fuel tank assembly, and then install the fuel tank assembly with the 4 bolts.

      Torque:
      45 N*m  { 459 kgf*cm, 33 ft.*lbf }

      Note


      • Be careful not to drop the fuel tank assembly.

      • When installing the fuel tank assembly, tilt it slightly to prevent it from interfering with the surrounding parts.

  5. CONNECT FUEL TANK MAIN TUBE SUB-ASSEMBLY


    1. Connect the fuel tank main tube sub-assembly to the fuel pipe.

      Click here

  6. CONNECT NO. 1 FUEL EVAPORATION TUBE SUB-ASSEMBLY


    1. *a 120°
      *b Up

      Connect the No. 1 fuel evaporation tube sub-assembly to the fuel pipe and slide the clip to secure it.

      Tech Tips

      Engage the clip within the area shown in the illustration.

  7. INSTALL NO. 3 PARKING BRAKE CABLE ASSEMBLY


    1. Install the No. 3 parking brake cable assembly with the 2 bolts.

      Torque:
      6.0 N*m  { 61 kgf*cm, 53 in.*lbf }

  8. CONNECT FUEL TANK TO FILLER PIPE HOSE


    1. *a 120°
      *b Up
      *c Paint Mark (Fuel Tank To Filler Pipe Hose)
      *d Protrusion (Fuel Tank Assembly)

      Connect the fuel tank to filler pipe hose to the fuel tank assembly and tighten the clamp to secure it.

      Tech Tips

      Make sure the clamp and fuel tank to filler pipe hose are positioned within the area shown in the illustration.

  9. CONNECT FUEL TANK BREATHER TUBE


    1. Connect the fuel tank breather tube to the fuel tank filler pipe sub-assembly.

      Click here

  10. CONNECT CHARCOAL CANISTER OUTLET HOSE


    1. Connect the charcoal canister outlet hose to the fuel tank filler pipe sub-assembly.

  11. INSTALL NO. 1 FUEL TANK PROTECTOR


    1. Install the No. 1 fuel tank protector to the fuel tank assembly with the 4 clips.

  12. INSTALL REAR FLOOR SIDE MEMBER COVER LH


    1. Install the rear floor side member cover LH with the clip (B).

    2. Install the 3 bolts and clip (A).

      Torque:
      7.5 N*m  { 76 kgf*cm, 66 in.*lbf }

  13. INSTALL NO. 1 FLOOR UNDER COVER ASSEMBLY


    1. Install the No. 1 floor under cover assembly with the clip.

    2. Install the 3 bolts.

      Torque:
      7.5 N*m  { 76 kgf*cm, 66 in.*lbf }

    Click here
