NAVIGATION SYSTEM(for Radio and Display Type) Data Signal Circuit between Stereo Jack Adapter and Extension Module

DESCRIPTION

The No. 1 stereo jack adapter assembly sends the sound data signal or image data signal from a USB device to the navigation ECU via this circuit.
