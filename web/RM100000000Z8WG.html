AIRBAG SYSTEM, Diagnostic DTC:B1650/32, B165A/32

DTC Code DTC Name
B1650/32 Occupant Classification System Malfunction
B165A/32 Occupant Detection Sensor Zero Point Calibration Incomplete

DESCRIPTION

The airbag sensor assembly and occupant detection ECU communicate via CAN communication.

When the occupant detection ECU stores DTC B1771, B1780, B1782, B1795, B1798, B1799, U0125 or U0129, the airbag sensor assembly receives this information and stores DTC B1650/32.

When the occupant detection ECU stores DTC B1785 or B1787, the airbag sensor assembly receives this information and stores DTC B165A/32.

DTC No. Detection Item DTC Detection Condition Trouble Area Test Mode / Check Mode
B1650/32 Occupant Classification System Malfunction The occupant detection ECU has stored DTC B1771, B1780, B1782, B1795, B1798, B1799, U0125 or U0129. Occupant classification system Does not apply to test/check mode
B165A/32 Occupant Detection Sensor Zero Point Calibration Incomplete The occupant detection ECU has stored DTC B1785 or B1787. Occupant classification system Does not apply to test/check mode
