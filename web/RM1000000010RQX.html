AUTOMATIC HEADLIGHT BEAM LEVEL CONTROL SYSTEM, Diagnostic DTC:B2456

DTC Code DTC Name
B2456 Left Headlight ECU Variation Error

DESCRIPTION

This DTC is stored when a No. 1 headlight ECU sub-assembly LH which is not compatible with the vehicle has been installed. The No. 1 headlight ECU sub-assembly LH stores DTC B2456.

DTC No. Detection Item DTC Detection Condition Trouble Area Note
B2456 Left Headlight ECU Variation Error Incompatible No. 1 headlight ECU sub-assembly LH is installed

  • No. 1 headlight ECU sub-assembly LH

  • Main body ECU (multiplex network body ECU)

 -

CAUTION / NOTICE / HINT

Note


  • If the No. 1 headlight ECU sub-assembly LH has been replaced, it is necessary to synchronize the vehicle information and initialize the No. 1 headlight ECU sub-assembly LH.

    Click here

  • Before replacing the main body ECU (multiplex network body ECU), refer to Service Bulletin.
