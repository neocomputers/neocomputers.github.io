LIGHTING SYSTEM, Diagnostic DTC:U1000

DTC Code DTC Name
U1000 CAN Communication Failure (Message Registry)

DESCRIPTION

The No. 1 headlight ECU sub-assembly LH stores this DTC if it detects an internal malfunction related to the CAN communication system. The No. 1 headlight ECU sub-assembly LH stores DTC U1000.

DTC No. Detection Item DTC Detection Condition Trouble Area Note
U1000 CAN Communication Failure (Message Registry) CAN communication failure No. 1 headlight ECU sub-assembly LH -

CAUTION / NOTICE / HINT

Note

If the No. 1 headlight ECU sub-assembly LH has been replaced, it is necessary to synchronize the vehicle information and initialize the No. 1 headlight ECU sub-assembly LH.
