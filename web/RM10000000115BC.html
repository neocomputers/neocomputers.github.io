BATTERY ECU INSTALLATION

PROCEDURE


  1. INSTALL BATTERY ECU ASSEMBLY

    CAUTION:

    Be sure to wear insulated gloves and protective goggles.


    1. *a Black Label

      Install the battery ECU assembly to the HV battery with the 3 nuts (B).

      Torque:
      7.5 N*m  { 76 kgf*cm, 66 in.*lbf }

      Note


      • Check the color of the label.

      • If the battery ECU assembly has been struck or dropped, replace it.

    2. Install the nut (A) to connect the wire harness.

      Torque:
      7.5 N*m  { 76 kgf*cm, 66 in.*lbf }
    3. *a Lock Lever (A)
      *b Lock Lever (B)

      Connect the battery ECU assembly connector and move the lock lever (B) as shown in the illustration to lock the connector.

      Note

      Make sure that the connector is connected securely.

    4. Connect the 5 battery ECU assembly connectors and move each lock lever (A) as shown in the illustration to lock the connectors.

      Note

      Make sure that the connectors are connected securely.
