FRONT BRAKE REASSEMBLY

PROCEDURE


  1. TEMPORARILY TIGHTEN FRONT DISC BRAKE BLEEDER PLUG

    Tech Tips

    Fully tighten the front disc brake bleeder plug after bleeding the system.

  2. INSTALL FRONT DISC BRAKE BLEEDER PLUG CAP

  3. INSTALL PISTON SEAL


    1. Lithium Soap Base Glycol Grease

      Apply lithium soap base glycol grease to the entire circumference of a new piston seal.

    2. *1 Piston Seal
      *2 Front Disc Brake Cylinder

      Install the piston seal to the front disc brake cylinder.

      Note

      Securely install the piston seal into the groove of the front disc brake cylinder.

  4. INSTALL FRONT DISC BRAKE PISTON


    1. *1 Cylinder Boot
      *2 Front Disc Brake Piston
      Lithium Soap Base Glycol Grease

      Apply a light layer of lithium soap base glycol grease to the entire circumference of a new cylinder boot.

    2. Apply a light layer of lithium soap base glycol grease to the contact surfaces of the front disc brake piston.

    3. Install the cylinder boot to the front disc brake piston.

      Note

      Securely install the cylinder boot into the groove of the front disc brake piston.

    4. *1 Cylinder Boot
      *2 Front Disc Brake Piston
      *3 Front Disc Brake Cylinder
      *4 Set Ring

      Install the front disc brake piston to the front disc brake cylinder.

      Note

      Do not forcibly install the front disc brake piston into the front disc brake cylinder.

    5. Install the cylinder boot to the front disc brake cylinder as shown in the illustration.

      Note


      • Securely install the cylinder boot into the groove of the front disc brake cylinder.

      • Do not damage the cylinder boot.

    6. *a Protective Tape

      Using a screwdriver with its tip wrapped with protective tape, install a new set ring.

      Note

      Do not damage the cylinder boot.
