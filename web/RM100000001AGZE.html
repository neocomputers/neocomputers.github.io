DESCRIPTION

Tech Tips


  • The electronic shift lever system is a linkless type that does not use a shift cable.

  • The shift and select sensors are non-contact type sensors.

The shift lever (shift lock control unit assembly) is a momentary type, which returns to its home position by spring tension as the driver's hand is released from the shift lever after shifting.

The shift lever (shift lock control unit assembly) contains a shift sensor to detect the shift lever position (Home, R, N, D or B). Because the shift sensor operates using Hall ICs, they can accurately detect the shift lever position in a reliable manner.

CONFIRMATION DRIVING PATTERN

Tech Tips

After repair has been completed, clear the DTC and then check that the vehicle has returned to normal by performing the following All Readiness check procedure.

Click here


  1. Connect the GTS to the DLC3.

  2. Turn the power switch on (IG) and turn the GTS on.

  3. Clear the DTCs (even if no DTCs are stored, perform the clear DTC procedure).

  4. Turn the power switch off and wait for 2 minutes or more.

  5. Turn the power switch on (IG) and turn the GTS on.

  6. Turn the power switch on (READY).

  7. With the brake pedal depressed, slowly move the shift lever as follows to select each shift state: N → R → N → D → N → Home → B → Home.

  8. Push the P position switch (transmission shift main switch) to select park (P).

  9. Enter the following menus: Powertrain / Hybrid Control / Utility / All Readiness.

  10. Check the DTC judgment result.

    Tech Tips


    • If the judgment result shows NORMAL, the system is normal.

    • If the judgment result shows ABNORMAL, the system has a malfunction.

    • If the judgment result shows INCOMPLETE or N/A, perform driving pattern again.
