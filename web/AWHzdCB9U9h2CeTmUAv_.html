ELECTRONIC SHIFT LEVER SYSTEM SYSTEM DESCRIPTION


  1. SYSTEM DESCRIPTION

    The electronic shift lever system electrically controls the parking lock mechanism using an actuator.

    The hybrid vehicle control ECU controls the shift change function to lock/unlock based on the security signal from the certification ECU (smart key ECU assembly).

    The hybrid vehicle control ECU performs shift control based on signals from the shift lever position sensor, P position switch (transmission shift main switch) and various ECUs in accordance with each shift position.

    If the electronic shift lever system malfunctions, the master warning light in the combination meter assembly is illuminated and the P position control system warning message is displayed on the multi-information display.

    If the malfunction occurs, a DTC is stored in the hybrid vehicle control ECU.

  2. P POSITION SWITCH INDICATOR LIGHT CONTROL
