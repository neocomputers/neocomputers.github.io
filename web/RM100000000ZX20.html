AIR CLEANER FILTER ELEMENT INSTALLATION

PROCEDURE


  1. INSTALL AIR CLEANER FILTER ELEMENT SUB-ASSEMBLY


    1. Check that the inside of the air cleaner case sub-assembly does not have dirt or deposits, and clean them away if they are present.

    2. Install the air cleaner filter element sub-assembly to the air cleaner case sub-assembly.

  2. INSTALL AIR CLEANER CAP SUB-ASSEMBLY


    1. Install the air cleaner cap sub-assembly to the air cleaner case sub-assembly.

    2. Secure the air cleaner cap sub-assembly with the 2 clamp hooks.
