WIPER SWITCH INSTALLATION

PROCEDURE


  1. INSTALL WINDSHIELD WIPER SWITCH ASSEMBLY


    1. Install in this Direction

      Engage the claw as shown in the illustration to install the windshield wiper switch assembly.

    2. Connect the 2 connectors.

  2. INSTALL UPPER STEERING COLUMN COVER


    1. Engage the 4 clips and 2 claws to connect the upper steering column cover to the lower instrument cover sub-assembly.

    2. Install in this Direction

      Engage the claw to install the upper steering column cover as shown in the illustration.

  3. INSTALL LOWER STEERING COLUMN COVER SUB-ASSEMBLY

    Note

    If the lower steering column cover sub-assembly is installed in the incorrect order, the parts may break.


    1. Install in this Direction

      Engage the 3 claws as shown in the illustration.

    2. Engage the 2 claws.

    3. Turn the steering wheel assembly to the left and install the screw.

    4. Turn the steering wheel assembly to the right and install the lower steering column cover sub-assembly with the screw.
