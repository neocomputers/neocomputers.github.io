SIMPLE INTELLIGENT PARKING ASSIST SYSTEM, Diagnostic DTC:C164A

DTC Code DTC Name
C164A EPS Communication Malfunction

DESCRIPTION

This DTC is stored when the clearance warning ECU assembly receives a communication malfunction signal from the power steering ECU assembly via CAN communication.

DTC No. Detection Item DTC Detection Condition Trouble Area
C164A EPS Communication Malfunction EPS communication malfunction

  • Power steering system

  • Power steering ECU assembly

  • Clearance warning ECU assembly

CAUTION / NOTICE / HINT

Note

Depending on the parts that are replaced or operations that are performed during vehicle inspection or maintenance, calibration of other systems as well as the simple intelligent parking assist system may be needed.

      Tech Tips


      • If the DTC is not output again when rechecking for DTCs, it may have been stored due to a temporary communication problem between the clearance warning ECU assembly and power steering ECU assembly.

      • If DTC C164A is output frequently, duplicate the conditions that caused the problem symptoms and perform the inspection again, even though DTCs were not output when rechecking for DTCs.
