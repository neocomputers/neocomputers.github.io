REAR SEAT INNER BELT ASSEMBLY(for RH Side) INSPECTION

PROCEDURE


  1. INSPECT REAR SEAT 3 POINT TYPE BELT ASSEMBLY RH

    *a

    Component without harness connected

    (Rear Seat 3 Point Type Belt Assembly RH)

    1. Measure the resistance according to the value(s) in the table below.

      Standard Resistance
      Tester Connection Condition Specified Condition
      5 - 4 Rear seat 3 point type belt assembly RH unfastened Below 1 Ω
      Rear seat 3 point type belt assembly RH fastened 10 kΩ or higher

      If the result is not as specified, replace the rear seat 3 point type belt assembly RH.
