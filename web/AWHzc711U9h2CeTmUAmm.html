CHARGE INLET INSTALLATION

PROCEDURE


  1. INSTALL CABLE EV CHARGER LOCK ASSEMBLY (w/ CABLE EV CHARGER LOCK ASSEMBLY)


    1. Install the cable EV charger lock assembly to the inlet AC charger cable with the pin.

  2. INSTALL INLET AC CHARGER CABLE (w/ CABLE EV CHARGER LOCK ASSEMBLY)

    CAUTION:

    Wear insulated gloves.


    1. *A for Type A
      *B for Type B
      *a Earth Terminal
      Nut
      Bolt

      Install the inlet AC charger cable with the 4 nuts.

      Torque:
      8.0 N*m  { 82 kgf*cm, 71 in.*lbf }

    2. Install the bolt to connect the earth terminal.

      Torque:
      for Type A
      10 N*m  { 102 kgf*cm, 7 ft.*lbf }
      for Type B
      7.0 N*m  { 71 kgf*cm, 62 in.*lbf }

    3. Connect the cable EV charger lock assembly connector.

    4. *a Green-colored Lock
      Slide

      Engage the 4 clamps.

    5. Connect the inlet AC charger cable connector (B) and slide the green-colored lock as shown in the illustration to lock it securely.

      Note

      Make sure that the connector is connected securely.

    6. Connect the inlet AC charger cable connector (A).

    7. Connect the drain hose.

  3. INSTALL INLET AC CHARGER CABLE (w/o CABLE EV CHARGER LOCK ASSEMBLY)

    CAUTION:

    Wear insulated gloves.


    1. *A for Type A
      *B for Type B
      *a Earth Terminal
      Nut
      Bolt

      Install the inlet AC charger cable with the 4 nuts.

      Torque:
      8.0 N*m  { 82 kgf*cm, 71 in.*lbf }

    2. Install the bolt to connect the earth terminal.

      Torque:
      for Type A
      10 N*m  { 102 kgf*cm, 7 ft.*lbf }
      for Type B
      7.0 N*m  { 71 kgf*cm, 62 in.*lbf }
    3. *a Green-colored Lock
      Slide

      Engage the 4 clamps.

    4. Connect the inlet AC charger cable connector (B) and slide the green-colored lock as shown in the illustration to lock it securely.

      Note

      Make sure that the connectors are connected securely.

    5. Connect the inlet AC charger cable connector (A).

    6. Connect the drain hose.
