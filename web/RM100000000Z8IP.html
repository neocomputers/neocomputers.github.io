NAVIGATION SYSTEM(for Radio and Display Type), Diagnostic DTC:B1579

DTC Code DTC Name
B1579 Voice Recognition Microphone Disconnected

DESCRIPTION

The radio and display receiver assembly and telephone microphone assembly are connected to each other using the microphone connection detection signal lines.

This DTC is stored when a microphone connection detection signal line is disconnected.

DTC No. Detection Item DTC Detection Condition Trouble Area
B1579 Voice Recognition Microphone Disconnected Microphone signal is lost

  • Telephone microphone assembly

  • Radio and display receiver assembly

  • Harness or connector

WIRING DIAGRAM

*a Radio and Display Receiver Assembly
*b Telephone Microphone Assembly
