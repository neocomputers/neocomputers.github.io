ROAD SIGN ASSIST SYSTEM CUSTOMIZE PARAMETERS


  1. CUSTOMIZE ROAD SIGN ASSIST SYSTEM

    Tech Tips

    The following items can be customized.

    Note


    • When the customer requests a change in a function, first make sure that the function can be customized.

    • Be sure to make a note of the current settings before customizing.

    • When troubleshooting a function, first make sure that the function is set to the default setting.


    1. Customizing with the multi-information display


      1. Turn the power switch on (IG).

      2. Enter the following menu: Settings Tab.

      3. Select the setting by referring to the table below.

        Settings Tab
        Display Default Description Setting Relevant ECU
        RSA ON/OFF ON System ON/OFF setting ON or OFF Forward recognition camera

      4. Enter the following menus: Settings Tab / Settings / Road Sign Assist Setup.

      5. Select the setting by referring to the table below.

        Road Sign Assist Setup
        Display Default Description Setting Relevant ECU
        Excess Speed Only Visual Excess speed notification method setting No Notification, Only Visual or Visual and Audible Forward recognition camera
        Notification Level 2 km/h (1 MPH) Excess speed notification level setting*1 10 km/h (5 MPH), 5 km/h (3 MPH), 2 km/h (1 MPH) Forward recognition camera
        Other Notifications Only Visual No overtaking notification method setting No Notification, Only Visual or Visual & Audible Forward recognition camera

        *1: When the unit of speed selected for the meter is changed, the displayed unit of speed also changes.
