DYNAMIC RADAR CRUISE CONTROL SYSTEM OPERATION CHECK


  1. INPUT SIGNAL CHECK

    *a +RES
    *b -SET
    *c ON/OFF
    *d CANCEL

    1. Connect the GTS to the DLC3.

    2. Check the cruise control main switch using the Data List function of the GTS (ON/OFF, -SET, +RES and CANCEL).

      Click here

  2. INSPECT CRUISE CONTROL MAIN SWITCH (ON/OFF BUTTON)


    1. Turn the power switch on (IG).

    2. *a ON/OFF

      Turn the dynamic radar cruise control system on using the cruise control main switch (ON/OFF button).

    3. *1

      Cruise control indicator

      (Vehicle-to-vehicle Distance Control Mode)
      *2 Multi-information Display

      Check that the cruise control indicator (vehicle-to-vehicle distance control mode) in the combination meter assembly illuminates and "RADAR READY" is displayed on the multi-information display.

    4. Turn the cruise control system off using the cruise control main switch (ON/OFF button). Check that the cruise control indicator (vehicle-to-vehicle distance control mode) in the combination meter assembly and "RADAR READY" on the multi-information display turn off.

    5. Turn the power switch off with the cruise control indicator (vehicle-to-vehicle distance control mode) in the combination meter assembly illuminated and "RADAR READY" on the multi-information display displayed. Turn the power switch back on (IG) and check the cruise control indicator (vehicle-to-vehicle distance control mode) in the combination meter assembly and "RADAR READY" on the multi-information display are turned off.

  3. INSPECT MODE SELECT


    1. Turn the power switch on (IG).

    2. *a ON/OFF

      Push and hold the switch of the cruise control main switch (ON/OFF button) for 1.5 seconds or more with the dynamic radar cruise control system off to change to the constant speed control mode.

    3. *a

      Cruise Control Indicator

      (Vehicle-to-vehicle Distance Control Mode)
      *b Multi-information Display
      *c

      Cruise Control Indicator

      (Constant Speed Control Mode)

      Check that the cruise control indicator (vehicle-to-vehicle distance control mode) in the combination meter assembly and "RADAR READY" on the multi-information display turn off and the cruise control indicator (constant speed control mode) illuminates.

      Note

      Do not push any other switches before pushing the cruise control main switch to MODE. If any other switch is pushed, turn the dynamic radar cruise control system off and repeat the procedure above.

      Tech Tips

      If a malfunction is detected, turn the power switch off and repeat the procedure above.

  4. INSPECT STEERING PAD SWITCH ASSEMBLY


    1. Turn the power switch on (IG).

    2. *a ON/OFF

      Turn the dynamic radar cruise control system on using the cruise control main switch (ON/OFF button).

    3. *a Distance Control Switch

      Press the steering pad switch assembly (distance control switch).

    4. Check that the indicator of the vehicle-to-vehicle distance, which is shown on the multi-information display in the combination meter assembly changes from long to middle to short in that order.

      Tech Tips

      Long is automatically selected each time the power switch is turned on (IG).
