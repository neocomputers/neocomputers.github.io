PARKING ASSIST MONITOR SYSTEM DTC CHECK / CLEAR


  1. CHECK DTC


    1. Connect the GTS to the DLC3.

    2. Turn the power switch on (IG).

    3. Turn the GTS on.

    4. Enter the following menus: Chassis / Parking Assist Camera / Trouble Codes.


      Chassis > Parking Assist Camera > Trouble Codes

    5. Enter the following menus: Body Electrical / Navigation System / Trouble Codes.


      Body Electrical > Navigation System > Trouble Codes

    6. Check for DTCs.

      Click here

      Note

      The navigation receiver assembly*1 or radio and display receiver assembly*2 outputs DTCs for the following system. When DTCs other than those in Diagnostic Trouble Code Chart for the parking assist monitor system are output, refer to Diagnostic Trouble Code Chart for the relevant systems.


      • *1: for Navigation Receiver Type

      • *2: for Radio and Display Type

      System Proceed to
      Navigation System (for Navigation Receiver Type)

      Click here

      Navigation System (for Radio and Display Type)

      Click here

  2. CLEAR DTC


    1. Connect the GTS to the DLC3.

    2. Turn the power switch on (IG).

    3. Turn the GTS on.

    4. Enter the following menus: Chassis / Parking Assist Camera / Trouble Codes.


      Chassis > Parking Assist Camera > Clear DTCs

    5. Enter the following menus: Body Electrical / Navigation System / Trouble Codes.


      Body Electrical > Navigation System > Clear DTCs

    6. Clear the DTCs.
