VANITY LIGHT INSTALLATION

CAUTION / NOTICE / HINT

Tech Tips

  • The following procedure is for the LH side.

PROCEDURE


  1. INSTALL VANITY LIGHT BULB


    1. Install in this Direction

      Install the vanity light bulb to the bulb holder as shown in the illustration.

  2. INSTALL VANITY LIGHT ASSEMBLY


    1. Engage the 2 claws to install the vanity light assembly to the bulb holder.

    2. Engage the claw to install the vanity light assembly.
