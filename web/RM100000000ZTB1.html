IMMOBILISER SYSTEM, Diagnostic DTC:B279C95

DTC Code DTC Name
B279C95 Engine Immobiliser System Incorrect Assembly

DESCRIPTION

If a hybrid vehicle control ECU that is incompatible with the immobiliser system is installed, the hybrid vehicle control ECU will store this DTC.

DTC No. Detection Item DTC Detection Condition Trouble Area Note
B279C95 Engine Immobiliser System Incorrect Assembly A hybrid vehicle control ECU that is incompatible with the immobiliser system is installed (1-trip detection logic*). Hybrid vehicle control ECU

DTC output confirmation operation:


  • Check for DTCs.

  • *: Only detected while a malfunction is present.

Vehicle Condition and Fail-safe Function when Malfunction Detected
Vehicle Condition when Malfunction Detected Fail-safe Function when Malfunction Detected
Hybrid control system cannot be started -
