RADIATOR INSTALLATION

PROCEDURE


  1. INSTALL RADIATOR SUPPORT GROMMET


    1. Install the 2 radiator support grommets to the radiator assembly.

  2. INSTALL RADIATOR ASSEMBLY


    1. Install the No. 1 radiator hose and slide the clip to secure it.

    2. Install the radiator assembly to the vehicle body.

      Note

      Do not apply excessive force to the cooler condenser assembly or pipe when installing the radiator assembly.

    3. Engage the 2 guides.

    4. Engage the 2 claws to install the cooler condenser assembly to the radiator assembly.

      Note

      Make sure not to damage the cooler condenser assembly when installing the radiator assembly.

  3. CONNECT NO. 1 RADIATOR HOSE


    1. Connect the No. 1 radiator hose and slide the clip to secure it.
