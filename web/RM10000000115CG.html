BATTERY BLOWER INSTALLATION

PROCEDURE


  1. INSTALL BATTERY COOLING BLOWER ASSEMBLY (for LH Side)


    1. Install the battery cooling blower assembly with the 3 nuts.

      Torque:
      7.5 N*m  { 76 kgf*cm, 66 in.*lbf }

    2. Connect the battery cooling blower assembly connector.

  2. INSTALL BATTERY COOLING BLOWER ASSEMBLY (for RH Side)


    1. Install the battery cooling blower assembly with the 3 nuts.

      Torque:
      7.5 N*m  { 76 kgf*cm, 66 in.*lbf }

    2. Connect the battery cooling blower assembly connector.

  3. INSTALL NO. 2 HYBRID BATTERY INTAKE DUCT (for LH Side)


    1. Install the No. 2 hybrid battery intake duct with the 2 clips.

  4. INSTALL NO. 1 HYBRID BATTERY INTAKE DUCT (for LH Side)


    1. Install the No. 1 hybrid battery intake duct with the 2 clips.

  5. INSTALL NO. 2 HYBRID BATTERY INTAKE DUCT (for RH Side)


    1. Install the No. 2 hybrid battery intake duct with the 2 clips.

  6. INSTALL NO. 1 HYBRID BATTERY INTAKE DUCT (for RH Side)


    1. Install the No. 1 hybrid battery intake duct with the 2 clips.

  7. INSTALL NO. 3 HYBRID BATTERY INTAKE DUCT (for LH Side)


    1. Install the No. 3 hybrid battery intake duct with the 3 clips.

  8. INSTALL NO. 3 HYBRID BATTERY INTAKE DUCT (for RH Side)


    1. Install the No. 3 hybrid battery intake duct with the 3 clips.
