HEADUP DISPLAY SYSTEM SYSTEM DESCRIPTION


  1. HEADUP DISPLAY SYSTEM DESCRIPTION


    1. The headup display system receives signals from each ECU via CAN communication and local bus communication and displays driving assist information, such as current vehicle speed, on the windshield glass assembly. The brightness and position of the headup display can be changed on the settings screen of the multi-information display. Depending on certain conditions, the following items can be displayed on the headup display:

      *A for LHD *B for RHD
      *a Display Area A *b Display Area B
      *c Display Area C - -
      Display Area Display
      A Speedometer
      B Master warning light
      C Pre-crash safety warning display*1
      Intelligent clearance sonar system display*2
      Dynamic radar cruise control system warning display*3
      Lane departure alert system warning display*4
      Unsteady driving alert display*4
      Hands off steering wheel alert display*4
      Navigation system-linked display*6
      Speed limit animation (Road sign assist system)*5
      Hybrid system indicator display
      Distance (EV driving range)

      • *1: w/ Pre-crash Safety System

      • *2: w/ Intelligent Clearance Sonar System

      • *3: w/ Dynamic Radar Cruise Control System

      • *4: w/ Lane Departure Alert System (w/ Steering Control)

      • *5: w/ Road Sign Assist System

      • *6: w/ Navigation System
