FUEL INJECTOR INSTALLATION

PROCEDURE


  1. INSTALL FUEL INJECTOR ASSEMBLY

    Tech Tips

    Perform "Inspection After Repair" after replacing a fuel injector assembly.


    • SFI system (w/ Canister Pump Module):

      Click here

    • SFI system (w/o Canister Pump Module):

      Click here


    1. *1 O-ring
      *2 Injector Vibration Insulator

      Apply a light coat of gasoline or spindle oil to new injector vibration insulators and new O-rings, and then install one to each fuel injector assembly.

    2. Apply a light coat of gasoline or spindle oil where the fuel delivery pipe sub-assembly contacts each O-ring.

    3. *a Turn
      Push

      While turning the fuel injector assembly left and right, install it to the fuel delivery pipe sub-assembly.

      Note


      • Do not damage the fuel injector assembly or O-ring.

      • Make sure that the O-ring is not twisted or moved out of place when installing the fuel injector assembly.

      • After installing each fuel injector assembly, check that it turns smoothly. If not, replace the O-ring with a new one.

      Tech Tips

      Use the same procedure to install the other fuel injector assemblies.

  2. INSTALL NO. 1 DELIVERY PIPE SPACER


    1. *a Fuel Delivery Pipe Sub-assembly Side
      *b Cylinder Head Sub-assembly Side

      Install the 2 No. 1 delivery pipe spacers to the cylinder head sub-assembly.

      Note

      Install the No. 1 delivery pipe spacers in the correct direction.

  3. INSTALL FUEL DELIVERY PIPE SUB-ASSEMBLY


    1. Install the fuel delivery pipe sub-assembly with the 4 fuel injector assemblies with the 2 bolts.

      Torque:
      21 N*m  { 214 kgf*cm, 15 ft.*lbf }

      Note


      • Be careful not to drop the fuel injector assemblies when installing the fuel delivery pipe sub-assembly.

      • Check that the fuel injector assemblies turn smoothly after installing the fuel delivery pipe sub-assembly.

    2. Install the clamp of the fuel delivery pipe sub-assembly to the cylinder head sub-assembly with the bolt.

      Torque:
      21 N*m  { 214 kgf*cm, 15 ft.*lbf }

  4. CONNECT FUEL TUBE SUB-ASSEMBLY


    1. Connect the fuel tube sub-assembly to the fuel pipe.

      Click here

    2. Install the fuel pipe clamp to the fuel tube connector and close the cover of the fuel pipe clamp.

  5. CONNECT ENGINE WIRE


    1. Engage the clamp to connect the engine wire.

    2. Install the bolt.

      Torque:
      8.0 N*m  { 82 kgf*cm, 71 in.*lbf }

    3. Connect the 4 fuel injector assembly connectors.

  6. CONNECT NO. 2 VENTILATION HOSE


    1. Connect the No. 2 ventilation hose to the cylinder head cover sub-assembly and slide the clip to secure it.
