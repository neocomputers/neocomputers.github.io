POWER DOOR LOCK CONTROL SYSTEM CUSTOMIZE PARAMETERS


  1. CUSTOMIZE POWER DOOR LOCK CONTROL SYSTEM (w/ Canister Pump Module)

    Tech Tips

    The following items can be customized.

    Note


    • When the customer requests a change in a function, first make sure that the function can be customized.

    • Be sure to make a note of the current settings before customizing.

    • When troubleshooting a function, first make sure that the function is set to the default setting.


    1. Customizing with the GTS


      1. Connect the GTS to the DLC3.

      2. Turn the power switch on (IG).

      3. Turn the GTS on.

      4. Enter the following menus: Customize Setting / Door Lock.

      5. Select the setting by referring to the table below.


        Door Lock
        Tester Display Description Default Setting ECU
        Unlock Key Twice Function that unlocks only the driver door when the driver door key cylinder is turned to unlock once, and unlocks all doors when it is turned to unlock twice. For the OFF setting, turning it once unlocks all doors. ON 0:OFF,1:ON Main body ECU (Multiplex network body ECU)
        Auto Lock Function that locks all doors when the vehicle speed reaches a certain level. ON 0:OFF,1:ON Main body ECU (Multiplex network body ECU)
        Auto Lock/Shift Function that locks all doors when the shift lever is moved to select another shift state with park (P) selected, the power switch on (READY) and all doors closed. OFF 0:OFF,1:ON Main body ECU (Multiplex network body ECU)
        Auto Unlock/Shift Function that unlocks all doors when the P position switch (transmission shift main switch) is pushed with a shift state other than park (P) selected and the power switch on (READY). ON 0:OFF,1:ON Main body ECU (Multiplex network body ECU)
        All Unlock/Open-Close Function that unlocks the other doors when the driver door is opened within approximately 43 seconds of the power switch being turned off. OFF 0:OFF,1:ON Main body ECU (Multiplex network body ECU)

    2. Customizing with the multi-display


      1. Turn the power switch on (IG).

      2. Enter the following menus: MENU / SETUP / Vehicle / Vehicle customization / Door lock settings.*


        • *: for Navigation Receiver Type

      3. Enter the following menus: MENU / Setup / Vehicle / Vehicle customization / Door lock settings.*


        • *: for Radio and Display Type

      4. Select the setting by referring to the table below.

        Display Description Default Setting Relevant ECU
        Speed sensitive auto locking Function that locks all doors when the vehicle speed reaches a certain level. On On or Off Main body ECU (Multiplex network body ECU)
        Auto lock by shift from P Function that locks all doors when the shift lever is moved to select another shift state with park (P) selected, the power switch on (READY) and all doors closed. Off On or Off Main body ECU (Multiplex network body ECU)
        Auto unlock by shift to P Function that unlocks all doors when the P position switch (transmission shift main switch) is pushed with a shift state other than park (P) selected and the power switch on (READY). On On or Off Main body ECU (Multiplex network body ECU)
        Auto unlock by driver door Function that unlocks the other doors when the driver door is opened within approximately 43 seconds of the power switch being turned off. Off On or Off Main body ECU (Multiplex network body ECU)
