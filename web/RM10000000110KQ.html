ELECTRONICALLY CONTROLLED BRAKE SYSTEM, Diagnostic DTC:C1432

DTC Code DTC Name
C1432 Steering Angle Sensor Power Source Voltage

DESCRIPTION

The skid control ECU (brake booster with master cylinder assembly) outputs this DTC when it receives a sensor power source malfunction signal from the steering angle sensor.

DTC No. Detection Item INF Code DTC Detection Condition Trouble Area Note
C1432 Steering Angle Sensor Power Source Voltage 703 Steering angle sensor power supply malfunction signal is received from steering angle sensor.

  • Wire harness or connector

  • Steering angle sensor

Note

Inspect the fuses for circuits related to this system before performing the following procedure.

PROCEDURE


  1. CHECK HARNESS AND CONNECTOR (POWER SOURCE TERMINAL)


    1. *a

      Front view of wire harness connector

      (to Steering Angle Sensor)

      Remove the steering wheel and column cover.

    2. Make sure that there is no looseness at the locking part and the connecting part of the connector.

      OK
      The connector is securely connected.

    3. Disconnect the I58 steering angle sensor connector.

    4. Check both the connector case and the terminals for deformation and corrosion.

      OK
      No deformation or corrosion.

    5. Measure the voltage according to the value(s) in the table below.

      Standard Voltage
      Tester Connection Condition Specified Condition
