LIGHTING SYSTEM Hazard Warning Switch Circuit

DESCRIPTION

The combination meter assembly (meter circuit plate) receives the hazard warning signal switch assembly on signal and controls the operation of the hazard warning lights.

WIRING DIAGRAM

PROCEDURE


  1. READ VALUE USING GTS


    1. Connect the GTS to the DLC3.

    2. Turn the power switch on (IG).

    3. Turn the GTS on.

    4. Enter the following menus: Body Electrical / Combination Meter / Data List.

    5. Read the Data List according to the display on the GTS.
