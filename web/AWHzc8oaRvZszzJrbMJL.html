BATTERY COOLING FILTER INSTALLATION

PROCEDURE


  1. INSTALL NO. 1 HV BATTERY INTAKE FILTER


    1. Engage the claw to temporarily install the No. 1 HV battery intake filter to the front deck side trim cover RH.

    2. Engage the claw to install the No. 1 HV battery intake filter to the front deck side trim cover RH.

  2. INSTALL NO. 2 HV BATTERY INTAKE FILTER

    Tech Tips

    Use the same procedure as for the No. 1 HV battery intake filter.

  3. INSTALL FRONT DECK SIDE TRIM COVER RH


    1. Engage the 3 guides to temporarily install the front deck side trim cover RH.

    2. Engage the 3 claws to install the front deck side trim cover RH.

  4. CONNECT REAR DOOR OPENING TRIM WEATHERSTRIP RH


    1. Connect the rear door opening trim weatherstrip RH.

  5. INSTALL FRONT DECK SIDE TRIM COVER LH

    Tech Tips

    Use the same procedure as for the RH side.

  6. CONNECT REAR DOOR OPENING TRIM WEATHERSTRIP LH

    Tech Tips

    Use the same procedure as for the RH side.

  7. CLEAR DTC

    Tech Tips

    If the message "Maintenance required for Traction battery cooling parts" is displayed on the multi-information display, clean or replace the HV battery intake filter, and clear the DTCs to reset the learning values even if no DTCs are output.
