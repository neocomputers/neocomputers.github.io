WIPER AND WASHER SYSTEM SYSTEM DESCRIPTION


  1. FRONT WIPER AND WASHER CONTROL FUNCTION

    Control/Function Description
    MIST function Operates the wipers in the LO setting when the windshield wiper switch assembly is held in the MIST position.
    Auto operation Operates the wipers as requested by the rain sensor when the windshield wiper switch assembly is set to the AUTO position.
    Intermittent wiper operation control*

    Controls the delay of the wipers when the windshield wiper switch assembly is set to the AUTO position.

    Tech Tips


    • The period of delay is controlled by the auto sensitivity adjustment switch on the windshield wiper switch assembly.

    • The period of delay changes in accordance with vehicle speed.
    Washer cooperation

    • When the washer switch is operated for 0.5 seconds or more, the front wipers operate in the LO setting.

    • When the washer switch is released, the front wipers operate in the LO setting for 3 cycles.

    Note

    If the washer switch is operated for 40 seconds or more, operation of the washers is stopped to prevent burnout of the windshield washer motor, and the wipers return to the parked position.
    Drip prevention wiper function

    3 seconds after washer cooperation completes, operates the wipers for 1 cycle to remove any washer fluid that has dripped out.

    Tech Tips

    This function only operates when the vehicle is stationary and does not operate at a vehicle speed of 4 km/h (2 mph) or more.

    • *: When the auto wiper customize setting is set to "Not Avl", intermittent control will operate.

  2. OTHER FUNCTIONS

    Control/Function Description
    Washer fluid level low warning (w/ Level Warning Switch) Displays "Windshield Washer Fluid Low" on the multi-information display in the combination meter assembly when the washer fluid level is low.
