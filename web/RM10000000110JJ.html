ELECTRONICALLY CONTROLLED BRAKE SYSTEM, Diagnostic DTC:C1203

DTC Code DTC Name
C1203 ECM Communication Circuit

DESCRIPTION

The skid control ECU (brake booster with master cylinder assembly) stores identification information sent from other ECUs when the vehicle is shipped from the factory and changes the control constant for each system (ABS, VSC, TRC, etc.) based on the identification information.

Note

DTC C1203 is output when an incorrect ECU is installed. If initialization is performed and learning occurs with an incorrect ECU installed, operations and functions will differ from those stored when the vehicle was shipped from the factory. Therefore, make sure that learning occurs properly.

DTC No. Detection Item INF Code DTC Detection Condition Trouble Area Note
C1203 ECM Communication Circuit 1161

Either of the following is detected:


  1. Identification information sent from other ECUs does not match with the value stored when shipped from the factory.

  2. Identification information sent from other ECUs is not stored when shipped from the factory.

  • Other ECUs are not installed correctly

  • Skid control ECU (brake booster with master cylinder assembly)

Electronically controlled brake system DTC

Tech Tips


  • The DTC is cleared when the conditions return to normal.

  • This DTC is stored when incorrect identification information is detected and is not due to an ECM communication error.
