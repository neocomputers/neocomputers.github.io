REAR CONSOLE BOX INSTALLATION

PROCEDURE


  1. INSTALL REAR SEAT CONSOLE BOX ASSEMBLY


    1. Install the rear seat console box assembly with the 4 bolts.

      Torque:
      13 N*m  { 133 kgf*cm, 10 ft.*lbf }

  2. INSTALL REAR CONSOLE BOX COVER


    1. Install the rear console box cover.

  3. INSTALL REAR UNDER COVER


    1. Install in this Direction

      Engage the 5 clips and 2 claws as shown in the illustration.

    2. Install in this Direction

      Engage the 2 clips to install the rear under cover as shown in the illustration.
