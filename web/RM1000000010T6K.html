SOLAR CHARGING SYSTEM DTC CHECK / CLEAR


  1. CHECK FOR DTCS


    1. Connect the GTS to the DLC3.

    2. Turn the power switch on (IG).

    3. Turn the GTS on.

    4. Enter the following menus: Powertrain / Solar Charging Control / Trouble Codes.


      Powertrain > Solar Charging Control > Trouble Codes

    5. Check the DTCs and freeze frame data, and then write them down.

    6. Check the details of the DTCs.

      Tech Tips

      Display Item Description
      Confirmed (Current DTC) DTCs that indicate malfunctions
      Pending (Pending DTC)

      • DTCs that indicate temporary malfunctions

      • Existence of malfunction has not been confirmed but there is a possibility

      • A pending DTC is a DTC that is stored in solar energy control unit during the 1st trip when 2 trip detection logic is used.

      • Both Confirmed (Current DTC) and Pending (Pending DTC) record freeze frame data.


      1. Enter the following menus: Powertrain / Solar Charging Control / Utility / Check Mode.


        Powertrain > Solar Charging Control > Utility
        Tester Display
        Check Mode

      2. Check the display and press "Next".

        Note


        • All the stored DTCs and freeze frame data are cleared if the solar energy control unit is changed from normal mode to check mode. Before changing modes, always check and note any DTCs and freeze frame data.

        • Changing from normal mode to check mode is not possible when the power switch is on (READY).

        • If DTCs have been stored, note the DTCs and freeze frame data, before changing from normal mode to check mode.

  2. CHECK FREEZE FRAME DATA


    1. If a DTC is present, select it in order to display its freeze frame data.

    2. Read the freeze frame data recorded when the DTC was stored.

  3. CHECK FOR DTCS (SYSTEMS EXCEPT SOLAR CHARGING SYSTEM)

    Tech Tips

    The solar energy control unit maintains communication with other computers, including the hybrid vehicle control ECU, the battery ECU assembly and combination meter assembly. Therefore, if the solar energy control unit outputs a DTC, it is necessary to check for and record the DTCs of all other systems.


    1. If DTCs are present, check the relevant systems.

      Tech Tips

      If DTCs for the CAN communication system are present in addition to other DTCs, first troubleshoot and repair any malfunctions in the CAN communication system.

  4. CLEAR DTCS

    Note

    Clearing the DTCs will also clear the freeze frame data.


    1. Connect the GTS to the DLC3.

    2. Turn the power switch on (IG).

    3. Turn the GTS on.

    4. Enter the following menus: Powertrain / Solar Charging Control / Trouble Codes.

    5. Clear the DTCs and freeze frame data.


      Powertrain > Solar Charging Control > Clear DTCs
