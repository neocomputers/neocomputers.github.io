REAR DOOR COURTESY SWITCH INSTALLATION

CAUTION / NOTICE / HINT

Tech Tips


  • Use the same procedure for the RH side and LH side.

  • The following procedure is for the LH side.

PROCEDURE

    1. Connect the connector.

    2. Using a T30 "TORX" socket wrench, install the rear door courtesy light switch assembly with the screw.

      6.3 N*m  { 64 kgf*cm, 56 in.*lbf }
