AIR CONDITIONING SYSTEM CUSTOMIZE PARAMETERS


  1. CUSTOMIZE AIR CONDITIONING SYSTEM


    1. Customizing with the GTS.

      Note


      • When the customer requests a change in a function, first make sure that the function can be customized.

      • Be sure to make a note of the current settings before customizing.

      • When troubleshooting a function, first make sure that the function is set to the default setting.

      Tech Tips

      The following items can be customized.


      1. Connect the GTS.

      2. Turn the power switch on (IG).

      3. Turn the GTS on.

      4. Enter the following menus: Customize Setting / Air Conditioner.

      5. Select the setting by referring to the table below.

    2. Customizing with the multi-display (w/ Multi-display).


      1. Turn the power switch on (IG).

      2. Enter the following menus:


        • for Navigation Receiver Type: MENU / SETUP / Vehicle / Vehicle customization / Climate settings.

        • for Radio and Display Type: MENU / Setup / Vehicle / Vehicle customization / Climate settings.

      3. Select the setting by referring to the table below.

        Display Default Content Setting ECU
        Auto A/C mode On Function to turn the A/C on automatically by pressing the AUTO button when the blower is on and the A/C is off On or Off Air conditioning amplifier assembly
        Efficient ventilation mode On Function to change the mode automatically to recirculation air mode when turning the A/C on to cool the cabin quickly On or Off Air conditioning amplifier assembly

    3. Customizing with the multi-information display (combination meter assembly (meter circuit plate)) (w/o Multi-display).


      1. Turn the power switch on (IG).

      2. Select the setting tab in the multi-information display.

      3. Enter the following menus: Vehicle settings / Climate settings.

      4. Select the setting by referring to the table below.

        Display Default Content Setting ECU
        Auto A/C mode On Function to turn the A/C on automatically by pressing the AUTO button when the blower is on and the A/C is off On or Off Air conditioning amplifier assembly
        Efficient ventilation mode On Function to change the mode automatically to recirculation air mode when turning the A/C on to cool the cabin quickly On or Off Air conditioning amplifier assembly
