REAR DOOR OPENING TRIM WEATHERSTRIP INSTALLATION

CAUTION / NOTICE / HINT

Tech Tips


  • Use the same procedure for the RH side and LH side.

  • The following procedure is for the LH side.

PROCEDURE


  1. INSTALL REAR DOOR OPENING TRIM WEATHERSTRIP


    1. *a Alignment Mark
      Flange Position

      Align the alignment mark on the rear door opening trim weatherstrip with the flange on the vehicle body indicated by the arrow in the illustration, and install the rear door opening trim weatherstrip.

      Note


      • Always align the alignment mark with the flange when installing the part. If the alignment mark is not aligned, water ingress may occur.

      • After installation, check that the corners fit correctly.

      Tech Tips


      • Make sure to install the part of the rear door opening trim weatherstrip near the alignment mark first.

      • The color of the alignment marks on the rear door opening trim weatherstrip LH and rear door opening trim weatherstrip RH are different.

        Alignment Mark
        Location Color
        for LH Side Red
        for RH Side Blue
