INTEGRATION RELAY INSTALLATION

PROCEDURE


  1. INSTALL NO. 1 INTEGRATION RELAY


    1. Connect the 2 connectors.

    2. Install in this Direction

      Engage the 2 claws to install the No. 1 integration relay as shown in the illustration.

  2. INSTALL NO. 1 RELAY BLOCK COVER


    1. Install in this Direction

      Engage the 3 claws to install the No. 1 relay block cover as shown in the illustration.

  3. CONNECT CABLE TO NEGATIVE AUXILIARY BATTERY TERMINAL

    Note

    When disconnecting the cable, some systems need to be initialized after the cable is reconnected.
