REAR SEAT ASSEMBLY REASSEMBLY

CAUTION / NOTICE / HINT

CAUTION:

Wear protective gloves. Sharp areas on the parts may injure your hands.

PROCEDURE


  1. INSTALL REAR SEAT CUSHION COVER SUB-ASSEMBLY LH

    Tech Tips

    When installing a separate type rear seat cushion cover, refer to Precaution in order to prevent wrinkles from forming.

    Click here


    1. Engage the 11 claws.

      Note

      Be careful not to damage the rear seat cushion cover sub-assembly LH.

    2. Engage the 10 hooks.

      Note

      Be careful not to damage the rear seat cushion cover sub-assembly LH.

    3. *a Fastener

      Engage the 2 fasteners.

      Note

      Be careful not to damage the rear seat cushion cover sub-assembly LH.

  2. INSTALL REAR SEAT CUSHION COVER SUB-ASSEMBLY RH

    Tech Tips

    Use the same procedure as for the LH side.

  3. INSTALL CHILD RESTRAINT SEAT GUIDE CUP


    1. Install in this Direction

      Install the child restraint seat guide cup as shown in the illustration.

      Tech Tips

      Use the same procedure for all of the child restraint seat guide cups.

  4. INSTALL NO. 2 CHILD RESTRAINT SEAT COVER


    1. Install in this Direction

      Engage the 4 claws to install the No. 2 child restraint seat cover as shown in the illustration.

      Tech Tips

      Use the same procedure for all of the No. 2 child restraint seat covers.

  5. INSTALL CHILD RESTRAINT SEAT COVER


    1. Install in this Direction

      Engage the 2 guides and 2 claws to install the child restraint seat cover as shown in the illustration.

      Tech Tips

      Use the same procedure for all of the child restraint seat covers.

  6. INSTALL REAR SEATBACK LOCK ASSEMBLY RH (for RH Side)


    1. Install the rear seatback lock assembly RH to the rear seatback frame sub-assembly RH with the 2 bolts.

      Torque:
      30 N*m  { 306 kgf*cm, 22 ft.*lbf }

  7. INSTALL SEPARATE TYPE REAR SEATBACK COVER (for RH Side)

    Tech Tips

    When installing a separate type rear seatback cover, refer to Precaution in order to prevent wrinkles from forming.

    Click here


    1. Engage the 14 claws to install the separate type rear seatback cover to the separate type rear seatback pad RH.

      Note

      Be careful not to damage the separate type rear seatback cover.

  8. INSTALL SEPARATE TYPE REAR SEATBACK COVER WITH PAD (for RH Side)


    1. Install in this Direction

      Install the separate type rear seatback cover with pad to the rear seatback frame sub-assembly RH as shown in the illustration.

    2. Engage the 2 hooks.

  9. INSTALL REAR SEAT HEADREST SUPPORT (for RH Side)


    1. for Type A:


      1. Install in this Direction

        Engage the 4 claws to install the 2 rear seat headrest supports as shown in the illustration.

    2. for Type B:


      1. Install in this Direction

        Engage the 4 claws to install the 2 rear seat headrest supports as shown in the illustration.

  10. INSTALL REAR SEATBACK BOARD SUB-ASSEMBLY RH (for RH Side)


    1. Engage the guide.

    2. Engage the 4 claws to install the rear seatback board sub-assembly RH.

    3. *a Fastener

      Close the fastener as shown in the illustration.

    4. Engage the 3 hooks.

  11. INSTALL REAR SEATBACK UPPER LOCK BEZEL (for RH Side)


    1. Engage the 4 claws to install a new rear seatback upper lock bezel.

  12. INSTALL NO. 2 SEAT SIDE NO. 1 PLATE (for RH Side)


    1. Install in this Direction

      Engage the 2 guides to install a new No. 2 seat side No. 1 plate as shown in the illustration.

    2. Return the cover as shown in the illustration.

  13. INSTALL NO. 1 SEAT ARMREST ASSEMBLY (for RH Side)


    1. Engage the 5 claws to install the No. 1 seat armrest assembly.

  14. INSTALL NO. 1 SEAT SIDE NO. 1 PLATE (for RH Side)


    1. Engage the 3 clips and 8 claws to install the No. 1 seat side No. 1 plate.

    2. Install the 3 screws.

  15. INSTALL REAR NO. 1 SEATBACK BOARD CAP (for RH Side)


    1. Install the 3 rear No. 1 seatback board caps.

  16. INSTALL REAR SEATBACK LOCK ASSEMBLY LH (for LH Side)


    1. Install the rear seatback lock assembly LH to the rear seatback frame sub-assembly LH with the 2 bolts.

      Torque:
      30 N*m  { 306 kgf*cm, 22 ft.*lbf }

  17. INSTALL SEPARATE TYPE REAR SEATBACK COVER (for LH Side)

    Tech Tips

    When installing a separate type rear seatback cover, refer to Precaution in order to prevent wrinkles from forming.

    Click here


    1. Engage the 14 claws to install the separate type rear seatback cover to the separate type rear seatback pad LH.

      Note

      Be careful not to damage the separate type rear seatback cover.

  18. INSTALL SEPARATE TYPE REAR SEATBACK COVER WITH PAD (for LH Side)


    1. Install in this Direction

      Install the separate type rear seatback cover with pad to the rear seatback frame sub-assembly LH as shown in the illustration.

  19. INSTALL REAR SEAT HEADREST SUPPORT (for LH Side)


    1. for Type A:


      1. Install in this Direction

        Engage the 4 claws to install the 2 rear seat headrest supports as shown in the illustration.

    2. for Type B:


      1. Install in this Direction

        Engage the 4 claws to install the 2 rear seat headrest supports as shown in the illustration.

  20. INSTALL REAR SEATBACK BOARD SUB-ASSEMBLY LH (for LH Side)


    1. Engage the 2 guides.

    2. Engage the 5 claws to install the rear seatback board sub-assembly LH.

    3. *a Fastener

      Close the 2 fasteners as shown in the illustration.

  21. INSTALL REAR SEATBACK UPPER LOCK BEZEL (for LH Side)
