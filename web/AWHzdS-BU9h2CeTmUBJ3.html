METER / GAUGE SYSTEM FREEZE FRAME DATA


  1. FREEZE FRAME DATA


    1. Whenever a meter DTC is detected, the combination meter assembly (meter circuit plate) stores the current vehicle state as freeze frame data.

  2. CHECK FREEZE FRAME DATA


    1. Connect the GTS to the DLC3.

    2. Turn the power switch on (IG).

    3. Turn the GTS on.

    4. Enter the following menus: Body Electrical / Combination Meter / Trouble Codes.

    5. According to the GTS display, select a DTC that stored freeze frame data.

    6. Read the freeze frame data recorded when the DTC was stored.

  3. CLEAR FREEZE FRAME DATA

    Note

    Clearing the DTCs will also clear the freeze frame data.


    1. Connect the GTS to the DLC3.

    2. Turn the power switch on (IG).

    3. Clear the DTCs and freeze frame data.

      Click here


      Body Electrical > Combination Meter > Clear DTCs
