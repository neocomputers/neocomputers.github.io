HEATED STEERING WHEEL SYSTEM SYSTEM DESCRIPTION


  1. HEATED STEERING WHEEL SYSTEM


    1. The heated steering wheel system heats the steering wheel assembly when the steering heater switch is operated.

    2. The heated steering wheel system uses a thermistor inside of the steering wheel assembly to detect the heater temperature and maintain the set temperature.

    3. The heated steering wheel timer function turns off the heater after a predetermined period of time.

  2. HEATER CONTROLLER SYSTEM


    1. Operation description


      1. When the power switch is on (IG), pressing the steering heater switch illuminates the steering heater indicator light LED in the combination meter and current is output from the steering wheel heater control assembly to the steering wheel heater unit of the heated steering wheel system. Pressing the steering heater switch again turns off the LED and stops the current from being output.

      2. A thermostat is installed in the steering wheel heater unit as a safety mechanism.

      3. The steering heater indicator light LED in the combination meter will go off when either of the following occurs: 1) an open or short in the steering wheel heater unit thermistor continues for 2 seconds or more; or 2) the steering heater switch is pressed continuously for 10 seconds or more.

      4. The timer will turn off the heater 30 minutes after the steering heater switch was first turned on.

    2. Signal input / output description

      Signal Signal Name Function Signal Type
      Input Thermistor input Input of voltage corresponding to heater temperature Analog input
      Input Temperature setting input Input of voltage corresponding to temperature setting Analog input

    3. Safety function

      Content Operation
      When thermistor malfunction is detected Heater off
      When overheating (175°C (347°F)) of controller is detected Heater off
      When load short current (50 A or more) is detected Heater off
      When undervoltage (4.5 V) is detected Heater off
      OFF timer (30 minutes) After preset time of timer passes, heater off
      Reverse voltage protection Protection circuit operates
