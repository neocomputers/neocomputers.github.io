TOYOTA PARKING ASSIST-SENSOR SYSTEM, Diagnostic DTC:C1AEE

DTC Code DTC Name
C1AEE IPA Sensor Communication Circuit

DESCRIPTION

This DTC is stored when there is an open or short circuit in the communication line between the front side sensors and the ECU, or when there is a malfunction in a front side sensor.

DTC No. Detection Item DTC Detection Condition Trouble Area
C1AEE IPA Sensor Communication Circuit An open or short circuit in the communication line between the front side sensors and ECU or a malfunction in a front side sensor during initialization mode after the power switch is turned on (IG).

  • Front side ultrasonic sensor circuit

  • Harness or connector

  • Clearance warning ECU assembly

WIRING DIAGRAM

*a Front Side Ultrasonic Sensor RH
*b Front Side Ultrasonic Sensor LH
*c Clearance Warning ECU Assembly
