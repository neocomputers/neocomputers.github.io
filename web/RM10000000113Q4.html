MOTOR CABLE INSTALLATION

PROCEDURE


  1. INSTALL MOTOR CABLE

    CAUTION:

    Be sure to wear insulated gloves.


    1. Using an insulated tool, install the motor cable to the hybrid vehicle transaxle assembly with the 6 bolts.

      Torque:
      10 N*m  { 102 kgf*cm, 7 ft.*lbf }

      Note


      • Keep the motor cable terminals and their installation area free from foreign matter, water, etc.

      • Do not touch the waterproof seal or terminals of the motor cable.

    2. Engage the 2 claws to install a new terminal cap to the hybrid vehicle transaxle assembly.

      Note


      • Keep the terminal cap and its installation area free from foreign matter, water, etc.

      • Do not pinch the O-ring.

      • Check that the terminal cap is securely installed.

    3. Temporarily install the connector cover to the hybrid vehicle transaxle assembly with the 2 bolts.

    4. Tighten the 2 bolts to install the connector cover.

      Torque:
      10 N*m  { 102 kgf*cm, 7 ft.*lbf }
