THEFT DETERRENT SYSTEM, Diagnostic DTC:B2761

DTC Code DTC Name
B2761 Intrusion Sensor Internal Circuit Malfunction

DESCRIPTION

The intrusion sensor (theft warning ultrasonic sensor) conducts self-diagnosis immediately after power is supplied to the sensor (when the theft deterrent system is set).

If a problem is detected in the signals transmitted and received by the intrusion sensor (theft warning ultrasonic sensor), or if the transmission or reception circuits malfunction, the intrusion sensor (theft warning ultrasonic sensor) transmits a signal to the main body ECU (multiplex network body ECU). The main body ECU (multiplex network body ECU) then stores this DTC.

DTC No. Detection Item DTC Detection Condition Trouble Area
B2761 Intrusion Sensor Internal Circuit Malfunction Intrusion sensor (theft warning ultrasonic sensor) sensor malfunction signal output

  • Intrusion sensor (Theft warning ultrasonic sensor)

  • Main body ECU (Multiplex network body ECU)

CAUTION / NOTICE / HINT

Note

Before replacing the main body ECU (multiplex network body ECU), refer to Service Bulletin.
