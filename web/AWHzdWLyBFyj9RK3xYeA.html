PRE-CRASH SAFETY SYSTEM FREEZE FRAME DATA


  1. DESCRIPTION


    1. When a pre-crash safety system DTC is stored, the driving support ECU assembly stores the current vehicle (ECU or sensor) state as Freeze Frame Data.

  2. CHECK FREEZE FRAME DATA


    1. Connect the GTS to the DLC3.

    2. Turn the power switch on (IG).

    3. Turn the GTS on.

    4. Enter the following menus: Body Electrical / Pre-Crash 2 / Trouble Codes.


      Body Electrical > Pre-Crash 2 > Trouble Codes

    5. According to the GTS display, select a DTC that stored freeze frame data.

    6. Read the freeze frame data recorded when the DTC was stored.
