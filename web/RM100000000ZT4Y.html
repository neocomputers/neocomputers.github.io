PROCEDURE


  1. INSTALL FRONT BUMPER ASSEMBLY


    1. Move the front bumper assembly into position.

    2. Install in this Direction

      Temporarily install the front bumper assembly with the 2 bolts as shown in the illustration.

    3. Install the 4 clips.

    4. w/ Intuitive Parking Assist System:


      1. Connect the connector.

    5. w/ Toyota Safety Sense P:


      1. Connect the connector.

    6. Pull back the side of the front bumper assembly and connect the connector.

      Note

      Do not apply excessive force when pulling back the front bumper assembly.

      Tech Tips

      Use the same procedure for the RH side and LH side.

    7. Install in this Direction

      Engage the 3 claws as shown in the illustration.

      Tech Tips

      Use the same procedure for the RH side and LH side.

    8. Install the 12 screws.

    9. *1 Pin Hold Clip
      Install in this Direction

      Install the front bumper assembly with the 2 pin hold clips as shown in the illustration.

      Tech Tips

      Use the same procedure for the RH side and LH side.

  2. INSTALL RADIATOR SUPPORT OPENING COVER


    1. Install in this Direction (1)
      Install in this Direction (2)

      Engage the 2 guides as shown in the illustration.

    2. Install the radiator support opening cover with the 7 clips.
