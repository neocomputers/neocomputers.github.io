OUTER REAR VIEW MIRROR GLASS INSTALLATION

CAUTION / NOTICE / HINT

Tech Tips


  • Use the same procedure for the RH side and LH side.

  • The following procedure is for the LH side.

PROCEDURE


  1. INSTALL OUTER MIRROR


    1. w/o Blind Spot Monitor System:


      1. Connect the connector.

    2. w/ Blind Spot Monitor System:


      1. Install in this Direction

        Engage the clamp.

      2. Engage the claw as shown in the illustration.

      3. Connect the 2 connectors.

    3. Engage the 4 claws to install the outer mirror.
