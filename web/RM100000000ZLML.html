    1. Remove the main body ECU (multiplex network body ECU) from the instrument panel junction block assembly.

      Click here

    2. Reconnect the instrument panel junction block assembly connectors.

    3. Measure the voltage and resistance according to the value(s) in the table below.

      Terminal No. (Symbol) Wiring Color Terminal Description Condition Specified Condition
      MB-11 (GND1) - Body ground - Ground Always Below 1 Ω

      MB-32 (IG) - Body ground - IG power supply Power switch off Below 1 V

      I18-6 (FLCY) - Body ground BR - Body ground Front door courtesy light switch (for LH) input Front door LH closed Pulse generation
      I18-27 (FRCY) - Body ground L - Body ground Front door courtesy light switch (for RH) input Front door RH open Below 1 V
      I18-27 (FRCY) - Body ground L - Body ground Front door courtesy light switch (for RH) input Front door RH closed Pulse generation

  2. CHECK CERTIFICATION ECU (SMART KEY ECU ASSEMBLY) (w/ Entry System Back Door Open Function)


    1. Disconnect the I1 certification ECU (smart key ECU assembly) connector.

    2. Measure the voltage and resistance according to the value(s) in the table below.

      Terminal No. (Symbol) Wiring Color Terminal Description Condition Specified Condition
      I1-4 (+B) - Body ground GR - Body ground Auxiliary battery power supply Power switch off 11 to 14 V
      I1-18 (E) - Body ground W-B - Body ground Ground Always Below 1 Ω

    3. Reconnect the I1 certification ECU (smart key ECU assembly) connector.

    4. Check for pulses according to the value(s) in the table below.

      Terminal No. (Symbol) Wiring Color Terminal Description Condition Specified Condition
      N54-26 (TSW5) - Body ground B - Body ground Back door opener switch input Back door opener switch assembly (open switch) off → on Below 1 V → Pulse generation

  3. CHECK DOUBLE LOCK DOOR CONTROL RELAY ASSEMBLY (w/ Double Locking System)


    1. Disconnect the I16 double lock door control relay assembly connector.

    2. Measure the voltage and resistance according to the value(s) in the table below.

      Terminal No. (Symbol) Wiring Color Terminal Description Condition Specified Condition
      I16-12 (+B) - Body ground R - Body ground Auxiliary battery power supply Power switch off 11 to 14 V
      I16-11 (CPUB) - Body ground P - Body ground Auxiliary battery power supply Power switch off 11 to 14 V
      I16-7 (GND) - Body ground LA - Body ground Ground Always Below 1 Ω

    3. Reconnect the I16 double lock door control relay assembly connector.

    4. Measure the voltage and check for pulses according to the value(s) in the table below.

      Terminal No. (Symbol) Wiring Color Terminal Description Condition Specified Condition
      I16-8 (ACTS) - Body ground LG - Body ground All door double lock motor set on output Double lock unset Below 1 V
      I16-8 (ACTS) - Body ground LG - Body ground All door double lock motor set on output Double lock set 11 to 14 V
      I16-1 (ACTR) - Body ground GR - Body ground All door double lock motor set off output Double lock set Below 1 V
      I16-1 (ACTR) - Body ground GR - Body ground All door double lock motor set off output Double lock unset 11 to 14 V
      I16-6 (DLPD) - Body ground G - Body ground Front RH double lock position switch input Double lock unset Pulse generation
      I16-6 (DLPD) - Body ground G - Body ground Front RH double lock position switch input Double lock set Below 1 V
      I16-5 (DLPP) - Body ground V - Body ground Front LH double lock position switch input Double lock unset Pulse generation
      I16-5 (DLPP) - Body ground V - Body ground Front LH double lock position switch input Double lock set Below 1 V
      I16-4 (DLPR) - Body ground B - Body ground Rear RH double lock position switch input Double lock unset Pulse generation
      I16-4 (DLPR) - Body ground B - Body ground Rear RH double lock position switch input Double lock set Below 1 V
      I16-3 (DLPL) - Body ground SB - Body ground Rear LH double lock position switch input Double lock unset Pulse generation
      I16-3 (DLPL) - Body ground SB - Body ground Rear LH double lock position switch input Double lock set Below 1 V
