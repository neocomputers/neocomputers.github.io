BACK DOOR LOCK INSTALLATION

PROCEDURE


  1. INSTALL BACK DOOR LOCK ASSEMBLY

    Tech Tips

    Make sure to remove the string before installing a new back door lock assembly.


    1. Apply MP grease to the sliding parts of the back door lock assembly.

    2. Using a T30 "TORX" socket wrench, install the back door lock assembly with the 2 collars and 2 screws.

      Torque:
      9.0 N*m  { 92 kgf*cm, 80 in.*lbf }

    3. Connect the connector.
