CRUISE CONTROL SYSTEM, Diagnostic DTC:P157800

DTC Code DTC Name
P157800 Brake System

DESCRIPTION

This DTC is output when the electronically controlled brake system has a problem. Check the electronically controlled brake system when this DTC P157800 is output.

DTC No. Detection Item DTC Detection Condition Trouble Area
P157800 Brake System When the power switch is on (IG) and the cruise control system is operating, a malfunction in the electronically controlled brake system is detected for 0.2 seconds or more.

  • Electronically controlled brake system

  • Hybrid vehicle control ECU

CAUTION / NOTICE / HINT

Note

Before replacing the hybrid vehicle control ECU, refer to Service Bulletin.

PROCEDURE


  1. CHECK FOR DTCS (ELECTRONICALLY CONTROLLED BRAKE SYSTEM)


    1. Connect the GTS to the DLC3.

    2. Turn the power switch on (IG).

    3. Turn the GTS on.

    4. Enter the following menus: Chassis / ABS/VSC/TRC / Trouble Codes.

    5. Check for DTCs.

      Click here


      Chassis > ABS/VSC/TRC > Trouble Codes

  2. CHECK FOR DTCS (CRUISE CONTROL SYSTEM)


    1. Connect the GTS to the DLC3.

    2. Turn the power switch on (IG).

    3. Clear the DTCs.

      Click here


      Powertrain > Cruise Control > Clear DTCs

    4. Perform the following to make sure that the DTC detection conditions are met.

      Tech Tips

      If the detection conditions are not met, the malfunction cannot be detected.


      1. Drive the vehicle at a speed for which cruise control system operation is possible.

      2. Turn the cruise control system on using the cruise control main switch (ON-OFF).

      3. Push the cruise control main switch to -SET to begin control of vehicle speed using the cruise control system.
