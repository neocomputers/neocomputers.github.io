GRILLE SHUTTER INSTALLATION

PROCEDURE


  1. INSTALL RADIATOR SHUTTER SUB-ASSEMBLY


    1. Install in this Direction

      Engage the 2 guides as shown in the illustration.

    2. Install the radiator shutter sub-assembly with the 3 bolts.

      Torque:
      5.5 N*m  { 56 kgf*cm, 49 in.*lbf }
    3. Install in this Direction

      Engage the 2 claws as shown in the illustration to install the cooler thermistor bracket.

    4. Engage the 3 clamp.

    5. Connect the connector.
