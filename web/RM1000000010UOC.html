LIGHTING SYSTEM Turn Signal Switch Circuit

DESCRIPTION

The combination meter assembly (meter circuit plate) receives the turn signal switch information and controls the turn signal lights.

WIRING DIAGRAM

*a Turn Signal Switch
*b Combination Meter Assembly (Meter Circuit Plate)
*c Headlight Dimmer Switch Assembly

PROCEDURE


  1. READ VALUE USING GTS


    1. Connect the GTS to the DLC3.

    2. Turn the power switch on (IG).

    3. Turn the GTS on.

    4. Enter the following menus: Body Electrical / Combination Meter / Data List.

    5. Read the Data List according to the display on the GTS.


      Body Electrical > Combination Meter > Data List
