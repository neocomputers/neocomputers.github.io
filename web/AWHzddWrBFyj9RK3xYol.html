BACK DOOR WEATHERSTRIP INSTALLATION

PROCEDURE


  1. INSTALL BACK DOOR WEATHERSTRIP


    1. Make sure to remove any non-drying sealant from the installation surfaces on the vehicle body.

      Note

      If there is any non-drying sealant remaining on the vehicle body, the back door weatherstrip may not be able to be securely installed and may fall off. Make sure to completely remove the non-drying sealant from both the interior side and exterior side installation surfaces on the vehicle body.

    2. Align the joint of a new back door weatherstrip with the back door lock striker and temporarily install the back door weatherstrip.

      *a Alignment mark (Yellow) *b Alignment mark (White)
      *c Joint - -
      Flange Position - -

    3. Align the alignment marks on the back door weatherstrip with the flanges on the vehicle body indicated by the arrows, and install the back door weatherstrip.

      Note


      • Make sure to position the alignment mark correctly during installation. Failure to do so may lead to water ingress.

      • After installation, check that the corners fit correctly.

      Tech Tips

      Make sure to install the parts of the back door weatherstrip near the joint and alignment mark shown in the illustration first, and then install the corners.
