CHARGE LID OPENER SYSTEM PRECAUTION


  1. PRECAUTION FOR DISCONNECTING CABLE FROM NEGATIVE AUXILIARY BATTERY TERMINAL

    Note

    When disconnecting the cable from the negative (-) auxiliary battery terminal, initialize the following systems after the cable is reconnected.

    System Name See Procedure
    Lane Departure Alert System (w/ Steering Control)

    Click here

    Intelligent Clearance Sonar System
    Parking Assist Monitor System
    Simple Intelligent Parking Assist System
    Power Door Lock Control System
    Pre-crash Safety System
    Adaptive High Beam System

    1. Charging port lid lock operation may be prohibited after the auxiliary battery has been replaced or the cable has been disconnected and reconnected to the negative (-) auxiliary battery terminal.

      Operate the charging port lid lock again to return the operation to normal.

  2. PRECAUTIONS FOR AUXILIARY BATTERY AND TRANSMITTER BATTERY BUILT INTO ELECTRICAL KEY TRANSMITTER SUB-ASSEMBLY


    1. When the doors are locked, power from the auxiliary battery is used to transmit radio waves. The auxiliary battery may become discharged if the vehicle remains parked for a long time. If the vehicle is not to be used for a long time, disconnect the cable from the negative (-) auxiliary battery terminal, set transmitter battery saving mode or cancel the entry and start system (for Entry Function).
