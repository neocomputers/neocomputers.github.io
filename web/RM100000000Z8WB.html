AIRBAG SYSTEM, Diagnostic DTC:B1653/35

DTC Code DTC Name
B1653/35 Seat Position Airbag Sensor Circuit Malfunction

DESCRIPTION

The seat position airbag sensor circuit consists of the airbag sensor assembly and seat position airbag sensor.

DTC B1653/35 is stored when a malfunction is detected in the seat position airbag sensor circuit.

DTC No. Detection Item DTC Detection Condition Trouble Area Test Mode / Check Mode
B1653/35 Seat Position Airbag Sensor Circuit Malfunction

  • The airbag sensor assembly detects a line short, short to ground or B+, or an open in the seat position airbag sensor circuit.

  • Seat position airbag sensor malfunction

  • Airbag sensor assembly malfunction

    for LHD:

  • Floor wire

  • Front No. 2 seat wire LH

  • Seat position airbag sensor

  • Airbag sensor assembly


    for RHD:

  • Floor wire

  • Front seat wire RH

  • Seat position airbag sensor

  • Airbag sensor assembly

 Does not apply to test/check mode
