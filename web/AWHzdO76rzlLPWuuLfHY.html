CAN COMMUNICATION SYSTEM FAIL-SAFE CHART


  1. FAIL-SAFE FUNCTION


    1. When communication fails in any of the CAN bus lines (communication lines), a fail-safe function(s) will operate. The fail-safe function that is specified for each system operates to prevent those systems from malfunctioning.

    2. The following table shows the effects on each system when communication is impossible. (For further details, see the pages for each system.)
