FRONT SEAT SIDE AIRBAG ASSEMBLY INSTALLATION

PROCEDURE


  1. INSTALL FRONT SEAT AIRBAG ASSEMBLY


    1. Install the front seat airbag assembly with 2 new nuts.

      Torque:
      5.5 N*m  { 56 kgf*cm, 49 in.*lbf }

      Note


      • Do not reuse the nuts.

      • Make sure that the front seatback frame sub-assembly is not deformed. If it is deformed, replace it with a new one.

    2. Engage the clamp.
