REAR LIGHT ASSEMBLY DISASSEMBLY

CAUTION / NOTICE / HINT

Tech Tips


  • Use the same procedure for the RH side and LH side.

  • The following procedure is for the LH side.

PROCEDURE


  1. REMOVE REAR COMBINATION PACKING


    1. Remove the rear combination packing.

      Note


      • Be sure to remove all traces of the old rear combination packing from the vehicle body.

      • Do not reuse the removed rear combination packing. Be sure to install a new rear combination packing to prevent water ingress.

  2. REMOVE REAR LIGHT GASKET


    1. Remove the 3 rear light gaskets.

      Note


      • Be sure to remove all traces of the old rear light gaskets from the vehicle body.

      • Do not reuse the removed rear light gaskets. Be sure to install new rear light gaskets to prevent water ingress.
