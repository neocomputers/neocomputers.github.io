ELECTRONICALLY CONTROLLED BRAKE SYSTEM TEST MODE PROCEDURE


  1. WARNING LIGHT AND INDICATOR LIGHT INITIAL CHECK


    1. When the power switch is turned on (IG), check that the ABS warning, brake warning / red (malfunction), brake warning / yellow (minor malfunction), VSC OFF indicator and slip indicator lights all come on approximately 3 seconds.

      Tech Tips


      • When the brake fluid level is low, the brake warning light / red (malfunction) comes on.

      • If the skid control ECU (brake booster with master cylinder assembly) stores any DTCs, the ABS warning, brake warning / red (malfunction), brake warning / yellow (minor malfunction) and slip indicator lights will come on.

      • If any of the indicators remains on or does not come on, proceed to troubleshooting for the light circuits listed below.

  2. SENSOR CHECK USING TEST MODE (SIGNAL CHECK)

    Note

    Before performing the master cylinder pressure sensor check, perform linear solenoid valve offset learning and ABS holding solenoid valve learning.

    Tech Tips


    • Signals related to the electronically controlled brake system can be inspected by performing a Test Mode (Signal Check) inspection. During the inspection, the display of items determined normal by the skid control ECU (brake booster with master cylinder assembly) changes from incomplete to complete.

    • During Test Mode (Signal Check), the VSC system does not operate regardless of whether the system is normal or a malfunction is detected.

    • If a sensor is malfunctioning, ABS does not operate and the ABS warning, brake warning / yellow (minor malfunction) and slip indicator lights illuminate.

    • When entering test mode, the skid control ECU (brake booster with master cylinder assembly) communicates with the driving support ECU assembly to judge whether the vehicle is equipped with the pre-crash safety system. Therefore, do not exit test mode within 5 seconds of entering test mode (w/ Pre-crash Safety System).


    1. Procedure to Enter Test Mode (Signal Check)


      1. Turn the power switch off.

      2. Check that the steering wheel is centered.

      3. Check that park (P) is selected.

      4. Connect the GTS to the DLC3.

      5. Turn the power switch on (IG).

      6. Turn the GTS on.

      7. Switch the skid control ECU (brake booster with master cylinder assembly) to Test Mode (Signal Check) using the GTS. Enter the following menus: Chassis / ABS/VSC/TRC / Utility / Signal Check.


        Chassis > ABS/VSC/TRC > Utility
        Tester Display
        Signal Check

        Tech Tips

        Do not exit test mode within 5 seconds of entering test mode. If test mode is exited within 5 seconds of entering test mode, DTC U1104 may be stored. If DTC U1104 is output after exiting test mode, enter test mode again, wait at least 5 seconds, then recheck for DTCs (w/ Pre-crash Safety System).

    2. Test Mode (Signal Check) Display Check


      1. Check that the ABS warning, brake warning / yellow (minor malfunction) and slip indicator lights come on for several seconds and then blink in the Test Mode pattern.

        Tech Tips

        If the ABS warning light, brake warning light / yellow (minor malfunction) or slip indicator light remains illuminated or does not illuminate when Test Mode (Signal Check) is entered, a component or wire harness may be malfunctioning.

    3. Acceleration Sensor Check


      1. Keep the vehicle stationary on a level surface for 2 seconds or more.

        Tech Tips


        • The ABS warning light remains blinking.

        • If the acceleration sensor is normal and the above step is performed when Test Mode (Signal Check) is entered, the acceleration sensor check will complete normally.

        • The acceleration sensor check can be performed by following the master cylinder pressure sensor check procedure below.

    4. Master Cylinder Pressure Sensor Check

      Note

      Before performing the master cylinder pressure sensor check, perform linear solenoid valve offset learning and ABS holding solenoid valve learning.


      1. Leave the vehicle in a stationary condition and release the brake pedal for 1 second or more, and quickly and continuously depress the brake pedal with a force greater than 98 N (10 kgf, 22.0 lbf) for 1 second.

      2. Check that the ABS warning light remains on for 3 seconds.

        Tech Tips


        • Confirm that the ABS warning light comes on.

        • While the ABS warning light remains on, continue to depress the brake pedal with a force of 98 N (10 kgf, 22.0 lbf) or more.

        • The ABS warning light comes on for 3 seconds every time the preceding brake pedal operation is performed.

    5. Speed Sensor Check

      Note

      Before performing the speed sensor check, complete the acceleration sensor and master cylinder pressure sensor checks.


      1. With the steering wheel held straight, accelerate the vehicle to a speed of 45 km/h (28 mph) or more without spinning the wheels.

        Note

        The speed sensor check may not complete if the speed sensor check is started while turning the steering wheel or spinning the wheels.

      2. Check that the ABS warning light goes off.

        Note

        If the sensor check has not completed, the ABS warning light will blink while the vehicle is being driven and the ABS will not operate.

      3. Stop the vehicle.

    6. End of Sensor Check


      1. When the sensor checks have completed, the ABS warning light goes off while the vehicle is being driven, and blinks in the Test Mode pattern while the vehicle is stopped.

        Note


        • When the acceleration sensor, speed sensor and master cylinder pressure sensor checks are complete, the sensor check is complete.

        • If the sensor checks have not completed, the ABS warning light will remain blinking while the vehicle is being driven, and the ABS will not operate.

        • If any malfunctions are detected during Test Mode (Signal Check), the ABS warning light remains illuminated.

        • If any DTCs are output or if Test Mode (Signal Check) items do not complete even after repeated attempts, repair or replace the malfunctioning part.

    7. End of Test Mode (Signal Check)


      1. Turn the power switch off and disconnect the GTS.
