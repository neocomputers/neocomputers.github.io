LANE DEPARTURE ALERT SYSTEM(w/ Steering Control) CUSTOMIZE PARAMETERS


  1. CUSTOMIZE LANE DEPARTURE ALERT SYSTEM

    Note


    • When the customer requests a change in a function, first make sure that the function can be customized.

    • Be sure to make a note of the current settings before customizing.

    • When troubleshooting a function, first make sure that the function is set to the default setting.

    Tech Tips

    The following items can be customized.


    1. Customizing with the Multi-information display


      1. Turn the power switch on (IG).

      2. Enter the following menus: Settings Tab / Settings / Lane Departure Alert Setup

      3. Select the setting by referring to the table below.

      4. Change the settings of the lane departure alert system using the steering pad switch assembly.

        Tech Tips

        Each item is displayed on the "Setting" screen on the multi-information display.

        Lane Departure Alert System
        Display Content Setting Default
        Steering Assist Steering control function On/Off On
        Warning Sensitivity Timing of lane departure alert High/Standard Standard
        Vehicle Sway Warning Vehicle sway warning function On/Off On
        Sway Sensitivity Sway warning sensitivity High/Standard/Low Standard
