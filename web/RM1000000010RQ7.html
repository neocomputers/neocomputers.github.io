ADAPTIVE HIGH BEAM SYSTEM, Diagnostic DTC:B2440, B2441

DTC Code DTC Name
B2440 Lost Communication with AHS EDU LH Module
B2441 Lost Communication with AHS EDU RH Module

DESCRIPTION

The No. 1 headlight ECU sub-assembly communicates with the headlight light control ECU sub-assembly via LIN communication. When a communication error between the No. 1 headlight ECU sub-assembly and headlight light control ECU sub-assembly is detected, the No. 1 headlight ECU sub-assembly LH stores DTC B2440 and B2441.

DTC No. Detection Item DTC Detection Condition Trouble Area
B2440 Lost Communication with AHS EDU LH Module Headlight light control ECU sub-assembly LH communication error

  • Headlight unit assembly LH

  • Headlight light control ECU sub-assembly LH

  • No. 1 headlight ECU sub-assembly LH
B2441 Lost Communication with AHS EDU RH Module Headlight light control ECU sub-assembly RH communication error

  • Headlight unit assembly RH

  • Headlight light control ECU sub-assembly RH

  • No. 1 headlight ECU sub-assembly LH

  • No. 1 headlight ECU sub-assembly RH

  • Harness or connector

CAUTION / NOTICE / HINT

Note

If the No. 1 headlight ECU sub-assembly LH has been replaced, it is necessary to synchronize the vehicle information and initialize the No. 1 headlight ECU sub-assembly LH.
