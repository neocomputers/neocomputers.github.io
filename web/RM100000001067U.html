CRANKSHAFT POSITION SENSOR INSTALLATION

PROCEDURE


  1. INSTALL CRANKSHAFT POSITION SENSOR


    1. Apply a light coat of engine oil to the O-ring.

      Note

      If reusing the crankshaft position sensor, check the O-ring.

    2. Install the crankshaft position sensor to the cylinder block sub-assembly with the bolt.

      Torque:
      10 N*m  { 102 kgf*cm, 7 ft.*lbf }

      Note


      • Make sure that the O-ring is not cracked or moved out of place when installing crankshaft position sensor.

      • If the crankshaft position sensor has been struck or dropped, replace it.

    3. Connect the crankshaft position sensor connector.

  2. INSPECT FOR OIL LEAK
