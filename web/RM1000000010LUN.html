TOYOTA PARKING ASSIST-SENSOR SYSTEM, Diagnostic DTC:C1AE7

DTC Code DTC Name
C1AE7 Rear Left Center Sensor Malfunction

DESCRIPTION

The rear center ultrasonic sensor LH is installed to the rear bumper. The clearance warning ECU assembly detects obstacles based on signals received from the rear center ultrasonic sensor LH. If the rear center ultrasonic sensor LH has an open circuit or other malfunction, it will not function normally.

DTC No. Detection Item DTC Detection Condition Trouble Area
C1AE7 Rear Left Center Sensor Malfunction A malfunction of the rear center ultrasonic sensor LH.

  • Rear center ultrasonic sensor LH

  • Clearance warning ECU assembly

CAUTION / NOTICE / HINT

Note

If DTCs are output after repairs, turn the power switch on (IG) and the TOYOTA parking assist-sensor system on. Then clear the DTCs.
