DRIVING SUPPORT ECU INSTALLATION

PROCEDURE


  1. INSTALL DRIVING SUPPORT ECU ASSEMBLY


    1. Connect the connector.

    2. Engage the guide.

    3. Install the driving support ECU assembly with the nut.

      Torque:
      5.5 N*m  { 56 kgf*cm, 49 in.*lbf }

      Note

      If the driving support ECU assembly has been struck or dropped, replace the driving support ECU assembly with a new one.
