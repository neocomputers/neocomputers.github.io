DISCHARGE TEMPERATURE SENSOR INSTALLATION

  1. INSTALL DISCHARGE TEMPERATURE SENSOR


    1. Install the discharge temperature sensor with the piping clamp.

  2. INSTALL COOLER PACKING


    1. Remove any remaining cooler packing from the discharge temperature sensor and No. 1 discharge tube.

    2. Remove the release paper from a new cooler packing.

    3. for LHD:
