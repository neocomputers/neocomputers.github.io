HV BATTERY STACK INSTALLATION

PROCEDURE


  1. INSTALL NO. 5 HV SUPPLY STACK SUB-ASSEMBLY

    CAUTION:

    Be sure to wear insulated gloves and protective goggles.


    1. Install the No. 5 HV supply stack sub-assembly with the 4 nuts.

      Torque:
      19 N*m  { 194 kgf*cm, 14 ft.*lbf }

  2. INSTALL NO. 4 HV SUPPLY STACK SUB-ASSEMBLY

    CAUTION:

    Be sure to wear insulated gloves and protective goggles.


    1. Install the No. 4 HV supply stack sub-assembly with the 4 nuts.

      Torque:
      19 N*m  { 194 kgf*cm, 14 ft.*lbf }

  3. INSTALL NO. 3 HV SUPPLY STACK SUB-ASSEMBLY

    CAUTION:

    Be sure to wear insulated gloves and protective goggles.


    1. Install the No. 3 HV supply stack sub-assembly with the 4 nuts.

      Torque:
      19 N*m  { 194 kgf*cm, 14 ft.*lbf }

  4. INSTALL NO. 2 HV SUPPLY STACK SUB-ASSEMBLY

    CAUTION:

    Be sure to wear insulated gloves and protective goggles.


    1. Install the No. 2 HV supply stack sub-assembly with the 4 nuts.

      Torque:
      19 N*m  { 194 kgf*cm, 14 ft.*lbf }

  5. INSTALL NO. 1 HV SUPPLY STACK SUB-ASSEMBLY

    CAUTION:

    Be sure to wear insulated gloves and protective goggles.


    1. Install the No. 1 HV supply stack sub-assembly with the 4 nuts.

      Torque:
      19 N*m  { 194 kgf*cm, 14 ft.*lbf }

  6. INSTALL NO. 1 HV BATTERY SHIELD REINFORCEMENT

    CAUTION:

    Be sure to wear insulated gloves and protective goggles.


    1. Install the 4 No. 1 HV battery shield reinforcements to the HV battery with the 16 bolts.

      Torque:
      7.5 N*m  { 76 kgf*cm, 66 in.*lbf }

  7. INSTALL NO. 7 HYBRID BATTERY INTAKE DUCT

    CAUTION:

    Be sure to wear insulated gloves and protective goggles.


    1. Engage each claw to install the 5 No. 7 hybrid battery intake ducts.

    2. Engage the 2 claws of 2 hybrid battery thermistors (sensor portion) to connect the hybrid battery thermistor to the No. 7 hybrid battery intake duct.

  8. INSTALL NO. 1 HV BATTERY PROTECTOR

    CAUTION:

    Be sure to wear insulated gloves and protective goggles.


    1. Install the No. 1 HV battery protector to the HV battery with the bolt.

      Torque:
      7.5 N*m  { 76 kgf*cm, 66 in.*lbf }

  9. INSTALL NO. 1 HYBRID BATTERY PACK WIRE

    CAUTION:

    Be sure to wear insulated gloves and protective goggles.


    1. Install the No. 1 hybrid battery pack wire to the HV battery with the 3 bolts.

      Torque:
      7.5 N*m  { 76 kgf*cm, 66 in.*lbf }

    2. Engage the 6 clamps.

    3. Connect the 7 connectors.

    4. Connect the 2 connectors.

      Note

      Make sure that the connectors are connected securely.

  10. INSTALL NO. 1 HV BATTERY HOSE

    CAUTION:

    Be sure to wear insulated gloves and protective goggles.


    1. Engage 10 claws to install the No. 1 HV battery hose.

    2. Install the 10 clips.

  11. INSTALL NO. 4 HYBRID BATTERY INTAKE DUCT

    CAUTION:

    Be sure to wear insulated gloves and protective goggles.


    1. Install the 5 No. 4 hybrid battery intake ducts to the HV battery with the 5 clips.

  12. INSTALL NO. 1 HYBRID BATTERY EXHAUST DUCT

    CAUTION:

    Be sure to wear insulated gloves and protective goggles.


    1. Engage the 2 claws to install the No. 1 hybrid battery exhaust duct to the HV battery.

  13. INSTALL NO. 2 BATTERY FRAME

    CAUTION:

    Be sure to wear insulated gloves and protective goggles.


    1. Install the No. 2 battery frame with the 2 nuts.

      Torque:
      7.5 N*m  { 76 kgf*cm, 66 in.*lbf }

  14. INSTALL NO. 1 BATTERY FRAME

    CAUTION:

    Be sure to wear insulated gloves and protective goggles.


    1. Install the No. 1 battery frame with the 3 nuts.

      Torque:
      7.5 N*m  { 76 kgf*cm, 66 in.*lbf }

  15. CONNECT WIRE HARNESS

    CAUTION:

    Be sure to wear insulated gloves and protective goggles.


    1. Engage the 4 clamps.

    2. Install the fuse box bracket with the 2 nuts.

      Torque:
      7.5 N*m  { 76 kgf*cm, 66 in.*lbf }

    3. Engage the clamp (A) to install the wire harness protector.

    4. Engage the 6 clamps (B).

    5. Close the wire harness protector.

    6. Install the service plug bracket with the 2 nuts.

      Torque:
      7.5 N*m  { 76 kgf*cm, 66 in.*lbf }

    7. Install the nut.

      Torque:
      7.5 N*m  { 76 kgf*cm, 66 in.*lbf }

    8. Engage the 3 clamps.

    9. Connect the connector.

      Note

      Make sure that the connector is connected securely.

    10. Engage the 6 clamps.

    11. Connect the connector.

    12. Engage the 3 clamps.
