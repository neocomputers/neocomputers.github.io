AIR CONDITIONING ACCESSORY ASSEMBLY INSTALLATION

PROCEDURE


  1. INSTALL NO. 1 AIR CONDITIONING ACCESSORY ASSEMBLY


    1. Remove the vinyl tape from the No. 1 air conditioning accessory assembly.

    2. Sufficiently apply compressor oil to a new O-ring and the fitting surface of the No. 2 connector tube.

    3. Install the O-ring to the No. 2 connector tube.

      Note

      Keep the O-ring and O-ring fitting surface free of foreign matter.

    4. Install the No. 1 air conditioning accessory assembly with the bolt.

      Torque:
      9.8 N*m  { 100 kgf*cm, 87 in.*lbf }

  2. INSTALL COOLER REFRIGERANT LIQUID PIPE A

  3. INSTALL NO. 1 RECEIVER TANK BRACKET WITH NO. 5 COOLER BRACKET


    1. Install the No. 1 receiver tank bracket with No. 5 cooler bracket with the 6 bolts.

      Bolt (A) Bolt (B)
      Torque:
      Bolt (A)
      9.8 N*m  { 100 kgf*cm, 87 in.*lbf }
      Bolt (B)
      3.4 N*m  { 35 kgf*cm, 30 in.*lbf }

      Tech Tips

      Make sure that the wire harnesses are routed as shown in the illustration.

      *1 High Pressure Magnetic Valve *2 No. 1 Air Conditioning Accessory Assembly

    2. Engage the clamp.

    3. Tighten the bolt.

      Torque:
      9.8 N*m  { 100 kgf*cm, 87 in.*lbf }

  4. INSTALL NO. 6 COOLER BRACKET

    Click here

  5. INSTALL AIR CONDITIONING RECEIVER TANK WITH BRACKET


    1. Remove the vinyl tape from the air conditioning receiver tank.

    2. Sufficiently apply compressor oil to a new O-ring and the fitting surface of the air conditioning receiver tank.

      Compressor Oil
      ND-OIL 11 or equivalent

    3. Install the O-ring to the No. 1 connector tube.

      Note

      Keep the O-ring and O-ring fitting surface free of foreign matter.

    4. Install in this Direction

      Temporarily install the air conditioning receiver tank with bracket as shown in the illustration.

    5. Temporarily install the 4 bolts.

    6. Bolt (A)
      Bolt (B)
      Bolt (C)

      Tighten the bolt (A).

      Torque:
      9.8 N*m  { 100 kgf*cm, 87 in.*lbf }

    7. Tighten the bolt (B).

      Torque:
      3.4 N*m  { 35 kgf*cm, 30 in.*lbf }

    8. Tighten the 2 bolts (C) to install the air conditioning receiver tank with bracket.

      Torque:
      9.8 N*m  { 100 kgf*cm, 87 in.*lbf }

    9. Engage the 2 clamps.
