UPPER INSTRUMENT PANEL REASSEMBLY

PROCEDURE


  1. INSTALL INSTRUMENT PANEL CUSHION


    1. Clean the upper instrument panel assembly surface.


      1. Remove the double-sided tape from the upper instrument panel assembly.

      2. Wipe off any tape adhesive residue.

    2. Remove the release paper from a new instrument panel cushion.

      Tech Tips

      After removing the release paper, keep the exposed adhesive free from foreign matter.

    3. *a Marking Line

      Align the ends of the instrument panel cushion with the marking lines on the upper instrument panel assembly and install the instrument panel cushion as shown in the illustration.

  2. INSTALL SPARE SWITCH HOLE COVER (for RHD)


    1. Engage the 2 claws to install the spare switch hole cover.

  3. INSTALL NO. 2 INSTRUMENT PANEL WIRE


    1. Engage the 10 clamps to install the No. 2 instrument panel wire.

  4. INSTALL SIDE DEFROSTER NOZZLE RH


    1. Engage the 3 claws to install the side defroster nozzle RH.

  5. INSTALL SIDE DEFROSTER NOZZLE ASSEMBLY RH


    1. Engage the 2 guides.

    2. Install the side defroster nozzle assembly RH with the 2 screws <A>.

  6. INSTALL SIDE DEFROSTER NOZZLE LH


    1. Engage the 3 claws to install the side defroster nozzle LH.

  7. INSTALL SIDE DEFROSTER NOZZLE ASSEMBLY LH


    1. Engage the 2 guides.

    2. Install the side defroster nozzle assembly LH with the 2 screws <A>.
