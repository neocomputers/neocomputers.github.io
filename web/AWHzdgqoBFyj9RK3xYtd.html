AUTOMATIC LIGHT CONTROL SENSOR ON-VEHICLE INSPECTION

PROCEDURE


  1. INSPECT AUTOMATIC LIGHT CONTROL SENSOR


    1. *a

      Front view of wire harness connector

      (to Automatic Light Control Sensor)

      Disconnect the G1 automatic light control sensor connector.

    2. Measure the voltage and resistance according to the value(s) in the table below.

      Standard Voltage
      Tester Connection Condition Specified Condition
      G1-1 (CLTB) - G1-2 (CLTE) Power switch off Below 1 V
      Power switch on (IG) 11 to 14 V
      Standard Resistance
      Tester Connection Condition Specified Condition
      G1-2 (CLTE) - Body ground Always Below 1 Ω

      If the result is not as specified, there may be a malfunction on the wire harness side.

    3. Connect the G1 automatic light control sensor connector.

    4. Connect an oscilloscope to the automatic light control sensor connector.

    5. Check the waveform.
