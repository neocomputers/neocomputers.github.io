NAVIGATION SYSTEM(for Navigation Receiver Type), Diagnostic DTC:B1324, B1325

DTC Code DTC Name
B1324 Lost Communication with Meter
B1325 Lost Communication with HUD

DESCRIPTION

These DTCs are stored when communication between the navigation receiver assembly and meter circuit plate or combination meter mirror ECU* is not possible.

DTC No. Detection Item DTC Detection Condition Trouble Area
B1324 Lost Communication with Meter After the navigation receiver assembly receives a registration information signal, which is sent by the meter circuit plate when the power switch is turned on (IG), 1 or more times, the navigation receiver assembly does not receive the signal for 30 seconds or more

  • Local bus communication line

  • Meter circuit plate power source circuit

  • Meter circuit plate

  • Navigation receiver assembly

  • Harness or connector
B1325 Lost Communication with HUD After the navigation receiver assembly receives a registration information signal, which is sent by the combination meter mirror ECU when the power switch is turned on (IG), 1 or more times, the navigation receiver assembly does not receive the signal for 30 seconds or more*

  • Local bus communication line

  • Combination meter mirror ECU power source circuit

  • Combination meter mirror ECU

  • Navigation receiver assembly

  • Harness or connector

  • *: w/ Headup Display System

Tech Tips

The navigation receiver assembly is the master unit.

CAUTION / NOTICE / HINT

Note
