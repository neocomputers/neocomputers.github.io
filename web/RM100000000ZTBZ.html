THEFT DETERRENT SYSTEM Glass Breakage Sensor Circuit

DESCRIPTION

When the main body ECU (multiplex network body ECU) detects that the glass breakage sensor (back door glass or back window fix glass) is broken, the theft deterrent system switches from the armed state to the alarm sounding state.

WIRING DIAGRAM

*a Glass Breakage Sensor (Back Window Fix Glass)
*b Glass Breakage Sensor (Back Door Glass)
*c Main Body ECU (Multiplex Network Body ECU)

PROCEDURE


  1. READ VALUE USING GTS (SEALED GLAS BRAK SEN)


    1. Connect the GTS to the DLC3.

    2. Turn the power switch on (IG).

    3. Turn the GTS on.

    4. Enter the following menus: Body Electrical / Main Body / Data List.

    5. Read the Data List according to the display on the GTS.


      Body Electrical > Main Body > Data List
      Tester Display Measurement Item Range Normal Condition Diagnostic Note
      Sealed Glas Brak Sen Glass breakage sensor connection With or Without

      With: Glass breakage sensor connected

      Without: Glass breakage sensor not connected
