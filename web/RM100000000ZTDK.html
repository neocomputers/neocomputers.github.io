FRONT SEAT INNER BELT ASSEMBLY INSTALLATION

CAUTION / NOTICE / HINT

Tech Tips


  • Use the same procedure for the RHD and LHD.

  • The following procedure is for the LHD.

PROCEDURE


  1. INSTALL FRONT SEAT INNER BELT ASSEMBLY (for Driver Side)


    1. Install in this Direction

      Install the front seat belt anchor plate as shown in the illustration.

    2. for Manual Seat:


      1. *a Protruding Part

        Install the front seat inner belt assembly with the nut.

        Torque:
        42 N*m  { 428 kgf*cm, 31 ft.*lbf }

        Note

        Do not allow the anchor part of the front seat inner belt assembly to overlap the protruding part of the separate type front seat cushion spring assembly.

    3. for Power Seat:


      1. *a Protruding Part

        Install the front seat inner belt assembly with the nut.

        Torque:
        42 N*m  { 428 kgf*cm, 31 ft.*lbf }

        Note

        Do not allow the anchor part of the front seat inner belt assembly to overlap the protruding part of the separate type front seat cushion spring assembly.

    4. Engage each clamp.

    5. Connect each connector.

  2. INSTALL FRONT SEAT INNER BELT ASSEMBLY (for Front Passenger Side)


    1. Install in this Direction

      Install the front seat belt anchor plate as shown in the illustration.

    2. *a Protruding Part

      Install the front seat inner belt assembly with the nut.

      Torque:
      42 N*m  { 428 kgf*cm, 31 ft.*lbf }

      Note

      Do not allow the anchor part of the front seat inner belt assembly to overlap the protruding part of the separate type front seat cushion spring assembly.

    3. Engage each clamp.

    4. Connect each connector.
