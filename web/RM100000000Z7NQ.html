FRONT SEAT ASSEMBLY(for Manual Seat) REASSEMBLY

CAUTION / NOTICE / HINT

CAUTION:

Wear protective gloves. Sharp areas on the parts may injure your hands.

Tech Tips


  • Use the same procedure for RHD and LHD vehicles.

  • The following procedure is for LHD vehicles.

  • Use the same procedure for the RH side and LH side.

  • The following procedure is for the LH side.

PROCEDURE


  1. INSTALL VERTICAL ADJUSTER BRACKET COVER (for Driver Side)


    1. Engage the claw to install the vertical adjuster bracket cover to the front vertical adjuster brake sub-assembly.

  2. INSTALL FRONT SEAT VERTICAL ADJUSTER ASSEMBLY (for Driver Side)


    1. Install the front seat vertical adjuster assembly.


      1. Install the front vertical adjuster brake sub-assembly.

        Note

        Make sure to insert the stud bolt of the front vertical adjuster brake sub-assembly into the hole of the front seat adjuster assembly as shown in the illustration.

      2. Install the vertical adjuster spacer.

      3. Install the vertical adjuster plate with the 3 nuts.

        Torque:
        5.0 N*m  { 51 kgf*cm, 44 in.*lbf }

        Note

        Tighten the nuts in the order shown in the illustration.

  3. INSTALL SEAT TRACK ADJUSTING HANDLE


    1. Engage the 2 claws to install the seat track adjusting handle to the front seat adjuster assembly.

  4. INSTALL FRONT SEAT CUSHION SPRING SUB-ASSEMBLY


    1. Engage the 6 hooks to install the front seat cushion spring sub-assembly to the front seat adjuster assembly.

  5. INSTALL FRONT SEAT CUSHION WIRE HARNESS HOLDER


    1. Engage the claw to install the front seat cushion wire harness holder.

    2. Install the 2 screws.

  6. INSTALL FRONT SEAT WIRE RH (for Front Passenger Side)


    1. w/ Occupant Classification System:


      1. Connect each connector and engage each clamp to install the front seat wire RH.

  7. INSTALL FRONT SEAT NO. 2 WIRE LH (for Driver Side)


    1. w/ Airbag Cut Off Switch:


      1. Engage the claw.

      2. Engage the clamp to install the front seat No. 2 wire LH.

  8. INSTALL FRONT SEAT WIRE LH (for Driver Side)


    1. Connect each connector and engage each clamp to install the front seat wire LH.

  9. INSTALL FRONT SEAT LOWER CUSHION SHIELD LH (for Driver Side)


    1. *a Hook
      *b Guide

      Engage the claw and guide.

    2. Engage the hook to install the front seat lower cushion shield LH.

  10. INSTALL FRONT SEAT LOWER CUSHION SHIELD RH (for Driver Side)


    1. *a Hook
      *b Guide

      Engage the claw and guide.

    2. Engage the hook to install the front seat lower cushion shield RH.

  11. INSTALL LH SEAT RECLINING ADJUSTER INSIDE COVER LH (for Driver Side)


    1. Engage the 4 claws to install the LH seat reclining adjuster inside cover LH.

    2. Engage the claw.

  12. INSTALL LH SEAT RECLINING ADJUSTER INSIDE COVER RH (for Driver Side)


    1. Engage the 4 claws to install the LH seat reclining adjuster inside cover RH.

  13. INSTALL RH SEAT RECLINING ADJUSTER INSIDE COVER LH (for Front Passenger Side)


    1. Engage the 4 claws to install the RH seat reclining adjuster inside cover LH.

    2. w/ Occupant Classification System:


      1. Engage the clamp.

  14. INSTALL RH SEAT RECLINING ADJUSTER INSIDE COVER RH (for Front Passenger Side)


    1. Engage the 4 claws to install the RH seat reclining adjuster inside cover RH.

  15. INSTALL FRONT SEAT CUSHION AIRBAG ASSEMBLY RH (for Front Passenger Side)


    1. w/ Occupant Classification System:

  17. INSTALL SEPARATE TYPE FRONT SEAT CUSHION COVER


    1. Engage the 13 claws to install the separate type front seat cushion cover to the separate type front seat cushion pad.

  18. INSTALL SEPARATE TYPE FRONT SEAT CUSHION COVER WITH PAD


    1. Engage the 10 hooks to install the separate type front seat cushion cover with pad.

    2. Engage the 2 hooks.

    3. for Driver Side:


      1. Engage the clamp.

      2. Connect the connector.

    4. for Front Passenger Side:


      1. Engage the claw and 4 clamps.

        Tech Tips

        Engage the claw first.

  19. INSTALL FRONT SEAT NO. 2 WIRE (for Driver Side)


    1. Engage the clamp to install the front seat No. 2 wire.

  20. INSTALL FRONT SEATBACK HOOK


    1. Install the 2 front seatback hooks to the front seatback frame sub-assembly.

  21. INSTALL FRONT SEATBACK EDGE PROTECTOR (for Front Passenger Side)


    1. Install the 2 front seatback edge protectors to the front seatback spring sub-assembly RH.

  22. INSTALL FRONT SEATBACK EDGE PROTECTOR (for Driver Side)


    1. Install the 2 front seatback edge protectors to the lumbar support adjuster assembly LH.

  23. INSTALL FRONT SEATBACK SPRING SUB-ASSEMBLY RH (for Front Passenger Side)


    1. Install in this direction

      Install the front seatback spring sub-assembly RH to the front seatback frame sub-assembly as shown in the illustration.

    2. Engage the 2 claws to install the 2 front seatback edge protectors to the front seatback frame sub-assembly.

  24. INSTALL LUMBAR SUPPORT ADJUSTER ASSEMBLY LH (for Driver Side)

  27. INSTALL SEPARATE TYPE FRONT SEATBACK COVER


    1. Engage the 17 claws to install the separate type front seatback cover to the separate type front seatback pad.

  28. INSTALL SEPARATE TYPE FRONT SEATBACK COVER WITH PAD


    1. Install the separate type front seatback cover with pad.

  29. INSTALL FRONT SEAT HEADREST SUPPORT


    1. Engage the 4 claws to install the 2 front seat headrest supports.

    2. w/ Occupant Classification System:


      1. *1 Seat Cover Hanger
        *a Bracket
        Install in this direction

        Slide the bracket as shown in the illustration to engage the hook and connect the bracket to the seat cover hanger.

        Note


        • For vehicles with a front seat airbag assembly, the separate type front seatback cover with pad must be securely installed. Otherwise, the front seat airbag assembly may not deploy properly.

        • Make sure that the strap is not twisted after connecting the bracket to the seat cover hanger.

        • Install the bracket securely.

      2. *1 Seatback Cover Hook
        *a Pin

        Insert the seatback cover hook and push in the pin to install it as shown in the illustration.

      3. Install in this direction

        Engage the hook as shown in the illustration.

    3. Close the 2 fasteners.

    4. Engage the clamp.

    5. Engage the 3 hooks.

  30. INSTALL SEPARATE TYPE FRONT SEATBACK ASSEMBLY


    1. Engage the 4 guides.

    2. Install the separate type front seatback assembly to the separate type front seat cushion assembly with the 4 bolts.

      Torque:
      42 N*m  { 428 kgf*cm, 31 ft.*lbf }

    3. Engage the claw and 4 clamps to install the front seat airbag assembly wire harness.

      Tech Tips

      Engage the claw first.

    4. for Driver Side:


      1. Engage the clamp.

      2. Connect the connector.

      3. Engage the clamp.

      4. Connect the connector.

    5. for Front Passenger Side:


      1. Engage the clamp.

      2. Connect the connector.

    6. Engage the 2 hooks.

    7. Pass the separate type front seatback cover through the grooves of the LH seat reclining adjuster inside cover LH and LH seat reclining adjuster inside cover RH.

  31. INSTALL FRONT SEAT INNER CUSHION SHIELD (for Driver Side)


    1. Install in this direction

      Engage the 2 claws and 2 guides as shown in the illustration.

    2. Engage the 2 claws to install the front seat inner cushion shield.

  38. INSTALL RECLINING HINGE COVER

  39. INSTALL VERTICAL ADJUSTING HANDLE (for Driver Side)
