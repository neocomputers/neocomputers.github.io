LUMBAR SUPPORT ADJUSTER ASSEMBLY(for Manual Seat) INSTALLATION

CAUTION / NOTICE / HINT

CAUTION:

Wear protective gloves. Sharp areas on the parts may injure your hands.

Tech Tips


  • Lumbar support adjuster assembly is available only on the driver side.

  • Use the same procedure for RHD and LHD vehicles.

  • The following procedure is for LHD vehicles.

PROCEDURE


  1. INSTALL FRONT SEATBACK EDGE PROTECTOR

    Click here

  2. INSTALL LUMBAR SUPPORT ADJUSTER ASSEMBLY LH


    1. Install in this direction

      Install the lumbar support adjuster assembly LH to the front seatback frame sub-assembly as shown in the illustration.

    2. Engage the 2 claws to install the 2 front seatback edge protectors to the front seatback frame sub-assembly.

    3. Engage the clamp.

    4. Connect the connector.
