CHARGE LID OPENER SYSTEM OPERATION CHECK


  1. Note

    Check that entry and start system (for entry function) customize setting "Auto Entry Cancel SW" is set to "ON" before performing the following procedure.

    CHECK CHARGE LID OPENER SYSTEM


    1. Charge lid unlock function


      1. The power switch is off.

      2. All doors are locked.

      3. Perform any of the following and check that the charging port lid opens.


        • Perform a wireless unlock operation*1 and then push the charging port lid.

        • Perform a key-linked unlock operation*2 and then push the charging port lid.

        • While carrying the electrical key transmitter sub-assembly, push the charging port lid.

        *2: Click here

    2. Charge lid lock function


      1. The power switch is off.

      2. All doors are closed.

    3. Perform any of the following and check that the charging port lid unlatches.


      • Perform a wireless lock operation*1 and then push the charging port lid.

      • Perform a key-linked lock operation*2 and then push the charging port lid.

      • Perform an entry lock operation*3 and then push the charging port lid.

      Note

      Make sure not to bring the electrical key transmitter sub-assembly into the charging port lid unlock detection area when pushing the charging port lid.
