IMMOBILISER SYSTEM DIAGNOSIS SYSTEM


  1. DESCRIPTION


    1. The certification ECU (smart key ECU assembly) and hybrid vehicle control ECU control the vehicle immobiliser system functions. Immobiliser system data and Diagnostic Trouble Codes (DTCs) can be read through the vehicle Data Link Connector 3 (DLC3).

      In some cases, a malfunction may be occurring in the immobiliser system even though the security indicator light is not illuminated.

      When the system seems to be malfunctioning, use the GTS to check for malfunctions and perform repairs.

  2. CHECK DLC3


    1. Check the DLC3.

      Click here

  3. INSPECT AUXILIARY BATTERY VOLTAGE


    1. Measure the auxiliary battery voltage with the power switch off.

      If the voltage is below 11 V, recharge or replace the auxiliary battery.
