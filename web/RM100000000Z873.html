NAVIGATION SYSTEM(for Navigation Receiver Type), Diagnostic DTC:B15C3

DTC Code DTC Name
B15C3 Speaker Output Short

DESCRIPTION

This DTC is stored when a malfunction occurs in the speakers.

DTC No. Detection Item DTC Detection Condition Trouble Area
B15C3 Speaker Output Short A short is detected in the speaker output circuit.

  • Harness or connector

  • Speaker

  • Stereo component amplifier assembly
