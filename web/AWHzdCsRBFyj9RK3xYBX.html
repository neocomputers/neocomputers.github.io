SHIFT LEVER KNOB INSTALLATION

PROCEDURE


  1. INSTALL SHIFT LEVER KNOB SUB-ASSEMBLY


    1. Turn the shift lever knob sub-assembly as shown in the illustration to install it.

    2. *a Measuring Point

      Using a vernier caliper, measure the height of the shift lever knob sub-assembly and adjust it as necessary.

      Standard Height
      12.4 to 15.4 mm (0.488 to 0.606 in.)
