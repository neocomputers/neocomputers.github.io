TEMPERATURE SWITCH INSTALLATION

PROCEDURE


  1. INSTALL ENGINE COOLANT TEMPERATURE SENSOR


    1. *a Torque Wrench Fulcrum Length

      Using a 19 mm union nut wrench, install the engine coolant temperature sensor to the No. 2 water joint.

      Torque:
      Specified tightening torque
      8.0 N*m  { 82 kgf*cm, 71 in.*lbf }

      Note

      Do not apply any excessive force to the heater pipe when installing the engine coolant temperature sensor.

      Tech Tips


      • Calculate the torque wrench reading when changing the fulcrum length of the torque wrench.

        Click here

      • When using a 19 mm union nut wrench (fulcrum length of 30.0 mm (1.18 in.)) + torque wrench (fulcrum length of 162 mm (6.38 in.)): 7.0 N*m (71 kgf*cm, 62 in.*lbf)

    2. Connect the engine coolant temperature sensor connector.
