DESCRIPTION

The airbag sensor assembly has a built-in yaw rate and acceleration sensor and detects the vehicle condition using 2 circuits (GL1, GL2).

The skid control ECU (brake booster with master cylinder assembly) receives signals from the hybrid vehicle control ECU, steering angle sensor, certification ECU (smart key ECU assembly), inverter with converter assembly and yaw rate and acceleration sensor (airbag sensor assembly) via CAN communication.
