ELECTRIC VEHICLE CHARGER ASSEMBLY INSTALLATION

PROCEDURE


  1. INSTALL CHARGER COOLING BLOWER


    1. Install the charger cooling blower with the 2 bolts.

    2. Engage the clamp.

  2. INSTALL ELECTRIC VEHICLE CHARGER ASSEMBLY

    CAUTION:

    Wear insulated gloves.


    1. *a

      Bolt (A)

      (Bolt Length: 25 mm (0.984 in.))
      *b

      Bolt (B)

      (Bolt Length: 24 mm (0.945 in.))

      Temporarily install the electric vehicle charger assembly with the 3 bolts (A) and bolt (B).

    2. Fully tighten the 3 bolts (A) and bolt (B) in the order shown in the illustration.

      Torque:
      19 N*m  { 194 kgf*cm, 14 ft.*lbf }

    3. Engage the 2 clamps.

    4. Connect the 3 connectors.

  3. INSTALL NO. 2 INDOOR ELECTRICAL KEY ANTENNA ASSEMBLY

    Click here

  4. INSTALL EV CHARGER DUCT


    1. Install the EV charger duct with the 2 clips.

  5. CONNECT HV BATTERY CHARGER WIRE

    CAUTION:

    Wear insulated gloves.


    1. w/ Solar Charging System:


      1. Engage the 2 clamps.

    2. *a Green-colored Lock
      Slide

      Connect the 2 electric vehicle charger assembly connectors and slide the green-colored lock as shown in the illustration to lock it securely.

      Note

      Make sure that the connectors are connected securely.

  6. INSTALL REAR SEAT CUSHION LEG SUB-ASSEMBLY


    1. Temporarily install the rear seat cushion leg sub-assembly with the 9 bolts.

    2. Fully tighten the 9 bolts in the order shown in the illustration.

      Torque:
      16 N*m  { 163 kgf*cm, 12 ft.*lbf }
