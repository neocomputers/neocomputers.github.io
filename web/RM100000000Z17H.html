PARKING BRAKE CABLE(for Front Side) INSTALLATION

PROCEDURE


  1. INSTALL FRONT PARKING BRAKE CABLE CLAMP (for LHD)


    1. Engage the 2 claws to install a new front parking brake cable clamp to the No. 1 parking brake cable assembly.

      Tech Tips

      Even if a one-piece type front parking brake cable clamp was originally installed, make sure to install a separate type front parking brake cable clamp.

  2. INSTALL NO. 1 PARKING BRAKE CABLE ASSEMBLY (for LHD)


    1. Install the No. 1 parking brake cable assembly with the 4 bolts.

      Torque:
      15.5 N*m  { 158 kgf*cm, 11 ft.*lbf }

    2. Engage the 2 clamps.

  3. INSTALL NO. 1 PARKING BRAKE CABLE ASSEMBLY (for RHD)


    1. Install the No. 1 parking brake cable assembly with the 3 bolts.

      Torque:
      15.5 N*m  { 158 kgf*cm, 11 ft.*lbf }

    2. Engage the clamp.

  4. CONNECT NO. 1 PARKING BRAKE CABLE ASSEMBLY


    1. *a Turn
      *b Hold

      Connect the No. 1 parking brake cable assembly to the No. 1 parking brake pull rod sub-assembly as shown in the illustration.

      Torque:
      5.4 N*m  { 55 kgf*cm, 48 in.*lbf }

  5. INSTALL NO. 1 SOLAR BATTERY MOUNT BRACKET (w/ Solar Charging System)


    1. Engage the claw.

    2. Install the No. 1 solar battery mount bracket with the 4 bolts.

      Torque:
      19 N*m  { 194 kgf*cm, 14 ft.*lbf }

    3. Install the front floor carpet assembly to its original position.

    4. Engage the 2 clamps.
