FRONT CONSOLE BOX INSTALLATION

PROCEDURE


  1. INSTALL REAR CONSOLE BOX ASSEMBLY (w/o Solar Charging System)


    1. Install the rear console box assembly with the 6 bolts.

      Torque:
      13 N*m  { 133 kgf*cm, 10 ft.*lbf }

  2. INSTALL REAR CONSOLE BOX ASSEMBLY (w/ Solar Charging System)


    1. Install the 2 clips.

    2. Install the rear console box assembly with the 6 bolts.

      Torque:
      13 N*m  { 133 kgf*cm, 10 ft.*lbf }

  3. INSTALL CONSOLE REAR END PANEL SUB-ASSEMBLY (w/o Solar Charging System)


    1. Connect the connector.

    2. Install in this Direction

      Engage the 8 clips to install the console rear end panel sub-assembly as shown in the illustration.

  4. INSTALL CONSOLE REAR END PANEL SUB-ASSEMBLY (w/ Solar Charging System)


    1. Connect the connector.

    2. Install in this Direction

      Engage the 8 clips to install the console rear end panel sub-assembly as shown in the illustration.

  5. INSTALL CONSOLE CUP HOLDER BOX SUB-ASSEMBLY


    1. Install the console cup holder box sub-assembly with the 6 screws.

  6. INSTALL UPPER CONSOLE PANEL SUB-ASSEMBLY


    1. Connect each connector.

    2. Engage each clamp.

    3. Install in this Direction

      Engage the 2 guides and 12 clips to install the upper console panel sub-assembly as shown in the illustration.

  7. INSTALL NO. 1 UPPER BOX PLATE


    1. Install in this Direction

      Engage the 2 claws as shown in the illustration.

    2. Install in this Direction

      Engage the 2 clips and claw to install the No. 1 upper box plate as shown in the illustration.
