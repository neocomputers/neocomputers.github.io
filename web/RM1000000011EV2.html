LIGHTING SYSTEM CUSTOMIZE PARAMETERS


  1. CUSTOMIZE LIGHTING SYSTEM (INT)


    1. Customizing using the GTS

      Note


      • When the customer requests a change in a function, first make sure that the function can be customized.

      • Be sure to make a note of the current settings before customizing.

      • When troubleshooting a function, first make sure that the function is set to the default setting.

      Tech Tips

      The following items can be customized.


      1. Connect the GTS to the DLC3.

      2. Turn the power switch on (IG).

      3. Turn the GTS on.

      4. Enter the following menus: Customize Setting / Illuminated Entry.

      5. Select the setting by referring to the table below.


        Illuminated Entry
        Tester Display Description Default Setting ECU
        Lighting Time

        Changes the lighting time of the following lights that are operated by the timer function when the interior light door switch of the map light assembly is DOOR position:


        • Map light assembly

        • No. 1 room light assembly

        		 15 s 10:30 s,00:15 s,01:7.5 s Main body ECU (Multiplex network body ECU)
        I/L when ACC OFF

        Turns off the following lights automatically when the interior light door switch of the map light assembly is DOOR position and the power switch is turned from ON or ACC to off:


        • Map light assembly

        • No. 1 room light assembly

        		 ON 0:OFF,1:ON Main body ECU (Multiplex network body ECU)
        I/L ON W/Door Key Unlock

        Lights up the following lights automatically when the interior light door switch of the map light assembly is DOOR position and the doors are unlocked by an unlock operation:


        • Map light assembly

        • No. 1 room light assembly

        		 ON 0:OFF,1:ON Main body ECU (Multiplex network body ECU)
        Room Light when Aprchd

        Lights up the following lights when the interior light door switch of the map light assembly is DOOR position and the electrical key transmitter sub-assembly is brought near the vehicle:


        • Map light assembly

        • Map light assembly

    2. Customizing with the multi-display (w/ Multi-display)


      1. Turn the power switch on (IG).

      2. Enter the following menus:


        1. for Navigation Receiver Type: MENU / SETUP / Vehicle / Vehicle customization / Lights Settings.

        2. for Radio and Display Type: MENU / Setup / Vehicle / Vehicle customization / Lights Settings.

      3. Select the setting by referring to the table below.

        Display Default Content Setting Relevant ECU
        Interior Lights Off Timer 15 sec.

        Changes the lighting time of the following lights that are operated by the timer function when the interior light door switch of the map light assembly is DOOR position:


        • Map light assembly

        • No. 1 room light assembly

        		 Off, 7.5 sec., 15 sec., 30 sec. Main body ECU (Multiplex network body ECU)

    3. Customizing with the multi-information display (combination meter assembly (meter circuit plate)) (w/o Multi-display)


      1. Turn the power switch on (IG).

      2. Select the setting tab in the multi-information display.

      3. Enter the following menus: Vehicle settings / Lights settings.

      4. Select the setting by referring to the table below.

        Display Default Content Setting Relevant ECU
        Interior Lights Off Timer 15 sec.

        Changes the lighting time of the following lights that are operated by the timer function when the interior light door switch of the map light assembly is DOOR position:


        • Map light assembly

        • No. 1 room light assembly

        		 Off, 7.5 sec., 15 sec., 30 sec. Main body ECU (Multiplex network body ECU)
