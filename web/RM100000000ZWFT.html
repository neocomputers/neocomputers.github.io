MILLIMETER WAVE RADAR SENSOR INSTALLATION

CAUTION / NOTICE / HINT

Note

If the millimeter wave radar sensor assembly has been struck or dropped, replace the millimeter wave radar sensor assembly with a new one.

PROCEDURE


  1. INSTALL MILLIMETER WAVE RADAR SENSOR ASSEMBLY

    Note

    If any of the front bumper assembly, radiator grill, millimeter wave radar sensor assembly or No. 1 millimeter wave radar sensor bracket has been replaced, check that the beam axis change mechanism is at the standard position (centered).


    1. Set beam axis to the standard position.


      1. Turn the bolt so that the beam axis change mechanism is positioned as shown in the illustration.
