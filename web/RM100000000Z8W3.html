AIRBAG SYSTEM, Diagnostic DTC:B1656/38

DTC Code DTC Name
B1656/38 Seat Belt Buckle Switch LH Circuit Malfunction

DESCRIPTION

The seat belt buckle switch LH circuit consists of the airbag sensor assembly and seat belt buckle switch LH (front seat inner belt assembly LH).

DTC B1656/38 is stored when a malfunction is detected in the seat belt buckle switch LH circuit.

DTC No. Detection Item DTC Detection Condition Trouble Area Test Mode / Check Mode
B1656/38 Seat Belt Buckle Switch LH Circuit Malfunction

  • The airbag sensor assembly detects a line short, short to ground or B+, or an open in the seat belt buckle switch LH circuit.

  • Seat belt buckle switch LH malfunction

  • Airbag sensor assembly malfunction

  • Floor wire

  • Seat belt buckle switch LH (Front seat inner belt assembly LH)

  • Airbag sensor assembly

 Does not apply to test/check mode
