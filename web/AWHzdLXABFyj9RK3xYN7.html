INTELLIGENT CLEARANCE SONAR SYSTEM UTILITY


  1. FREEZE FRAME DATA

    Note


    • Freeze frame data is stored and updated at each time the brakes are operated. Only the latest 30 sets of data are stored.

    • Using the GTS, make sure to save the data before performing a reproduction test as the data will be updated.

      Tech Tips

      The freeze frame data that is stored and updated each time the brakes are operated is stored in a different area to that of DTC freeze frame data.


    1. Connect the GTS to the DLC3.

    2. Turn the power switch on (IG).

    3. Turn the GTS on.

    4. Enter the following menus: Body Electrical / Advanced Parking Guidance/ICS/Intuitive P/A / Utility.

    5. Read the Utility according to the display on the GTS.
