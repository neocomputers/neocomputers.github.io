REAR COMBINATION LIGHT ASSEMBLY INSTALLATION

CAUTION / NOTICE / HINT

Tech Tips


  • Use the same procedure for the RH side and LH side.

  • The following procedure is for the LH side.

PROCEDURE


  1. INSTALL REAR COMBINATION LIGHT ASSEMBLY


    1. Engage the grommet.

    2. *a Pin
      *b Guide
      Install in this Direction

      Engage the 2 guides and pin to temporarily install the rear combination light assembly as shown in the illustration.

    3. Install the rear combination light assembly with the 2 screws.

    4. Remove the protective tape.

    5. Connect the connector.

  2. INSTALL REAR COMBINATION LIGHT COVER


    1. Install in this Direction

      Engage the 2 claws as shown in the illustration.

    2. Install in this Direction

      Engage the 4 claws to install the rear combination light cover as shown in the illustration.
