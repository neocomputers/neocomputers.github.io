NAVIGATION SYSTEM(for Radio and Display Type) MirrorLink Image is not Displayed

PROCEDURE


  1. CHECK USAGE CONDITION


    1. Check the conditions under which the "MirrorLink" function is being used.

      Result
      Result Proceed to
      An image is displayed while the vehicle is stopped. A
      An image is not displayed while the vehicle is being driven or while the vehicle is stopped. B

      Tech Tips

      Some applications have a display restriction in consideration of safe driving.


    A

    END

    B

  2. CHECK APPLICATION


    1. Refer to System Description and check if the application being used is "MirrorLink" compatible.

      Click here

      Tech Tips


      • Some applications require payment.

      • The names of applications are subject to change.

      Result
      Result Proceed to
      The application being used is "MirrorLink" compatible, but its image is not displayed. A
      The application being used is not "MirrorLink" compatible, and its image is not displayed. B

      Tech Tips

      Some applications have a display restriction in consideration of safe driving.


    B

    USE "MirrorLink" COMPATIBLE APPLICATION AND CHECK AGAIN

    A

  3. CHECK SMARTPHONE


    1. Check if an image is displayed on the "MirrorLink" compatible smartphone when a "MirrorLink" compatible application is running and it is disconnected from the head unit.

      Result
      Result Proceed to
      An image is displayed. A
      An image is not displayed. B

      Tech Tips

      Restarting the smartphone may return the application operation to normal.


    B

    RESTART "MirrorLink" COMPATIBLE APPLICATION

    A

  4. CHECK APPLICATION RUNNING STATUS


    1. Connect the smartphone to the head unit with a "MirrorLink" compatible application running and check if the "MirrorLink" function can be used and an image is displayed.

      Tech Tips

      The "MirrorLink" function may not start if the application is not running.

      Result
      Result Proceed to
      An image is displayed. A
      An image is not displayed. B

    A

    END

    B
