FUEL SENDER GAUGE ASSEMBLY(w/o Canister Pump Module) INSTALLATION

PROCEDURE


  1. INSTALL FUEL SENDER GAUGE ASSEMBLY


    1. Engage the claw to install the fuel sender gauge assembly to the fuel suction tube with pump and gauge assembly.

      Note

      Be careful not to bend the arm of the fuel sender gauge assembly.

    2. Connect the fuel sender gauge assembly connector.

    3. Install the harness protector to the wire harness.

      Note

      Do not damage the wire harness.

    4. Engage the 2 clamps to connect the wire harness.

      Note

      Do not damage the wire harness.

  2. INSTALL FUEL SUCTION TUBE WITH PUMP AND GAUGE ASSEMBLY
