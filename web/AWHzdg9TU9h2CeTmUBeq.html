HORN INSTALLATION

PROCEDURE


  1. INSTALL LOW PITCHED HORN ASSEMBLY


    1. Install the low pitched horn assembly with the bolt.

      Torque:
      19.5 N*m  { 199 kgf*cm, 14 ft.*lbf }

    2. Connect the connector.

  2. INSTALL HIGH PITCHED HORN ASSEMBLY


    1. Install the high pitched horn assembly with the bolt.

      Torque:
      19.5 N*m  { 199 kgf*cm, 14 ft.*lbf }

    2. Connect the connector.
