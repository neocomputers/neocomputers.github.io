SIMPLE INTELLIGENT PARKING ASSIST SYSTEM, Diagnostic DTC:C1AF6

DTC Code DTC Name
C1AF6 Rr Side Sensor Initialization Incomplete

DESCRIPTION

When it is judged that the rear side sensors have not been initialized, the clearance warning ECU assembly stores DTC C1AF6.

DTC No. Detection Item DTC Detection Condition Trouble Area
C1AF6 Rr Side Sensor Initialization Incomplete Rear side sensor not initialized

  • Initialize rear side sensor

  • Clearance warning ECU assembly

CAUTION / NOTICE / HINT

Note

If DTC C1AF6 is output after performing repairs, turn the power switch on (IG) and turn the TOYOTA parking assist-sensor system on to clear the DTC.
