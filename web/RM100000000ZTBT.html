THEFT DETERRENT SYSTEM Engine Hood Courtesy Switch Circuit

DESCRIPTION

The engine hood courtesy switch is built into the hood lock assembly. This switch turns on when the engine hood is closed and turns off when the engine hood is opened.

WIRING DIAGRAM

CAUTION / NOTICE / HINT

Note

Before replacing the main body ECU (multiplex network body ECU), refer to Service Bulletin.

PROCEDURE


  1. READ VALUE USING GTS (HOOD COURTESY SW)


    1. Connect the GTS to the DLC3.

    2. Turn the power switch on (IG).

    3. Turn the GTS on.

    4. Enter the following menus: Body Electrical / Main Body / Data List.

    5. Read the Data List according to the display on the GTS.


      Body Electrical > Main Body > Data List
      Tester Display Measurement Item Range Normal Condition Diagnostic Note
      Hood Courtesy SW Engine hood courtesy switch ON or OFF

      ON: Engine hood open

      OFF: Engine hood closed
