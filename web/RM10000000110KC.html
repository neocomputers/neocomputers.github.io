ELECTRONICALLY CONTROLLED BRAKE SYSTEM, Diagnostic DTC:C1352, C1353, C1354, C1355, C1356, C1357, C1358, C1359

DTC Code DTC Name

C1353 Increasing Pressure Solenoid (FL)
C1354 Increasing Pressure Solenoid (RR)
C1355 Increasing Pressure Solenoid (RL)
C1356 Decreasing Pressure Solenoid (FR)

C1358 Decreasing Pressure Solenoid (RR)
C1359 Decreasing Pressure Solenoid (RL)

DESCRIPTION

Each solenoid adjusts the pressure which affects each wheel cylinder according to signals from the skid control ECU (brake booster with master cylinder assembly) and controls the vehicle.
