  10. INSTALL REAR DOOR NO. 3 WEATHERSTRIP


    1. Clean the rear door panel.

    2. Remove the release paper from a new rear door No. 3 weatherstrip.

      Tech Tips

      After removing the release paper, keep the exposed adhesive free from foreign matter.

    3. Double-sided Tape

      Engage the claw and install the rear door No. 3 weatherstrip.

  11. INSTALL REAR DOOR DUST PROOF SEAL


    1. Engage the 3 claws to install 3 new rear door dust proof seals.

  12. INSTALL REAR DOOR PANEL CUSHION


    1. Engage the 2 claws to install a new rear door panel cushion.

  13. INSTALL REAR DOOR OUTSIDE HANDLE FRAME SUB-ASSEMBLY


    1. Apply MP grease to the sliding parts of the rear door outside handle frame sub-assembly.

    2. *A Outside
      *B Inside

      Engage the claw as shown in the illustration.

    3. Using a T30 "TORX" socket wrench, install the rear door outside handle frame sub-assembly with the screw.

      Torque:
      4.0 N*m  { 41 kgf*cm, 35 in.*lbf }

  14. INSTALL REAR DOOR REAR OUTSIDE HANDLE PAD


    1. Engage the 3 guides and claw to install the rear door rear outside handle pad.

  15. INSTALL REAR DOOR FRONT OUTSIDE HANDLE PAD


    1. Engage the 3 claws to install the rear door front outside handle pad.

  16. INSTALL REAR DOOR OUTSIDE HANDLE COVER


    1. Engage the claw.

    2. Using a T30 "TORX" socket wrench, install the rear door outside handle cover with the screw.

      Torque:
      4.0 N*m  { 41 kgf*cm, 35 in.*lbf }

  17. INSTALL REAR DOOR OUTSIDE HANDLE ASSEMBLY


    1. Install in this Direction

      Insert the front end of the rear door outside handle assembly into the rear door outside handle frame sub-assembly.

    2. Insert the rear end of the rear door outside handle assembly into the rear door outside handle frame sub-assembly, then slide the rear door outside handle assembly toward the front of the vehicle to install it.

    3. Move the lever as shown in the illustration and engage the 2 claws to secure the rear door outside handle assembly.

  19. INSTALL REAR DOOR WINDOW REGULATOR ASSEMBLY


    1. Apply MP grease to the sliding parts of the rear door window regulator assembly.

    2. Temporarily install the temporary bolt to the rear door window regulator assembly.

    3. *a Temporary Bolt

      Temporarily install the rear door window regulator assembly with the 3 bolts.

    4. Tighten the temporary bolt and 3 bolts to install the rear door window regulator assembly.

      Tech Tips

      Tighten the bolts in the order shown in the illustration.

      Torque:
      8.0 N*m  { 82 kgf*cm, 71 in.*lbf }

    5. Connect the connector.

  20. INSTALL REAR DOOR GLASS CHANNEL FILLER


    1. Apply soapy water to a new rear door glass channel filler.

    2. *A Front Side
      *B Rear Side
      *a Edge of curved surface

      Install the rear door glass channel filler to the rear door glass sub-assembly at position shown in the illustration.

      Standard Dimension
      Area Measurement
      A 5.0 mm (0.197 in.)
      B 5.0 mm (0.197 in.)

  21. INSTALL REAR DOOR GLASS CHANNEL SUB-ASSEMBLY


    1. Apply soapy water to the channel filler side of the rear door glass channel sub-assembly.

    2. *A Front Side
      *B Rear Side
      *a Edge of curved surface

      Using a plastic hammer, install the rear door glass channel sub-assembly to the position shown in the illustration.

      Standard Dimension
      Area Measurement
      A 5.0 mm (0.197 in.)
      B 5.0 mm (0.197 in.)

      Note

      To prevent damaging the rear door glass sub-assembly, be careful not to strike the channel with too much force.

      Install in this Direction (2)

  25. INSTALL REAR DOOR WEATHERSTRIP


    1. Clean the rear door panel.

    2. Remove the release paper from a new rear door weatherstrip.

      Tech Tips

      After removing the release paper, keep the exposed adhesive free from foreign matter.

    3. *a Double-sided Tape

      Engage the 25 clips and install the rear door weatherstrip.

  26. INSTALL REAR DOOR CHECK ASSEMBLY


    1. Apply MP grease to the sliding parts of the rear door check assembly.

    2. Clean the bolt hole in the vehicle body.

    3. Clean the threads of the bolt (B).

    4. Apply adhesive to the threads of the bolt (B).

      Adhesive
      Toyota Genuine Adhesive 1324, Three Bond 1324 or equivalent

    5. Install the rear door check assembly with the 3 bolts.

      Torque:
      Bolt (A)
      5.5 N*m  { 56 kgf*cm, 49 in.*lbf }
      Bolt (B)
      30 N*m  { 306 kgf*cm, 22 ft.*lbf }
