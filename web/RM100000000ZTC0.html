THEFT DETERRENT SYSTEM Power Source Circuit

DESCRIPTION

Based on changes in the power source voltage, the main body ECU (multiplex network body ECU) can detect if the auxiliary battery has been disconnected and reconnected.

WIRING DIAGRAM

*a from Auxiliary Battery
*b ECU-DCC NO. 2
*c Instrument Panel Junction Block Assembly
*d Main Body ECU (Multiplex Network Body ECU)

CAUTION / NOTICE / HINT

Note


  • Before replacing the main body ECU (multiplex network body ECU), refer to Service Bulletin.

  • Inspect the fuses for circuits related to this system before performing the following procedure.
