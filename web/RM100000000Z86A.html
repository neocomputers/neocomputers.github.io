NAVIGATION SYSTEM(for Radio and Display Type) AVC-LAN Circuit

DESCRIPTION

Each unit of the navigation system connected to the AVC-LAN (communication bus) transmits switch signals through the AVC-LAN.

If a short to +B or short to ground occurs in the AVC-LAN, the navigation system will not function normally because communication is not possible.

WIRING DIAGRAM

*1 Radio and Display Receiver Assembly
*2 Stereo Component Amplifier Assembly
*3 AVC-LAN Communication Line

CAUTION / NOTICE / HINT
