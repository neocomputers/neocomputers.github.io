CAMERA HEATER INSTALLATION

PROCEDURE


  1. INSTALL FORWARD RECOGNITION WITH HEATER HOOD SUB-ASSEMBLY

    Note


    • Do not apply force to the heater area as the heater may become damaged.

    • Do not forcibly pull the wire harness as it may become damaged.


    1. Install in this Direction (1)
      Install in this Direction (2)
      Heater Area

      Engage the 2 guides and 2 claws as indicated by the arrows, in the order shown in the illustration to install the No. 2 forward recognition cover.

      Note

      Make sure that the 2 claws are engaged as shown in the illustration. Failure to do so may result in the malfunction of systems that use the forward recognition camera.

    2. *a Clamp
      *b Rib

      Engage the clamp and 8 ribs to install the forward recognition with heater hood sub-assembly.

      Note

      As the No. 1 forward recognition cover cannot be installed correctly if the clamp and ribs are not engaged securely, make sure to engage each clamp and rib securely.

      Tech Tips

      Engage the clamp and ribs in the order shown in the illustration.

    3. Connect the connector.

  2. INSTALL FORWARD RECOGNITION CAMERA
