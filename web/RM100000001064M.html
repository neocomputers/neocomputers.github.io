SFI SYSTEM(w/o Canister Pump Module) DTC CHECK / CLEAR

Note

When the diagnosis system is changed from normal mode to check mode or vice versa, all DTCs and freeze frame data recorded in normal mode are cleared. Before changing modes, always check and make a note of DTCs and freeze frame data.

Tech Tips


  • DTCs which are stored in the ECM can be displayed on the GTS. The GTS can display the confirmed and pending DTCs.

  • Some DTCs are not stored if the ECM does not detect the same malfunction again during a second consecutive driving cycle. However, such malfunctions, detected on only one occasion, are stored as pending DTCs.


  1. CHECK DTC


    1. Connect the GTS to the DLC3.

    2. Turn the power switch on (IG).

    3. Turn the GTS on.

    4. Enter the following menus: Powertrain / Engine / Trouble Codes.


      Powertrain > Engine > Trouble Codes

    5. Check the DTC(s) and freeze frame data, and then write them down.

      Tech Tips

      GTS Display Description
      Test Failed Shows the malfunction judgment results during the current trip.
      Pending Shows the malfunction judgment results up to now. (Indicates the possibility of a malfunction when no DTC is confirmed.)
      Confirmed Shows the DTCs confirmed up to now. (The number of current trips differs for each DTC.)

    6. Check the details of the DTC(s).

      Click here

  2. CHECK TIME STAMP

    Tech Tips

    By checking Time Stamp, the time and order in which DTCs were stored in an ECU can be checked.


    1. Connect the GTS to the DLC3.

    2. Turn the power switch on (IG).

    3. Turn the GTS on.

    4. Enter the following menus: Health Check.

    5. Perform the following steps when the data setting screen is displayed.

    6. Select the systems for which to perform Health Check and check for time stamp data.


        Selectable items:

      • Powertrain

      • Chassis

      • Body

      • Store All Data

    7. Select "Yes" when "Do you want to store time stamp data?" is displayed.

      Tech Tips

      If "Yes" is not selected, time stamp data will not be stored.

    8. After Health Check has completed, select "Time Stamp Data" to display the Time Stamp screen.

    9. Select the desired system from the drop-down list on the bottom of the Time Stamp screen.

    10. Check the order and time which DTCs were stored for the selected system.

  3. CLEAR DTC


    1. Connect the GTS to the DLC3.

    2. Turn the power switch on (IG).

    3. Turn the GTS on.

    4. Enter the following menus: Powertrain / Engine / Trouble Codes.

    5. Clear the DTCs.


      Powertrain > Engine > Clear DTCs
