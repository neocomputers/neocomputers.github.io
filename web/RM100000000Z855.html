NAVIGATION SYSTEM(for Radio and Display Type), Diagnostic DTC:B15A3

DTC Code DTC Name
B15A3 Stereo Component Amplifier Malfunction

DESCRIPTION

This DTC is stored when a malfunction occurs in the stereo component amplifier assembly.

DTC No. Detection Item DTC Detection Condition Trouble Area
B15A3 Stereo Component Amplifier Malfunction

When one of the conditions below is met:


  • Internal power supply malfunction

  • DSP error

  • EEPROM error

 Stereo component amplifier assembly
