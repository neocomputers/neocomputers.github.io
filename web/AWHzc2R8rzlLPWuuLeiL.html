ENGINE COOLANT TEMPERATURE SENSOR INSTALLATION

PROCEDURE


  1. INSTALL NO. 2 ENGINE COOLANT TEMPERATURE SENSOR (w/o Canister Pump Module)


    1. Apply a light coat of engine coolant to the O-ring of the No. 2 engine coolant temperature sensor.

    2. Install the No. 2 engine coolant temperature sensor to the No. 2 water by-pass pipe with the clip.

      Note


      • If the No. 2 engine coolant temperature sensor has been struck or dropped, replace it.

      • If reusing the No. 2 engine coolant temperature sensor, be sure to inspect the O-ring.

      • Make sure that the O-ring is not cracked or moved out of place when installing the No. 2 engine coolant temperature sensor.

    3. Connect the No. 2 engine coolant temperature sensor connector.

    4. Install the inverter with converter assembly.

      Click here

    5. Add engine coolant (for Engine).

      Click here

    Tech Tips

    1. Install a new gasket to the engine coolant temperature sensor.

    2. Using SST, install the engine coolant temperature sensor to the water outlet.

      SST
      09817-33191

      Note

      If the engine coolant temperature sensor has been struck or dropped, replace it.

      Torque:
      19.6 N*m  { 200 kgf*cm, 14 ft.*lbf }

    3. Connect the engine coolant temperature sensor connector.

    4. Install the EGR valve assembly.

  3. INSTALL NO. 2 ENGINE COOLANT TEMPERATURE SENSOR (w/ Canister Pump Module)


    1. Apply a light coat of engine coolant to the O-ring of the No. 2 engine coolant temperature sensor.

    2. Install the No. 2 engine coolant temperature sensor to the radiator pipe with the clip.

      Note


      • If the No. 2 engine coolant temperature sensor has been struck or dropped, replace it.

      • If reusing the No. 2 engine coolant temperature sensor, be sure to inspect the O-ring.

      • Make sure that the O-ring is not cracked or moved out of place when installing the No. 2 engine coolant temperature sensor.

    3. Connect the No. 2 engine coolant temperature sensor connector.

    4. Install the No. 1 engine cover sub-assembly.
