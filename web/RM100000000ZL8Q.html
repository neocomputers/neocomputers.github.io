AIR CONDITIONING UNIT INSTALLATION

PROCEDURE


  1. TEMPORARILY INSTALL AIR CONDITIONER UNIT ASSEMBLY


    1. Temporarily install the air conditioner unit assembly to the instrument panel reinforcement assembly with the 3 bolts.

  2. INSTALL INSTRUMENT PANEL REINFORCEMENT ASSEMBLY WITH AIR CONDITIONER UNIT ASSEMBLY

    Note


    • Be sure to support the air conditioner unit assembly when installing it. Failure to do so may cause the bracket of the air conditioner unit assembly to break.

    • When installing the air conditioner unit assembly, eliminate static electricity by touching the vehicle body to prevent the components from being damaged.


    1. Temporarily install the instrument panel reinforcement assembly with air conditioner unit assembly as shown in the illustration.

      Install in this Direction - -

    2. Connect each connector.

    3. Install the 4 bolts (A).

      Torque:
      25 N*m  { 255 kgf*cm, 18 ft.*lbf }

    4. Install the bolt (B).

      Torque:
      15 N*m  { 153 kgf*cm, 11 ft.*lbf }

    5. Connect the parking brake pedal assembly with the bolt (C).

      Torque:
      15 N*m  { 153 kgf*cm, 11 ft.*lbf }

    6. Temporarily install the nut.

    7. Install the 2 bolts.

      Torque:
      25 N*m  { 255 kgf*cm, 18 ft.*lbf }

    8. Connect the drain cooler hose.

    9. for LHD:


      1. Engage each clamp.

      2. Connect the relay block assembly with the bolt.

        Torque:
        8.0 N*m  { 82 kgf*cm, 71 in.*lbf }

      3. Connect the 3 earth wires with the 3 bolts.

        Torque:
        8.5 N*m  { 87 kgf*cm, 75 in.*lbf }

      4. Connect each connector.

    10. for RHD:


      1. Engage each clamp.

      2. Connect the relay block assembly with the bolt.

        Torque:
        8.0 N*m  { 82 kgf*cm, 71 in.*lbf }

      3. Connect the 3 earth wires with the 3 bolts.

        Torque:
        8.5 N*m  { 87 kgf*cm, 75 in.*lbf }

      4. Connect each connector.

  3. INSTALL LOWER DEFROSTER NOZZLE ASSEMBLY


    1. Engage the 6 claws to install the lower defroster nozzle assembly.

  4. INSTALL INSTRUMENT PANEL JUNCTION BLOCK ASSEMBLY WITH MAIN BODY ECU

    Click here

  5. INSTALL NO. 3 INSTRUMENT PANEL TO COWL BRACE SUB-ASSEMBLY


    1. Install the No. 3 instrument panel to cowl brace sub-assembly with the bolt and nut.

      Torque:
      Bolt
      10 N*m  { 102 kgf*cm, 7 ft.*lbf }
      Nut
      6.0 N*m  { 61 kgf*cm, 53 in.*lbf }

    2. for LHD:


      1. Engage the clamp and 2 claws to connect the DLC3 connector.

  6. INSTALL NO. 2 INSTRUMENT PANEL BRACE SUB-ASSEMBLY


    1. Install the No. 2 instrument panel brace sub-assembly with the bolt and nut.

      Torque:
      Bolt
      20 N*m  { 204 kgf*cm, 15 ft.*lbf }
      Nut
      18 N*m  { 184 kgf*cm, 13 ft.*lbf }

    2. Temporarily install the screw.

      Tech Tips

      Do not fully tighten the screw.

    3. Engage each clamp.

    4. Install the front floor mat to its original position as shown in the illustration.

  7. INSTALL NO. 1 INSTRUMENT PANEL BRACE SUB-ASSEMBLY


    1. Install the No. 1 instrument panel brace sub-assembly with the bolt and nut.

      Torque:
      Bolt
      20 N*m  { 204 kgf*cm, 15 ft.*lbf }
      Nut
      18 N*m  { 184 kgf*cm, 13 ft.*lbf }

    2. Temporarily install the screw.

      Tech Tips

      Do not fully tighten the screw.

    3. Connect the earth wire with the bolt.

      Torque:
      8.5 N*m  { 87 kgf*cm, 75 in.*lbf }

    4. Engage each clamp.

    5. Install the front floor mat to its original position as shown in the illustration.

        Tighten the bolts, screws and nut in the order shown in the illustration.

    2. for RHD:


      1. Tighten the 3 bolts, 2 screws and nut to install the air conditioner unit assembly.

        Bolt Screw
        Nut - -
        Torque:
        Bolt

        Note

        Tighten the bolts, screws and nut in the order shown in the illustration.

  33. CONNECT DISCHARGE PIPE SUB-ASSEMBLY


    1. Remove the vinyl tape from the discharge pipe sub-assembly.

    2. Sufficiently apply compressor oil to a new O-ring and the fitting surface of the discharge pipe sub-assembly.

      Compressor Oil
      ND-OIL 11 or equivalent

    3. Install the O-ring to the discharge pipe sub-assembly.

      Note

      Keep the O-ring and O-ring fitting surface free of foreign matter.

    4. Connect the discharge pipe sub-assembly.

  34. CONNECT SUCTION TUBE SUB-ASSEMBLY


    1. Remove the vinyl tape from the suction tube sub-assembly.

    2. Sufficiently apply compressor oil to a new O-ring and the fitting surface of the suction tube sub-assembly.

      Compressor Oil
      ND-OIL 11 or equivalent

    3. Install the O-ring to the suction tube sub-assembly.

      Note

      Keep the O-ring and O-ring fitting surface free of foreign matter.

    4. Connect the suction tube sub-assembly.

    5. Rotate the hook connector as shown in the illustration.

    6. Insert the tube joint into the fitting hole securely and install the bolt.

      Torque:
      9.8 N*m  { 100 kgf*cm, 87 in.*lbf }
