BLIND SPOT MONITOR SYSTEM, Diagnostic DTC:C1AB6

DTC Code DTC Name
C1AB6 Blind Spot Monitor Master Module

DESCRIPTION

This DTC is stored when the blind spot monitor sensor LH detects an internal malfunction.

DTC No. Detection Item DTC Detection Condition Trouble Area
C1AB6 Blind Spot Monitor Master Module The blind spot monitor sensor LH (master) detects an internal malfunction Blind spot monitor sensor LH

CAUTION / NOTICE / HINT

Note

When checking for DTCs, make sure that the blind spot monitor system is turned on.
