METER / GAUGE SYSTEM, Diagnostic DTC:B1503

DTC Code DTC Name
B1503 Exhaust Heat Management Warning Detected

DESCRIPTION

This DTC is stored and displays an engine coolant temperature warning when the combination meter assembly (meter circuit plate) detects a malfunction in the engine coolant temperature sensor that is connected to the combination meter assembly (meter circuit plate) via a direct line.

Tech Tips

This DTC is for the engine coolant temperature sensor which is used to detect the engine coolant temperature for the exhaust heat recirculation system, not for the engine coolant temperature sensor which is used for the SFI system.

DTC No. Detection Item DTC Detection Condition Trouble Area Memory Note
B1503 Exhaust Heat Management Warning Detected

Diagnosis Condition:


  • The power switch is on (IG).

  • IG power source voltage is 9.5 V or more.

Malfunction Status:


  • Engine coolant temperature sensor circuit open or shorted

  • Engine coolant temperature is 120°C (248°F) or more

  • Harness or connector

  • Engine coolant temperature sensor

  • Combination meter assembly (Meter circuit plate)

  • Exhaust heat recirculation system

 DTC stored -

WIRING DIAGRAM

*a Engine Coolant Temperature Sensor
*b Combination Meter Assembly (Meter Circuit Plate)

CAUTION / NOTICE / HINT

Note

When replacing the combination meter assembly, always replace it with a new one. If a combination meter assembly which was installed to another vehicle is used, the information stored in it will not match the information from the vehicle and a DTC may be stored.
