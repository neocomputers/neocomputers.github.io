THERMOSTAT INSTALLATION

PROCEDURE


  1. INSTALL WATER INLET WITH THERMOSTAT SUB-ASSEMBLY


    1. Type A:


      1. Install a new gasket to the water inlet with thermostat sub-assembly.

      2. Install the water inlet with thermostat sub-assembly with the 2 nuts and bolt.

        Torque:
        10 N*m  { 102 kgf*cm, 7 ft.*lbf }

    2. Type B:


      1. Install a new gasket to the water inlet with thermostat sub-assembly.

      2. Install the water inlet with thermostat sub-assembly with the 3 bolts.

        Torque:
        10 N*m  { 102 kgf*cm, 7 ft.*lbf }

    3. Connect the No. 2 radiator hose and No. 3 water by-pass hose to the water inlet with thermostat sub-assembly and slide the 2 clips to secure them.

  2. INSTALL ENGINE OIL LEVEL DIPSTICK GUIDE


    1. Install a new engine oil level dipstick guide O-ring to the engine oil level dipstick guide.

    2. Apply a light coat of engine oil to the engine oil level dipstick guide O-ring.

    3. Insert the engine oil level dipstick guide end into the oil pan sub-assembly.

    4. Install the engine oil level dipstick guide to the cylinder block sub-assembly with the bolt.

      Torque:
      21 N*m  { 214 kgf*cm, 15 ft.*lbf }

    5. Engage the clamp to connect the engine wire to the engine oil level dipstick guide.

  3. INSTALL ENGINE OIL LEVEL DIPSTICK


    1. Install the engine oil level dipstick to the engine oil level dipstick guide.
