REAR BUMPER REASSEMBLY

PROCEDURE


  1. INSTALL REAR BUMPER REINFORCEMENT SUB-ASSEMBLY


    1. Install the rear bumper reinforcement sub-assembly with the 8 bolts.

      Torque:
      18 N*m  { 184 kgf*cm, 13 ft.*lbf }

  2. INSTALL REAR BUMPER SIDE SEAL LH


    1. *1 Rear Bumper Side Clip

      Install the 3 clips.

    2. Install the rear bumper side seal LH with the rear bumper side clip.

  3. INSTALL REAR BUMPER SIDE SEAL RH

    Tech Tips

    Use the same procedure as for the LH side.

  4. INSTALL REAR BUMPER SIDE RETAINER LH


    1. Install in this Direction (1)
      Install in this Direction (2)

      Engage the guide as shown in the illustration.

    2. Engage the claw as shown in the illustration.

    3. Install in this Direction

      Engage the 3 clips as shown in the illustration to install the rear bumper side retainer LH.

  5. INSTALL REAR BUMPER SIDE RETAINER RH

    Tech Tips

    Use the same procedure as for the LH side.

  6. INSTALL NO. 3 REAR BUMPER PAD

    Tech Tips

    When installing the No. 3 rear bumper pad, heat the rear bumper assembly using a heat light.

    Heating Temperature
    Item Temperature
    Rear Bumper Assembly 20 to 30°C (68 to 86°F)

    Note

    Do not heat the rear bumper assembly excessively.


    1. Clean the rear bumper assembly surface.


      1. Using a heat light, heat the rear bumper assembly surface.

      2. Remove any remaining double-sided tape from the rear bumper assembly.

      3. Wipe off any tape adhesive residue with cleaner.

    2. Remove the release paper from a new No. 3 rear bumper pad.

      Tech Tips

      After removing the release paper, keep the exposed adhesive free from foreign matter.

    3. *a Line

      Install the No. 3 rear bumper pad as shown in the illustration.

      Tech Tips


      • Install the No. 3 rear bumper pad along the line on the rear bumper cover.

      • Use the same procedure for the RH side and LH side.
