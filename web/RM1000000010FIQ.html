DOOR COURTESY LIGHT BULB REPLACEMENT

CAUTION / NOTICE / HINT

Tech Tips


  • Use the same procedure for the RH side and LH side.

  • The following procedure is for the LH side.

PROCEDURE


  1. REMOVE COURTESY LIGHT ASSEMBLY

    Click here

  2. REMOVE COURTESY LIGHT BULB


    1. *a Protective Tape
      Remove in this Direction

      Using a screwdriver with its tip wrapped with protective tape, disengage the claw and remove the courtesy light housing with the courtesy light cover as shown in the illustration.

    2. Remove in this Direction

      Remove the courtesy light cover from the courtesy light housing as shown in the illustration.

    3. Remove in this Direction

      Remove the courtesy light bulb from the courtesy light housing as shown in the illustration.

  3. INSTALL COURTESY LIGHT BULB


    1. Install in this Direction

      Install the courtesy light bulb to the courtesy light housing as shown in the illustration.

    2. Install in this Direction

      Install the courtesy light cover to the courtesy light housing as shown in the illustration.

    3. Install in this Direction

      Engage the claw to install the courtesy light housing with the courtesy light cover as shown in the illustration.

  4. INSTALL COURTESY LIGHT ASSEMBLY
