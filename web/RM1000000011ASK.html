METER / GAUGE SYSTEM Engine Oil Pressure Switch Circuit

DESCRIPTION

The combination meter assembly (meter circuit plate) and engine oil pressure switch assembly are connected via direct line. The combination meter assembly determines the engine oil pressure based on the engine oil pressure switch ON/OFF signal.

Tech Tips


  • The combination meter assembly (meter circuit plate) receives various vehicle information signals from the hybrid vehicle control ECU via CAN communication in order to output warnings.

  • The combination meter assembly (meter circuit plate) operates the following to output oil pressure warnings:


    1. Engine oil pressure warning light

    2. Engine oil pressure warning buzzer

    3. Engine oil pressure warning message on multi-information display

CAUTION / NOTICE / HINT

Note


  • When replacing the combination meter assembly, always replace it with a new one. If a combination meter assembly which was installed to another vehicle is used, the information stored in it will not match the information from the vehicle and a DTC may be stored.

  • The following troubleshooting procedure is based on the assumption that the hybrid control system is normal. Confirm that the hybrid control system is not malfunctioning before performing the following procedure.
