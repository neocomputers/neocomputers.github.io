HEADUP DISPLAY REASSEMBLY

PROCEDURE


  1. INSTALL NO. 2 COMBINATION METER MIRROR


    1. Engage the 2 guides.

    2. Install the No. 2 combination meter mirror with the 3 screws.

  2. INSTALL COMBINATION METER MIRROR


    1. Install in this Direction

      Engage the 2 guides to install the combination meter mirror as shown in the illustration.

    2. Install in this Direction

      Engage the 2 claws to install the mirror clip and combination meter mirror as shown in the illustration.

  3. INSTALL COMBINATION METER WIRE


    1. Connect the connector.

    2. Engage the 2 clamps to install the combination meter wire.

  4. INSTALL COMBINATION DISPLAY


    1. Install in this Direction

      Engage the 2 guides as shown in the illustration.

    2. Install the combination display with the 2 screws.

  5. INSTALL COMBINATION METER MIRROR ECU


    1. Install in this Direction (1)
      Install in this Direction (2)

      Engage the 2 guides.

    2. Connect the connector and push down the holder as indicated by the arrow, in the order shown in the illustration to engage the 2 claws.

      Note


      • Be sure to connect the connector securely.

      • Be sure to engage the claws securely.

    3. Connect the 2 connectors to install the combination meter mirror ECU.

  6. INSTALL NO. 1 COMBINATION METER MIRROR PLATE


    1. Install the No. 1 combination meter mirror plate with the 5 screws.

  7. INSTALL NO. 1 COMBINATION METER MIRROR CASE


    1. Install in this Direction

      Engage the 2 guides and 6 claws as shown in the illustration.

    2. Install the No. 1 combination meter mirror case with the screw.
