SIMPLE INTELLIGENT PARKING ASSIST SYSTEM, Diagnostic DTC:C1645

DTC Code DTC Name
C1645 Power Steering Control System Failure

DESCRIPTION

This DTC is stored when the clearance warning ECU assembly receives a power steering system malfunction signal from the power steering ECU assembly via CAN communication.

DTC No. Detection Item DTC Detection Condition Trouble Area
C1645 Power Steering Control System Failure Power steering system malfunction Power steering system

PROCEDURE


  1. CHECK DTC OUTPUT


    1. Clear the DTCs.

      Click here


      Body Electrical > IPA/ICS/Clearance Sonar > Clear DTCs

    2. Recheck for DTCs and check if the same DTC is output again.


      Body Electrical > IPA/ICS/Clearance Sonar > Trouble Codes
      OK
      No DTCs are output.

      Tech Tips


      • This DTC is stored when a malfunction occurs in the power steering system.

      • This DTC may be output due to a temporary phenomenon such as low voltage or EPS overheat protection.

      • If troubleshooting and repair of a malfunction in the power steering system has been completed, DTC C1645 will not be output again when rechecking for DTCs.

      • If DTC C1645 is output frequently, duplicate the conditions that caused the problem symptoms and perform the inspection again, even though DTCs were not output when rechecking for DTCs.
