CAN COMMUNICATION SYSTEM UTILITY


  1. INITIALIZE THE CONNECTION INFORMATION OF A GATEWAY FUNCTION EQUIPPED ECU (BUS MONITOR ECU)


    1. Connect the GTS to the DLC3.

    2. Turn the power switch on (IG).

    3. Turn the GTS on.

    4. Enter the following menus:


      • for Body Electrical / Central Gateway / Utility / Initialization


      Body Electrical > Central Gateway > Utility
      Tester Display
      Initialization

      • for Body Electrical / Main Body / Utility / Initialization


      Body Electrical > Main Body > Utility
      Tester Display
      Initialization

    5. Initialize the ECU.
