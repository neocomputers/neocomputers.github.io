SPEED LIMITER SYSTEM, Diagnostic DTC:P157804

DTC Code DTC Name
P157804 Brake System System Internal Failure

DESCRIPTION

The speed limiter system uses the wheel speed signal that is sent from the skid control ECU (brake booster with master cylinder assembly).

This DTC indicates a malfunction in a wheel speed sensor of the skid control ECU (brake booster with master cylinder assembly).

DTC No. Detection Item DTC Detection Condition Trouble Area
P157804 Brake System System Internal Failure Information of wheel speed sensor malfunction is received from the skid control ECU (brake booster with master cylinder assembly).

  • Skid control ECU (Brake booster with master cylinder assembly)

  • Wheel speed sensor

  • Hybrid vehicle control ECU

CAUTION / NOTICE / HINT

Note

When this DTC is stored, speed limiter system operation will be prohibited. Even after DTCs are cleared, operation of the speed limiter system will remain prohibited until the following is performed.


  • Turn the power switch from off to on (IG), drive the vehicle at a speed of 15 km/h or more for at least 10 seconds, then turn the speed limiter system on.

Tech Tips

The DTCs related to the electronically controlled brake system will be stored at the same time. In that case, perform troubleshooting for the electronically controlled brake system first.
