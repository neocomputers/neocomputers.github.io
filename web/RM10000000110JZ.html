ELECTRONICALLY CONTROLLED BRAKE SYSTEM FREEZE FRAME DATA


  1. FREEZE FRAME DATA/INFORMATION


    1. Using the GTS, check the vehicle condition (ECU, sensor) when the brake system operates or a DTC is output.

    2. The Freeze Frame Data that is recorded when a DTC is stored can be used to check the INF codes, but only for DTCs which can be stored.

  2. CHECK FREEZE FRAME DATA WHEN BRAKE SYSTEM OPERATES


    1. Freeze Frame Data is stored when the brake system operates. The Freeze Frame Data is updated each time the system operates.

    2. Once Freeze Frame Data is stored when the system operates, it is not cleared until the DTC is cleared.

    3. The number of times (maximum: 31) the power switch has been turned from off to on (IG) since the last time the system was activated can be stored and displayed.

      Tech Tips


      • When the vehicle is stopped (vehicle speed below 7 km/h (4 mph)), turning the power switch from off to on (IG) does not cause the value to increase.

      • The value "31" is displayed when the power switch was turned on (IG) more than 31 times.

    4. Check Freeze Frame Data when the system operates.


      1. Turn the power switch off.

      2. Connect the GTS to the DLC3 and turn the power switch on (IG).

      3. Enter the following menus: Chassis / ABS/VSC/TRC / Utility.

      4. Select "ABS History".


        Chassis > ABS/VSC/TRC > Utility
        Tester Display
        ABS History

      5. Check the Freeze Frame Data when the system operates.

  3. CHECK FREEZE FRAME DATA AND INFORMATION WHEN DTC WAS STORED


    1. Freeze Frame Data is stored when a DTC is output.

    2. Once Freeze Frame Data is stored when a DTC is output, it is not updated or cleared until the DTC is cleared.

    3. The number of times (maximum: 31) the power switch has been turned from off to on (IG) since a DTC was output can be stored and displayed.

      Tech Tips

      The value "31" is displayed when the power switch was turned on (IG) more than 31 times.

    4. Check the Freeze Frame Data and INF code when a DTC is output.


      1. Turn the power switch off.

      2. Connect the GTS to the DLC3 and turn the power switch on (IG).

      3. Enter the following menus: Chassis / ABS/VSC/TRC / Trouble Codes.


        Chassis > ABS/VSC/TRC > Trouble Codes

      4. Select a DTC to display the Freeze Frame Data.

      5. Check the Freeze Frame Data for the output DTC.

        Tech Tips

        If an "INF Code" item appears when the Freeze Frame Data is displayed, select and check the INF code.


        Chassis > ABS/VSC/TRC

  4. CLEAR FREEZE FRAME DATA AND INFORMATION

    Note

    Clearing the DTCs will also clear the Freeze Frame Data and information codes (INF codes).


    1. Turn the power switch off.

    2. Connect the GTS to the DLC3.

    3. Turn the power switch on (IG).

    4. Turn the GTS on.

    5. Clear the DTCs and Freeze Frame Data.

      Click here


      Chassis > ABS/VSC/TRC > Clear DTCs
