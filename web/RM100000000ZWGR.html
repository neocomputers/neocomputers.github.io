OUTER REAR VIEW MIRROR INSTALLATION

CAUTION / NOTICE / HINT

Tech Tips


  • Use the same procedure for the RH side and LH side.

  • The following procedure is for the LH side.

PROCEDURE


  1. INSTALL OUTER REAR VIEW MIRROR ASSEMBLY


    1. Engage the guide and claw.

    2. Install the outer rear view mirror assembly with the 3 nuts.

      Torque:
      8.0 N*m  { 82 kgf*cm, 71 in.*lbf }

    3. Connect the connector.

    4. Engage the clip.

  2. INSTALL FRONT DOOR PANEL PROTECTOR


    1. Install the front door panel protector.
