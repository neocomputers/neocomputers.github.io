HV BATTERY INSTALLATION

PROCEDURE


  1. INSTALL NO. 1 HV BATTERY MOUNT BRACKET

    Tech Tips

    Perform this procedure only when replacement of the No. 1 HV battery mount bracket is necessary.


    1. Install the No. 1 HV battery mount bracket with the 2 bolts.

      Torque:
      19.5 N*m  { 199 kgf*cm, 14 ft.*lbf }

  2. INSTALL NO. 2 HV BATTERY MOUNT BRACKET

    Tech Tips

    Perform this procedure only when replacement of the No. 2 HV battery mount bracket is necessary.


    1. Install the No. 2 HV battery mount bracket with the 2 bolts.

      Torque:
      19.5 N*m  { 199 kgf*cm, 14 ft.*lbf }

  3. INSTALL NO. 3 HV BATTERY MOUNT BRACKET

    Tech Tips

    Perform this procedure only when replacement of the No. 3 HV battery mount bracket is necessary.


    1. Install the No. 3 HV battery mount bracket with the 3 bolts.

      Torque:
      35 N*m  { 357 kgf*cm, 26 ft.*lbf }

  4. INSTALL NO. 4 HV BATTERY MOUNT BRACKET

    Tech Tips

    Perform this procedure only when replacement of the No. 4 HV battery mount bracket is necessary.


    1. Install the No. 4 HV battery mount bracket with the 3 bolts.

      Torque:
      35 N*m  { 357 kgf*cm, 26 ft.*lbf }

  5. INSTALL HV BATTERY

    CAUTION:

    Wear insulated gloves.


    1. Set the 4 hooks and 2 straps.

    2. Using a suitable adaptor such as straps, install the HV battery while tilting the HV battery.

      CAUTION:

      To prevent any accidents and injuries due to the weight of the HV battery, follow all specified procedures and be careful to balance the HV battery when removing or installing it.

      Note


      • To prevent the wire harness from being caught, make sure to bundle the wire harness using insulating tape or equivalent.

      • Use cardboard or another similar material to protect the HV battery and vehicle body from damage.

      • Since the HV battery is very heavy, 2 people are needed to install it. When installing the HV battery, be careful not to damage the parts around it.

      • When removing/installing/moving the HV battery, make sure not to tilt it more than 80°.

      • While lowering the HV battery into the vehicle, do not allow it to contact the vehicle.

      • If the HV battery has been struck or dropped, replace it.

    3. Install the HV battery to the vehicle with the 4 bolts (A) and 6 bolts (B).

      Torque:
      29.5 N*m  { 301 kgf*cm, 22 ft.*lbf }
      *a

      Bolt (A)

      (Bolt Length: 23 mm (0.906 in.))

      		 *b

      Bolt (B)

      (Bolt Length: 25 mm (0.984 in.))

      Note

      Do not allow foreign matter, such as grease or oil, to adhere to the bolts of the HV battery.

  6. CONNECT FLOOR WIRE

    CAUTION:

    Wear insulated gloves.


    1. Connect the 2 HV battery connectors.

    2. Engage the clamp.

  7. CONNECT WIRE HARNESS

    CAUTION:

    Wear insulated gloves.


    1. *a Earth Terminal

      Engage the 3 clamps.

    2. Install the nut.

      Torque:
      8.0 N*m  { 82 kgf*cm, 71 in.*lbf }

    3. Install the 2 nuts to connect the earth terminals.

      Torque:
      8.0 N*m  { 82 kgf*cm, 71 in.*lbf }

    4. Connect the 2 HV battery junction block assembly connectors (B).

      Note

      Make sure that the connectors are connected securely.

    5. Connect the 2 HV battery junction block assembly connectors (A).

      Note

      Make sure that the connectors are connected securely.

  8. INSTALL NO. 2 HV BATTERY SHIELD PANEL

    CAUTION:

    Wear insulated gloves.


    1. Install the No. 2 HV battery shield panel to the HV battery with the 3 nuts.

      Torque:
      7.5 N*m  { 76 kgf*cm, 66 in.*lbf }

  9. INSTALL NO. 3 HV BATTERY SHIELD PANEL

    CAUTION:

    Wear insulated gloves.


    1. Install the No. 3 HV battery shield panel to the HV battery with the 4 nuts.

      Torque:
      7.5 N*m  { 76 kgf*cm, 66 in.*lbf }

  10. INSTALL NO. 1 HV BATTERY SHIELD PANEL

    CAUTION:

    Wear insulated gloves.


    1. *1 Battery Cover Lock Striker
      *a Button
      *b Push

      Install the No. 1 HV battery shield panel to the HV battery with the 8 nuts.

      Torque:
      7.5 N*m  { 76 kgf*cm, 66 in.*lbf }

    2. Install the battery cover lock striker, then push the button to lock it.
