HEADLIGHT ECU INSTALLATION

CAUTION / NOTICE / HINT

Tech Tips


  • Use the same procedure for the RH side and LH side.

  • The following procedure is for the LH side.

PROCEDURE


  1. INSTALL HEADLIGHT GASKET


    1. Install a new headlight gasket.

  2. INSTALL NO. 1 HEADLIGHT ECU SUB-ASSEMBLY


    1. Connect the 2 connectors.

    2. Install the connector cover to the No. 1 headlight ECU sub-assembly.

    3. Install the No. 1 headlight ECU sub-assembly with the 3 screws.

      Note

      If the No. 1 headlight ECU sub-assembly has been struck or dropped, replace it with a new one.
