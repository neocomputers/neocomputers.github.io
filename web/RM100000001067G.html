ECM INSTALLATION

PROCEDURE


  1. INSTALL NO. 2 ECM BRACKET


    1. Install the No. 2 ECM bracket to the ECM with the 2 screws.

      Torque:
      4.5 N*m  { 46 kgf*cm, 40 in.*lbf }

  2. INSTALL NO. 1 ECM BRACKET


    1. Install the No. 1 ECM bracket to the ECM with the 2 screws.

      Torque:
      4.5 N*m  { 46 kgf*cm, 40 in.*lbf }

  3. INSTALL ECM


    1. Install the ECM with the bolt and nut.

      Torque:
      Bolt
      13 N*m  { 133 kgf*cm, 10 ft.*lbf }
      Nut
      8.0 N*m  { 82 kgf*cm, 71 in.*lbf }

      Note

      If the ECM has been struck or dropped, replace it.

    2. Install the engine wire to the No. 1 ECM bracket with the bolt.

      Torque:
      8.0 N*m  { 82 kgf*cm, 71 in.*lbf }

    3. Engage the 2 clamps.

    4. Connect the 2 ECM connectors and lower the 2 levers.

      Note


      • When connecting the ECM connectors, make sure that the connecting parts of the ECM connectors are free of dirt, water or other foreign matter.

      • Be sure to securely connect the ECM connectors.
