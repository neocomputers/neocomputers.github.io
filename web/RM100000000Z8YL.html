SRS SEAT CUSHION AIRBAG ASSEMBLY INSTALLATION

PROCEDURE


  1. INSTALL FRONT SEAT CUSHION AIRBAG ASSEMBLY RH


    1. Pass the airbag wire harness through the hole.

    2. Install the front seat cushion airbag assembly RH with 3 new nuts.

      Torque:
      5.5 N*m  { 56 kgf*cm, 49 in.*lbf }

      Note


      • The nuts must not be reused.

      • Make sure that the front seat adjuster assembly RH is not deformed. If it is deformed, replace it with a new one.

    3. Engage the claw and 2 clamps.

      Tech Tips

      Engage the claw first.
