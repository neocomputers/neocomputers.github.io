HEADUP DISPLAY SYSTEM, Diagnostic DTC:U0100, U0142, U0163, U023A, U1104

DTC Code DTC Name
U0100 Lost Communication with ECM / PCM "A"
U0142 Lost Communication with Body Control Module "B"
U0163 Lost Communication with Navigation Control Module
U023A Lost Communication with Front Camera Module
U1104 Lost Communication with Driving Support ECU

DESCRIPTION

The combination meter mirror ECU communicates with the hybrid vehicle control ECU, main body ECU (multiplex network body ECU), radio and display receiver assembly*1, navigation receiver assembly*2, forward recognition camera*3 and driving support ECU assembly*3 via CAN communication.

DTC No. Detection Item DTC Detection Condition Trouble Area Memory Note
U0100 Lost Communication with ECM / PCM "A"

Diagnosis Condition:


  • The power switch is on (IG)

  • IG power source voltage is 9.5 V or more

Malfunction Status:


  • No communication with hybrid vehicle control ECU continues

Malfunction Time:


  • 3 seconds or more

  • Hybrid vehicle control ECU

  • CAN communication system

  • Combination meter mirror ECU
