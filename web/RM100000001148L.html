SIMPLE INTELLIGENT PARKING ASSIST SYSTEM DIAGNOSIS SYSTEM


  1. DESCRIPTION


    1. Simple intelligent parking assist system data and Diagnostic Trouble Codes (DTCs) can be read from the Data Link Connector 3 (DLC3) of the vehicle. When the system seems to be malfunctioning, use the GTS to check for malfunctions and to repair them.

    1. Check the DLC3.

      Click here

  3. DIAGNOSIS FUNCTION


    1. When the simple intelligent parking assist system is unavailable either temporarily or due to a malfunction, a warning message is displayed on the multi-information display.


      • When the system is temporarily unavailable, "System Unavailable" is displayed.

      • When the system is malfunctioning, "IPA System Check Visit Your Dealer" is displayed.
