LANE DEPARTURE ALERT SYSTEM(w/ Steering Control) FREEZE FRAME DATA


  1. DESCRIPTION


    1. Whenever a lane departure alert system DTC is stored, the forward recognition camera stores the current vehicle state (ECU and sensor information) as Freeze Frame Data.

  2. CHECK FREEZE FRAME DATA


    1. Connect the GTS to the DLC3.

    2. Turn the power switch on (IG).

    3. Turn the GTS on.

    4. Enter the following menus: Chassis / LKA/LDA / Trouble Codes.


      Chassis > LKA/LDA > Trouble Codes

    5. According to the GTS display, select a DTC that stored freeze frame data.

    6. Read the freeze frame data recorded when the DTC was stored.
