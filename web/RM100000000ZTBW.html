THEFT DETERRENT SYSTEM CUSTOMIZE PARAMETERS


  1. CUSTOMIZE THEFT DETERRENT SYSTEM

    Note


    • When the customer requests a change in a function, first make sure that the function can be customized.

    • Be sure to make a note of the current settings before customizing.

    • When troubleshooting a function, first make sure that the function is set to the default setting.

    Tech Tips

    The following items can be customized.


    1. Customizing with the GTS


      1. Connect the GTS to the DLC3.

      2. Turn the power switch on (IG).

      3. Turn the GTS on.

      4. Enter the following menus: Customize Setting / Security or Wireless Door Lock.

      5. Select the setting by referring to the table below.


        Security
        Tester Display Description Default Setting ECU
        Intrusion Win Opened This function makes it possible to use the intrusion sensor when the windows are open.*1 OFF 00:OFF,01:ON Main body ECU (Multiplex network body ECU)
        Security control with mechanism key This function makes it possible to cancel the security alarm with the mechanical key.*2 OFF 0:OFF,1:ON Main body ECU (Multiplex network body ECU)

        • *1: w/ Intrusion Sensor

        • *2: Vehicles displaying the Item "Security control with mechanism key" on the GTS
