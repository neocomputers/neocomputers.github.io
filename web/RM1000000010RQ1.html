ADAPTIVE HIGH BEAM SYSTEM DIAGNOSIS SYSTEM


  1. DESCRIPTION


    1. Adaptive high beam system data and Diagnostic Trouble Codes (DTCs) can be read from the Data Link Connector 3 (DLC3) of the vehicle. When the system seems to be malfunctioning, use the GTS to check for malfunctions and perform repairs.

  3. INSPECT AUXILIARY BATTERY VOLTAGE


    1. Measure the auxiliary battery voltage with the power switch off.

      If the voltage is below 11 V, recharge or replace the auxiliary battery.

    2. DIAGNOSIS SYSTEM


      1. If the adaptive high beam system malfunctions, the adaptive high beam indicator light turn off and "Headlight System Malfunction Visit Your Dealer" warning message is displayed on the multi-information display.

        Tech Tips
