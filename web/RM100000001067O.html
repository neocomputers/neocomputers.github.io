CAMSHAFT POSITION SENSOR INSTALLATION

PROCEDURE


  1. INSTALL CAMSHAFT POSITION SENSOR


    1. Apply a light coat of engine oil to the O-ring of the camshaft position sensor.

      Note

      If reusing a camshaft position sensor, check the O-ring.

    2. for Bolt with Adhesive:


      1. Temporarily install the camshaft position sensor to the cylinder head cover sub-assembly with a new bolt.

        Note


        • Make sure that the O-ring is not cracked or moved out of place when installing the camshaft position sensor.

        • If a camshaft position sensor has been struck or dropped, replace it.

    3. except Bolt with Adhesive:


      1. Temporarily install the camshaft position sensor to the cylinder head cover sub-assembly with the bolt.

        Note


        • Make sure that the O-ring is not cracked or moved out of place when installing the camshaft position sensor.

        • If a camshaft position sensor has been struck or dropped, replace it.

    4. *a Torque Wrench Fulcrum Length
      *b 10 mm Union Nut Wrench

      Using a 10 mm union nut wrench, tighten the bolt.

      Torque:
      Specified tightening torque
      10 N*m  { 102 kgf*cm, 7 ft.*lbf }

      Tech Tips


      • Calculate the torque wrench reading when changing the fulcrum length of the torque wrench.

        Click here

      • When using a 10 mm union nut wrench (fulcrum length of 22 mm (0.866 in.)) + torque wrench (fulcrum length of 162 mm (6.38 in.)):

        8.8 N*m (90 kgf*cm, 78 in.*lbf)

    5. Connect the camshaft position sensor connector.

    6. Connect the No. 1 fuel vapor feed hose to the fuel vapor feed pipe.
