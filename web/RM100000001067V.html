    Tech Tips

    • w/o Canister Pump Module

    1. Install the 4 ignition coil assemblies to the cylinder head cover sub-assembly with the 4 bolts.

      Torque:
      10 N*m  { 102 kgf*cm, 7 ft.*lbf }

      Note

      If an ignition coil assembly has been struck or dropped, replace it.

      Tech Tips

      Install the same parts to their original positions.

    2. Connect the 4 ignition coil assembly connectors.
