POWER STEERING SYSTEM, Diagnostic DTC:U0129, U023A, U0293, U1110

DTC Code DTC Name
U0129 Lost Communication with Brake System Control Module
U023A Lost Communication with Front Camera Module
U0293 Lost Communication with Hybrid Control Module
U1110 Lost Communication with Clearance Sonar Module

DESCRIPTION

The power steering ECU assembly receives signals from the ECM, skid control ECU (brake booster with master cylinder assembly), forward recognition camera (w/ Toyota Safety Sense), hybrid vehicle control ECU, and clearance warning ECU assembly (w/ Simple Intelligent Parking Assist System) via CAN communication.
