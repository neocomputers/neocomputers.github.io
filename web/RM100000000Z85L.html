NAVIGATION SYSTEM(for Radio and Display Type), Diagnostic DTC:B157E

DTC Code DTC Name
B157E Bluetooth Antenna Disconnected

DESCRIPTION

This DTC is stored when a malfunction occurs in the "Bluetooth" antenna which is connected to the navigation ECU.

The "Bluetooth" antenna is built into the radio and display receiver assembly.

DTC No. Detection Item DTC Detection Condition Trouble Area
B157E Bluetooth Antenna Disconnected "Bluetooth" antenna is not connected

  • Navigation ECU

  • Radio and display receiver assembly

  • Antenna cord sub-assembly (for "Bluetooth")

PROCEDURE


  1. REPLACE ANTENNA CORD SUB-ASSEMBLY (for "Bluetooth")


    1. Replace the antenna cord sub-assembly (for "Bluetooth") with a new or known good one.

      Click here

    2. Clear the DTCs.

      Click here


      Body Electrical > Navigation System > Clear DTCs

    3. Recheck for DTCs and check that no DTCs are output.
