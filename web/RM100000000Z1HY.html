  2. HANDLING PRECAUTION FOR CRUISE CONTROL SYSTEM


    1. Turn the cruise control system off using the cruise control main switch (ON-OFF button) when not using the cruise control system.

    2. Be careful as the vehicle speed increases when driving downhill with the cruise control system controlling vehicle speed.

    3. The + (ACCEL)/RES (RESUME) operation changes according to the cruise control system status. When the cruise control system is controlling vehicle speed, the + (ACCEL) function operates. When the cruise control system is not controlling vehicle speed, the RES (RESUME) function operates.

    4. While the cruise control system is controlling vehicle speed, if the cruise control indicator turns off and a warning message is displayed, turn the cruise control system off using the cruise control main switch (ON-OFF button) to reset the cruise control system. After the cruise control system is reset, if the cruise control system does not turn on, or if the cruise control system stops functioning immediately after being turned on, there may be a malfunction.

    5. Do not use the cruise control system where the road conditions are as follows:


      • Heavy traffic

      • Steep downhill roads

      • Roads with sharp turns

      • Icy or snowy roads

      • Slippery roads

    6. Do not use the cruise control system while towing.
