TOYOTA PARKING ASSIST-SENSOR SYSTEM, Diagnostic DTC:C1AF8

DTC Code DTC Name
C1AF8 Rr IPA Sensor Communication Circuit

DESCRIPTION

This DTC is stored when there is an open or short circuit in the communication line between the rear side sensors and the ECU, or when there is a malfunction in a rear side sensor.

DTC No. Detection Item DTC Detection Condition Trouble Area
C1AF8 Rr IPA Sensor Communication Circuit An open or short circuit in the communication line between the rear side sensors and ECU or a malfunction in a rear side sensor during initialization mode after the power switch is turned on (IG).

  • Rear side ultrasonic sensor circuit

  • Harness or connector

  • Clearance warning ECU assembly

WIRING DIAGRAM

*a Rear Side Ultrasonic Sensor RH
*b Rear Side Ultrasonic Sensor LH
*c Clearance Warning ECU Assembly
