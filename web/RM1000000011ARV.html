DTC Code DTC Name

U0142 Lost Communication with Body Control Module "B"
U0151 Lost Communication with Restraints Control Module

U0182 Lost Communication with Lighting Control Module Front

U0293 Lost Communication with Hybrid Vehicle Control System
U1104 Lost Communication with Driving Support ECU

DESCRIPTION

The combination meter assembly (meter circuit plate) communicates with the ECM, hybrid vehicle control ECU, skid control ECU (brake booster with master cylinder assembly), power steering ECU assembly, main body ECU (multiplex network body ECU), airbag ECU assembly, radio and display receiver assembly*1, navigation receiver assembly*2, No. 1 headlight ECU sub-assembly LH, forward recognition camera*3 and driving support ECU assembly*3 via CAN communication.

DTC No. Detection Item DTC Detection Condition Trouble Area Memory Note
U0100 Lost Communication with ECM / PCM "A"

Diagnosis Condition:


  • The power switch is on (IG)

  • IG power source voltage is 9.5 V or more

Malfunction Status:


  • No communication with ECM continues

  • No communication with hybrid vehicle control ECU continues

Malfunction Time:


  • 2 seconds or more (for ECM)

  • 3 seconds or more (for Hybrid control ECU)

  • ECM

  • Hybrid vehicle control ECU

  • CAN communication system

  • Combination meter assembly (Meter circuit plate)
