LIGHTING SYSTEM Rear Door Courtesy Switch Circuit

DESCRIPTION

The main body ECU (multiplex network body ECU) detects the condition of the rear door courtesy light switch assembly.

WIRING DIAGRAM

*a Rear Door Courtesy Light Switch Assembly LH
*b Rear Door Courtesy Light Switch Assembly RH
*c Instrument Panel Junction Block Assembly
*d Main Body ECU (Multiplex Network Body ECU)

CAUTION / NOTICE / HINT

Note

Before replacing the main body ECU (multiplex network body ECU), refer to Service Bulletin.

PROCEDURE


  1. READ VALUE USING GTS


    1. Connect the GTS to the DLC3.

    2. Turn the power switch on (IG).

    3. Turn the GTS on.

    4. Enter the following menus: Body Electrical / Main Body / Data List.

    5. Read the Data List according to the display on the GTS.


      Body Electrical > Main Body > Data List
      Tester Display Measurement Item Range Normal Condition Diagnostic Note
      RR Door Courtesy SW Rear door courtesy light switch assembly RH signal OFF or ON

      OFF: Rear door RH closed

      ON: Rear door RH open

      		 -

      OFF: Rear door LH closed

      ON: Rear door LH open
