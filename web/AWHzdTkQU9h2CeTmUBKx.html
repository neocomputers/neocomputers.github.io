COMBINATION METER REASSEMBLY

PROCEDURE


  1. INSTALL METER CIRCUIT PLATE


    1. Install in this Direction (1)
      Install in this Direction (2)

      Connect each connector and push down each holder as indicated by the arrows, in the order shown in the illustration to engage the 4 claws.

      Note


      • Be sure to connect the connector securely.

      • Be sure to engage the claws securely.

    2. Install in this Direction

      Engage the 4 guides and 4 claws to install the meter circuit plate as shown in the illustration.

  2. INSTALL NO. 2 METER CIRCUIT PLATE


    1. Install in this Direction

      Engage the 4 guides as shown in the illustration.

    2. Install the No. 2 meter circuit plate with the 4 screws.

  3. INSTALL NO. 2 COMBINATION METER CASE


    1. Install in this Direction

      Engage the 2 guides to install the combination meter multi-display to the No. 2 combination meter case as shown in the illustration.

    2. Install in this Direction

      Engage the 2 guides and connect the connector to install the No. 2 combination meter case with combination meter multi-display as shown in the illustration.

      Note


      • Make sure to push the connector straight down when connecting it as it is easily damaged.

      • Make sure not to push the combination meter multi-display forcibly, or the connector may be damaged.

      • Be sure to connect the connector securely.

    3. Install the 2 screws.

    4. Engage the 2 guides.

    5. Install the No. 2 combination meter case with the screw.

  4. INSTALL NO. 1 COMBINATION METER PLATE


    1. Engage the 3 guides to install the No. 1 combination meter plate.

  5. INSTALL NO. 1 COMBINATION METER COVER


    1. Engage the 10 claws.

    2. Install the No. 1 combination meter cover with the 2 screws.

  6. INSTALL COMBINATION METER GLASS


    1. Engage the 12 claws to install the combination meter glass.

    2. Install the 9 bushes.
