HEATED OXYGEN SENSOR INSTALLATION

PROCEDURE


  1. INSTALL HEATED OXYGEN SENSOR

    Tech Tips

    Perform "Inspection After Repair" after replacing the air fuel ratio sensor. (w/ Canister Pump Module)

    Click here


    1. *a Torque Wrench Fulcrum Length

      Using SST, install the heated oxygen sensor to the front exhaust pipe assembly (TWC: Rear Catalyst).

      SST
      09224-00012
      Torque:
      Specified tightening torque
      44 N*m  { 449 kgf*cm, 32 ft.*lbf }

      Note

      If the heated oxygen sensor has been struck or dropped, replace it.

      Tech Tips


      • Calculate the torque wrench reading when changing the fulcrum length of the torque wrench.

        Click here

      • When using SST (fulcrum length of 30 mm (1.18 in.)) + torque wrench (fulcrum length of 255 mm (10.0 in.)):

        39 N*m (398 kgf*cm, 29 ft.*lbf)

    2. Install the wire harness clamp bracket to the heated oxygen sensor.

    3. Install the wire harness clamp.

    4. Connect the heated oxygen sensor connector.
