LIGHTING SYSTEM Power Switch Illumination Circuit

DESCRIPTION

The illuminated entry system controls the power switch illumination.

WIRING DIAGRAM

*1 Power Switch
*2 Certification ECU (Smart Key ECU Assembly)

CAUTION / NOTICE / HINT

Note

Before replacing the certification ECU (smart key ECU assembly), refer to Service Bulletin.

PROCEDURE


  1. PERFORM ACTIVE TEST USING GTS


    1. Connect the GTS to the DLC3.

    2. Turn the power switch on (IG).

    3. Turn the GTS on.

    4. Enter the following menus: Body Electrical / Entry&Start / Active Test.

    5. Perform the Active Test according to the display on the GTS.
