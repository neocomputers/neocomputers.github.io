INNER REAR VIEW MIRROR INSTALLATION

PROCEDURE


  1. INSTALL INNER REAR VIEW MIRROR ASSEMBLY (w/o Toyota Safety Sense)


    1. Install in this Direction

      Slide and temporarily install the inner rear view mirror assembly as shown in the illustration.

    2. Using a T20 "TORX" socket wrench, install the inner rear view mirror assembly with the screw.

    3. Connect the connector.

  2. INSTALL INNER REAR VIEW MIRROR STAY HOLDER COVER (w/o Toyota Safety Sense)


    1. Install in this Direction

      Engage the 6 claws to install the inner rear view mirror stay holder cover as shown in the illustration.

    2. Slide

      Slide the inner rear view mirror stay holder cover as shown in the illustration and engage the 2 guides.

  3. INSTALL INNER REAR VIEW MIRROR ASSEMBLY (w/ Toyota Safety Sense)


    1. Install in this Direction

      Slide and temporarily install the inner rear view mirror assembly as shown in the illustration.

    2. Using a T20 "TORX" socket wrench, install the inner rear view mirror assembly with the screw.

    3. Engage the clamp.

    4. Connect the connector.
