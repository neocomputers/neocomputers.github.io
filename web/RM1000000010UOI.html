LIGHTING SYSTEM Parking Brake Switch Circuit

DESCRIPTION

The main body ECU (multiplex network body ECU) detects the condition of the parking brake switch assembly.

WIRING DIAGRAM

*a Parking Brake Switch Assembly
*b Instrument Panel Junction Block Assembly
*c Main Body ECU (Multiplex Network Body ECU)

CAUTION / NOTICE / HINT

Note

Before replacing the main body ECU (multiplex network body ECU), refer to Service Bulletin.

PROCEDURE


  1. READ VALUE USING GTS


    1. Connect the GTS to the DLC3.

    2. Turn the power switch on (IG).

    3. Turn the GTS on.

    4. Enter the following menus: Body Electrical / Main Body / Data List.

    5. Read the Data List according to the display on the GTS.


      Body Electrical > Main Body > Data List
      Tester Display Measurement Item Range Normal Condition Diagnostic Note
      Parking Brake SW Parking brake switch signal OFF or ON

      OFF: Parking brake switch off

      ON: Parking brake switch on
