ELECTRONIC SHIFT LEVER SYSTEM, Diagnostic DTC:P272C46

DTC Code DTC Name
P272C46 Park Pawl Motor Calibration / Parameter Memory Failure

DESCRIPTION

If the hybrid vehicle control ECU detects a malfunction in its EEPROM, it stores this DTC. If this DTC is stored, replace the hybrid vehicle control ECU.
