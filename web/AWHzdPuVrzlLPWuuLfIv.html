POWER DOOR LOCK CONTROL SYSTEM SYSTEM DESCRIPTION


  1. POWER DOOR LOCK CONTROL SYSTEM DESCRIPTION


    1. The power door lock system locks/unlocks all doors.

      The main body ECU (multiplex network body ECU) receives lock/unlock request signals from a door control switch or the driver door key lock and unlock switch. Then, the main body ECU (multiplex network body ECU) sends these request signals to the door lock motors in each door to lock/unlock each door in response to the inputs.

  3. SYSTEM FUNCTION


    1. This system is controlled by the main body ECU (multiplex network body ECU). The main body ECU (multiplex network body ECU) outputs signals to each door lock motor. The power door lock control system has the following functions:

      Function Outline
      Manual lock and unlock function This function can lock or unlock all of the doors by the door control switch operation.
      Key-linked lock and unlock function This function, which is linked with the mechanical key cylinder, can lock or unlock all of the doors when a lock or unlock operation is performed.
      Manual unlock prohibition function

      When the condition below is met, unlocking the vehicle using the door control switch will be prohibited:


      • The doors are locked using a key-linked operation, wireless key operation or entry operation with all of the doors closed.
      Key lock-in prevention function When the key is in the vehicle, performing the door lock operation will not lock the door.
      Key-linked 2-step unlock function*1 Unlocks only the driver door by turning the key cylinder once and unlocks all of the doors by turning it twice.
      Shift-linked automatic door lock function*1

      When the conditions listed below are met consecutively, this function causes all of the doors to be automatically locked:


      • All of the doors are closed.

      • The hybrid control system is started.

      • With park (P) selected, the shift lever is moved to select another shift state.

      • Any of the doors is unlocked.
      Speed-sensitive automatic door lock function*1

      When the conditions listed below are met consecutively, this function causes all of the doors to be automatically locked:


      • Vehicle speed is higher than approximately 20 km/h (12 mph).

      • All of the doors are closed.

      • Any of the doors is unlocked.
      Shift-linked automatic door unlock function*1

      When the conditions listed below are met consecutively, this function causes all of the doors to be automatically unlocked:


      • The hybrid control system is started.

      • With a shift state other than park (P) selected, the P position switch (transmission shift main switch) is pushed.
      Driver door-linked automatic door unlock*1 all of the doors are unlocked automatically when the driver door is opened within approximately 43 seconds of the power switch being turned from on (IG) to off.
      Double locking function*2

      • This function prevents the doors from being opened through the operation of the inside door knobs. Thus, the doors cannot be opened either from inside or outside the vehicle.

      • To lock the doors with this function, pressing the electrical key transmitter sub-assembly lock switch twice within 5 seconds or touching the lock sensor on the outside door handle twice while holding the key within 5 seconds activates the double locking function. However, as an emergency unlocking maneuver, only the driver door can be unlocked with a key.

      Note

      Never activate the double locking function when there are people in the vehicle because the doors cannot be opened from the inside. If the doors are locked by accident, unlock the door by using the wireless unlock operation or entry unlock operation.

      • *1: w/ Canister Pump Module

      • *2: w/ Double Locking System
