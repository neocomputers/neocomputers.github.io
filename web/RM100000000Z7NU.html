FRONT SEAT ASSEMBLY(for Power Seat) REASSEMBLY

CAUTION / NOTICE / HINT

CAUTION:

Wear protective gloves. Sharp areas on the parts may injure your hands.

PROCEDURE


  1. INSTALL POWER SEAT TILT MOTOR ASSEMBLY LH


    1. Install the power seat tilt motor assembly LH with the 3 bolts.

      Torque:
      5.0 N*m  { 51 kgf*cm, 44 in.*lbf }

      Note

      Bolt (A) is shorter than bolt (B). Make sure to install them to the correct positions.

  2. INSTALL POWER SEAT LIFTER MOTOR ASSEMBLY LH


    1. Install the power seat lifter motor assembly LH.


      1. *a Stud Bolt of the Front Seat Vertical Housing Sub-assembly LH
        *b Hole of the Front Seat Adjuster Assembly
        *c Front Seat Vertical Housing Sub-assembly LH
        *d Front Seat Adjuster Assembly

        Install the front seat vertical housing sub-assembly LH.

        Note


        • Make sure to insert the stud bolt of the front seat vertical housing sub-assembly LH into the hole of the front seat adjuster assembly as shown in the illustration.

        • Make sure to position the front seat adjuster assembly so that when the front seat vertical housing sub-assembly LH is installed, their gears will be positioned as shown in the illustration.

      2. Install the vertical adjuster spacer.

      3. Install the front seat adjuster plate LH with the 3 nuts.

        Torque:
        5.0 N*m  { 51 kgf*cm, 44 in.*lbf }

        Note

        Tighten the nuts in the order shown in the illustration.

  3. INSTALL FRONT SEAT LOWER NO. 1 CUSHION SHIELD LH


    1. Install in this direction

      Engage the guide as shown in the illustration.

    2. Engage the claw to install the front seat lower No. 1 cushion shield LH.

  4. INSTALL FRONT SEAT CUSHION WIRE HARNESS HOLDER LH


    1. Install in this direction

      Engage the guide as shown in the illustration.

    2. Engage the 2 claws to install the front seat cushion wire harness holder LH.

    3. Install the 2 screws.

  5. INSTALL FRONT SEAT CUSHION SPRING SUB-ASSEMBLY LH


    1. Engage the 6 hooks to install the front seat cushion spring sub-assembly LH to the front seat adjuster assembly LH.

  6. INSTALL FRONT SEAT WIRE LH


    1. Connect each connector and engage each clamp to install the front seat wire LH.

  7. INSTALL FRONT SEAT LOWER CUSHION SHIELD LH


    1. *a Hook
      *b Guide

      Engage the claw and guide.

    2. Engage the hook to install the front seat lower cushion shield LH.

  8. INSTALL FRONT SEAT LOWER CUSHION SHIELD RH


    1. *a Hook
      *b Guide

      Engage the claw and guide.

    2. Engage the hook to install the front seat lower cushion shield RH.

  9. INSTALL LH SEAT RECLINING ADJUSTER INSIDE COVER LH


    1. Engage the 4 claws to install the LH seat reclining adjuster inside cover LH.

    2. Engage the claw.

  10. INSTALL LH SEAT RECLINING ADJUSTER INSIDE COVER RH


    1. Engage the 4 claws to install the LH seat reclining adjuster inside cover RH.

  11. INSTALL FRONT SEAT CUSHION HEATER ASSEMBLY LH

    Click here

  12. INSTALL SEPARATE TYPE FRONT SEAT CUSHION COVER


    1. Engage the 13 claws to install the separate type front seat cushion cover to the separate type front seat cushion pad.

  13. INSTALL SEPARATE TYPE FRONT SEAT CUSHION COVER WITH PAD


    1. Engage the 10 hooks to install the separate type front seat cushion cover with pad.

    2. Engage the clamp.

    3. Connect the connector.

  14. INSTALL FRONT SEAT NO. 2 WIRE LH


    1. Connect each connector and engage each clamp to install the front seat No. 2 wire LH.

  15. INSTALL FRONT SEATBACK HOOK


    1. Install the 2 front seatback hooks to the front seatback frame sub-assembly LH.

  16. INSTALL FRONT SEATBACK EDGE PROTECTOR


    1. Install the 2 front seatback edge protectors to the lumbar support adjuster assembly LH.

  17. INSTALL LUMBAR SUPPORT ADJUSTER ASSEMBLY LH

    Click here

  18. INSTALL FRONT SEAT AIRBAG ASSEMBLY LH

    Click here

  19. INSTALL FRONT SEATBACK HEATER ASSEMBLY LH

    Click here

  20. INSTALL SEPARATE TYPE FRONT SEATBACK COVER


    1. Engage the 17 claws to install the separate type front seatback cover to the separate type front seatback pad.

  21. INSTALL SEPARATE TYPE FRONT SEATBACK COVER WITH PAD


    1. Install the separate type front seatback cover with pad.

  22. INSTALL FRONT SEAT HEADREST SUPPORT


    1. Engage the 4 claws to install the 2 front seat headrest supports.

    2. *1 Seat Cover Hanger
      *a Bracket
      Install in this direction

      Slide the bracket as shown in the illustration to engage the hook and connect the bracket to the seat cover hanger.

      Note


      • For vehicles with a front seat airbag assembly, the separate type front seatback cover with pad must be securely installed. Otherwise, the front seat airbag assembly may not deploy properly.

      • Make sure that the strap is not twisted after connecting the bracket to the seat cover hanger.

      • Install the bracket securely.

    3. *1 Seatback Cover Hook
      *a Pin

      Insert the seatback cover hook and push in the pin to install it as shown in the illustration.

    4. Install in this direction

      Engage the hook as shown in the illustration.

    5. Close the 2 fasteners.

    6. Engage the clamp.

    7. Engage the 3 hooks.

  23. INSTALL SEPARATE TYPE FRONT SEATBACK ASSEMBLY


    1. Engage the 4 guides.

    2. Install the separate type front seatback assembly to the separate type front seat cushion assembly with the 4 bolts.

      Torque:
      42 N*m  { 428 kgf*cm, 31 ft.*lbf }

    3. Engage the claw and 4 clamps to install the front seat airbag assembly LH wire harness.

      Tech Tips

      Engage the claw first.

    4. Engage the clamp.

    5. Connect the connector.

    6. Engage the clamp.

    7. Connect the connector.

    8. Engage the 2 hooks.

    9. Pass the separate type front seatback cover through the grooves of the LH seat reclining adjuster inside cover LH and LH seat reclining adjuster inside cover RH.

  24. INSTALL FRONT POWER SEAT SWITCH LH

    Click here

  25. INSTALL FRONT SEAT SIDE NO. 1 BRACKET LH


    1. Install the front seat side No. 1 bracket LH to the front seat cushion shield LH with the 2 screws.

  26. INSTALL RECLINING POWER SEAT SWITCH KNOB


    1. Engage the 4 claws to install the reclining power seat switch knob.

  27. INSTALL SLIDE AND VERTICAL POWER SEAT SWITCH KNOB


    1. Engage the 4 claws to install the slide and vertical power seat switch knob.

  28. INSTALL FRONT SEAT INNER CUSHION SHIELD LH


    1. Install in this direction

      Engage the 2 claws and 2 guides as shown in the illustration.

    2. Engage the 2 claws to install the front seat inner cushion shield LH.

  29. INSTALL FRONT SEAT CUSHION SHIELD LH


    1. Connect the front power seat switch LH connector.

    2. Install in this direction (1)
      Install in this direction (2)

      Engage the guide (A) as shown in the illustration.

    3. Engage the 2 claws and 2 guides (B) as shown in the illustration.

    4. Engage the 2 claws to install the front seat cushion shield LH.

  30. INSTALL FRONT SEAT INNER NO. 1 CUSHION SHIELD LH


    1. Engage the 3 guides.

    2. Engage the 2 claws as shown in the illustration.

    3. Engage the guide as shown in the illustration.

    4. Install the front seat inner No. 1 cushion shield LH with the clip.

  31. CONNECT SEPARATE TYPE FRONT SEATBACK COVER


    1. Connect the rubber band of the separate type front seatback cover.
