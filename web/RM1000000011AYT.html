HEADUP DISPLAY SWITCH INSPECTION

PROCEDURE


  1. INSPECT HEADUP DISPLAY SWITCH (NO. 2 COMBINATION SWITCH ASSEMBLY)

    *1 Headup Display Switch
    *a

    Component without harness connected

    (Headup Display Switch (No. 2 Combination Switch Assembly))

    1. Measure the resistance according to the value(s) in the table below.

      Standard Resistance
      Tester Connection Condition Specified Condition
      3 (ILU) - 8 (E) Headup display switch pressed Below 1 Ω
      Headup display switch not pressed 10 kΩ or higher

      If the result is not as specified, replace the headup display switch (No. 2 combination switch assembly).

    2. *1 Headup Display Switch
      *a

      Component without harness connected

      (Headup Display Switch (No. 2 Combination Switch Assembly))

      Illumination Inspection


      1. Apply auxiliary battery voltage to the headup display switch (No. 2 combination switch assembly) and check that it illuminates.

        OK
        Condition Specified Condition

        Auxiliary battery positive (+) → Terminal 12 (ILL+)

        Auxiliary battery negative (-) → Terminal 2 (ILL-)

        		 Illuminates

        If the result is not as specified, replace the headup display switch (No. 2 combination switch assembly).
