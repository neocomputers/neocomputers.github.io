CHILD RESTRAINT SEAT ANCHOR BRACKET INSTALLATION

PROCEDURE


  1. INSTALL NO. 2 HV BATTERY MOUNT BRACKET (for LH Side)


    1. Temporarily install the No. 2 HV battery mount bracket with the 4 bolts.

    2. Bolt (A)
      Bolt (B)

      Fully tighten the 2 bolts (A), and then the 2 bolts (B) to install the No. 2 HV battery mount bracket.

      Torque:
      Bolt (A)
      19.5 N*m  { 199 kgf*cm, 14 ft.*lbf }
      Bolt (B)
      29.5 N*m  { 301 kgf*cm, 22 ft.*lbf }

    3. Engage the 3 clamps.

    4. Connect the connector.

  2. INSTALL NO. 1 HV BATTERY MOUNT BRACKET (for RH Side)


    1. Temporarily install the No. 1 HV battery mount bracket with the 4 bolts.

    2. Bolt (A)
      Bolt (B)

      Fully tighten the 2 bolts (A), and then the 2 bolts (B) to install the No. 1 HV battery mount bracket.

      Torque:
      Bolt (A)
      19.5 N*m  { 199 kgf*cm, 14 ft.*lbf }
      Bolt (B)
      29.5 N*m  { 301 kgf*cm, 22 ft.*lbf }

  3. INSTALL REAR FLOOR FRONT BATTERY COVER BOARD


    1. Engage the 5 fasteners.

    2. Install the rear floor front battery cover board with the 4 clips.
