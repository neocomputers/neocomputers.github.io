ELECTRONIC SHIFT LEVER SYSTEM PROBLEM SYMPTOMS TABLE

Tech Tips


  • Use the table below to help determine the cause of problem symptoms. If multiple suspected areas are listed, the potential causes of the problem symptoms are listed in order of probability in the "Suspected Area" column of the table. Check each symptom by checking the suspected areas in the order they are listed. Replace parts as necessary.

  • Inspect the fuses and relays related to this system before inspecting the suspected areas below.

Communication with hybrid vehicle control ECU stopped


  • Turn the power switch on (IG), select neutral (N) and wait for 3 seconds.


    1. If any DTCs are stored, troubleshoot the DTCs.

    2. If the problem symptom does not recur, check the hybrid vehicle control ECU and related parts.


      1. Check hybrid vehicle control ECU connector connection condition.

      2. Check if the IGCT SCENE relay is stuck off.

      3. Check the current flow to terminal MREL.

      4. Check the current flow to terminals +B1 and +B2.

      5. Confirm problem symptoms. (Check for intermittent problems.)

      6. Check for a hybrid vehicle control ECU internal malfunction.
