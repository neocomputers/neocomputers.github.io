REAR SEAT INNER BELT ASSEMBLY(for LH Side) INSPECTION

PROCEDURE


  1. INSPECT REAR SEAT 3 POINT TYPE BELT ASSEMBLY LH


    1. *a

      Component without harness connected

      (Rear Seat 3 Point Type Belt Assembly LH)

      Measure the resistance according to the value(s) in the table below.

      Standard Resistance
      Tester Connection Condition Specified Condition
      5 - 4 Rear seat 3 point type belt assembly LH unfastened Below 1 Ω
      Rear seat 3 point type belt assembly LH fastened 10 kΩ or higher

      If the result is not as specified, replace the rear seat 3 point type belt assembly LH.
