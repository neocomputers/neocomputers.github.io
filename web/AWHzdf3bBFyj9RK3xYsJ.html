HEADLIGHT ASSEMBLY REPAIR

CAUTION / NOTICE / HINT

Tech Tips


  • Use the same procedure for the RH side and LH side.

  • The following procedure is for the LH side.

  • If the installation area of the headlight assembly is damaged, use a supply retainer for a low-cost repair.

  • Ensure that the headlight assembly is not damaged.

PROCEDURE


  1. INSTALL UPPER HEADLIGHT PROTECTOR RETAINER


    1. Cut off the part shaded in the illustration and sand smooth with sandpaper.

      Tech Tips

      After cutting off the part, place the upper headlight protector retainer against the bosses and gradually file away the old bracket if it interferes with the installation of a supply retainer.

    2. Install the upper headlight protector retainer with the 2 screws.

  2. INSTALL UPPER NO. 2 HEADLIGHT PROTECTOR RETAINER


    1. Cut off the part shaded in the illustration and sand smooth with sandpaper.

      Tech Tips

      After cutting off the part, place the upper No. 2 headlight protector retainer against the bosses and gradually file away the old bracket if it interferes with the installation of a supply retainer.

    2. Install the upper No. 2 headlight protector retainer with the 2 screws.

  3. INSTALL UPPER NO. 3 HEADLIGHT PROTECTOR RETAINER


    1. Cut off the part shaded in the illustration and sand smooth with sandpaper.

      Tech Tips

      After cutting off the part, place the upper No. 3 headlight protector retainer against the bosses and gradually file away the old bracket if it interferes with the installation of a supply retainer.

    2. Install the upper No. 3 headlight protector retainer with the 2 screws.
