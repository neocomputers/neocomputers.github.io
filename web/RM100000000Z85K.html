NAVIGATION SYSTEM(for Radio and Display Type), Diagnostic DTC:B1552, B158A, B15B7

DTC Code DTC Name
B1552 Extension Module Malfunction
B158A Extension Module Noise Adjustment Malfunction
B15B7 Bluetooth Module Malfunction

DESCRIPTION

These DTCs are stored when a malfunction occurs in the navigation ECU.

DTC No. Detection Item DTC Detection Condition Trouble Area
B1552 Extension Module Malfunction Internal malfunction of the navigation ECU Navigation ECU
B158A Extension Module Noise Adjustment Malfunction Screen noise adjustment fails Navigation ECU
B15B7 Bluetooth Module Malfunction "Bluetooth" module malfunction Navigation ECU

  1. CHECK DTC
