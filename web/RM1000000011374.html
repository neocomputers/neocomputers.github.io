BACK DOOR REASSEMBLY

PROCEDURE


  1. INSTALL BACK DOOR NO. 2 WIRE


    1. Engage the 8 clamps.

    2. Connect the 3 connectors to install the back door No. 2 wire.

  2. INSTALL BACK DOOR NO. 1 WIRE


    1. When reusing the back door No. 1 wire:

      Tech Tips

      Use the same procedure for both No. 4 wiring harness protectors.


      1. Install in this Direction

        Engage the claw as shown in the illustration to temporarily install a new No. 4 wiring harness protector.

      2. Install in this Direction

        Install the No. 4 wiring harness protector to the grommet as shown in the illustration.

    2. Secure the rope to the back door No. 1 wire with vinyl tape as shown in the illustration.

      *a Vinyl tape *b Connector

      Note

      Make sure that the rope is secured with vinyl tape to prevent the rope from separating from the back door No. 1 wire when installing it.

    3. Install in this Direction

      Pass the back door No. 1 wire through the inside of the back door panel sub-assembly as shown in the illustration.

      Note

      This step should not be performed with the back door panel sub-assembly removed from the vehicle.

      Tech Tips

      The back door No. 1 wire is likely to be caught on the parts of the back door panel sub-assembly. If the back door No. 1 wire is caught, gradually install it by moving it back and forth, or by turning it.

    4. Connect the 2 connectors.

    5. Pass the back door No. 1 wire as shown in the illustration.

    6. Engage the 2 clamps.

    7. Connect the 2 connectors to install the back door No. 1 wire.

    8. Install the 3 clips.

    9. Engage the 8 claws to connect the 2 grommets.
