OUTER REAR VIEW MIRROR REASSEMBLY

CAUTION / NOTICE / HINT

Tech Tips


  • Use the same procedure for the RH side and LH side.

  • The following procedure is for the LH side.

PROCEDURE


  1. INSTALL OUTER MIRROR RETRACTOR (w/ Automatic Retractable Mirror)


    1. Install the 2 screws in the order shown in the illustration.

    2. Install a new frame sub-assembly to the housing with the 2 screws.

    3. Install in this Direction

      Pass a new wire harness sub-assembly through the frame sub-assembly as shown in the illustration.

    4. Connect the connector.

    5. Engage the 2 clamps.

    6. Connect the connector.

    7. Install the actuator sub-assembly with the 3 screws.

    8. Wind vinyl tape around the wire harness sub-assembly to secure it.

    9. Pass the wire harness sub-assembly through the base sub-assembly.

    10. Remove the vinyl tape.

    11. Using a T25 "TORX" socket wrench, install the base sub-assembly with 3 new screws.

      Note

      When installing the base sub-assembly, check that the wire harness sub-assembly is not caught between the base sub-assembly and body. Failure to do so may cause a short circuit.

    12. Engage the guide and 5 claws to install the lower cover.

    13. Pass the wire harness sub-assembly through a new gasket sub-assembly and engage the 3 guides to install the gasket sub-assembly.

      Note

      Make sure there is no clearance between the gasket sub-assembly and base sub-assembly.

    14. *a Marking

      Adjust the wire harness sub-assembly so that the marking is at the position shown in the illustration.

    15. Wind vinyl tape around the wire harness sub-assembly to secure it.

      Reference Measurement
      Area Measurement
      A 50 mm (1.97 in.)

      Note

      If the vinyl tape is wrinkled, water may run down the wire harness sub-assembly and enter the vehicle. Make sure to wind the vinyl tape properly.

    16. Connect each connector to a new adapter.

    17. *a Wire Harness Routing

      Route the longer part of the wire harness sub-assembly as shown in the illustration.

    18. *a Vinyl Tape

      Wind vinyl tape around the wire harness sub-assembly to secure it.

      Reference Measurement
      Area Measurement
      A 5.0 mm (0.197 in.)
      B 50 mm (1.97 in.)

  2. INSTALL NO. 2 OUTER MIRROR COVER


    1. Install in this Direction

      Engage the guide and 2 claws to install the No. 2 outer mirror cover as shown in the illustration.
