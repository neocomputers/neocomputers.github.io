PLUG-IN CHARGE CONTROL SYSTEM CUSTOMIZE PARAMETERS


  1. CUSTOMIZE HYBRID CONTROL SYSTEM

    The following items can be customized.

    Note


    • When the customer requests a change in a function, first make sure that the function can be customized.

    • Be sure to make a note of the current settings before customizing.

    • When troubleshooting a function, first make sure that the function is set to the default setting.


    1. Customizing with the multi-information display


      1. Turn the power switch on (IG).

      2. Select the setting tab in the multi-information display.

      3. Enter the following menus: Vehicle Settings / Charge settings.

      4. Select the setting by referring to the table below.

        Display Description Default Setting Relevant ECU
        Charge schedule Setting the timer charging. -

        • Scheduled Events

        • Charge Now

        • Next Charging Event

        		 Electric vehicle charger assembly
        Charge current Changing the upper limit of the charging current. MAX MAX / 8 A
        Charging Connector Lock*1 Changing the charging connector lock settings. Manual Lock Manual Lock / Auto Lock / Auto Lock & Auto Unlock
        Traction battery heater Setting "Traction Battery Heater" on/off. ON ON / OFF Battery ECU assembly

        *1: w/ Charging Connector Locking System (for Electric vehicle charger cable assembly (Type 1))
