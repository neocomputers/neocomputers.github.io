SPEED LIMITER SYSTEM DIAGNOSIS SYSTEM


  1. DESCRIPTION

    The hybrid vehicle control ECU controls the speed limiter system of the vehicle. The data and DTCs related to the speed limiter system can be read from the DLC3 of the vehicle. Use the GTS to check and solve the problem.

    Tech Tips

    If a vehicle speed sensor or any other related part malfunctions, the hybrid vehicle control ECU cancels control of vehicle speed automatically.

  2. CHECK DLC3


    1. Check the DLC3.

  3. CHECK INDICATOR


    1. *a Speed Limiter Indicator

      Turn the power switch on (IG).

    2. Check that the speed limiter indicator illuminates when the speed limiter system is turned on using the speed limiter main switch, and that the indicator goes out when the speed limiter system is turned off using the speed limiter switch.

      Tech Tips

      While driving with the speed limiter system controlling vehicle speed, the hybrid vehicle control ECU will automatically cancel control of vehicle speed by the speed limiter system when a malfunction occurs in one of the following: vehicle speed sensors or other related parts. When control of vehicle speed by the speed limiter system is automatically canceled, the speed limiter indicator turns off and a warning message is displayed. At the same time, a DTC is stored.
