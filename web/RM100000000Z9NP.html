STEERING COLUMN ASSEMBLY INSTALLATION

PROCEDURE


  1. ALIGN FRONT WHEELS FACING STRAIGHT AHEAD

  2. INSTALL STEERING COLUMN ASSEMBLY (for RHD)

    Note

    Make sure that the wire harness is not interfering with the steering column assembly.


    1. Install the steering column assembly with the bolt and 2 nuts.

      Torque:
      36 N*m  { 367 kgf*cm, 27 ft.*lbf }

    2. Connect each connector and engage each clamp to the steering column assembly.

    3. Engage the clamp.

    4. Connect the 2 connectors.

  3. INSTALL STEERING COLUMN ASSEMBLY (for LHD)


    1. Install the steering column assembly with the bolt and 2 nuts.

      Torque:
      36 N*m  { 367 kgf*cm, 27 ft.*lbf }

    2. Connect each connector and engage each clamp to the steering column assembly.

    3. Engage the clamp.

    4. Connect the 2 connectors.

  4. INSTALL NO. 2 STEERING INTERMEDIATE SHAFT ASSEMBLY


    1. *a Matchmark
      Install in this direction

      Align the matchmarks on the No. 2 steering intermediate shaft assembly and steering column assembly.

    2. Install the No. 2 steering intermediate shaft assembly to the steering column assembly.

    3. Install the bolt.

      Torque:
      64 N*m  { 653 kgf*cm, 47 ft.*lbf }

  5. CONNECT NO. 2 STEERING INTERMEDIATE SHAFT ASSEMBLY


    1. *a Matchmark
      Connect in this direction

      Align the matchmarks on the No. 2 steering intermediate shaft assembly and steering gear assembly.

    2. Connect the No. 2 steering intermediate shaft assembly to the steering gear assembly.

    3. Install the bolt.

      Torque:
      64 N*m  { 653 kgf*cm, 47 ft.*lbf }

  6. INSTALL COLUMN HOLE COVER SILENCER SHEET


    1. Engage the 2 claws to install the column hole cover silencer sheet.

    2. Engage the claw to close the column hole cover silencer sheet.

  7. INSTALL STOP LIGHT SWITCH ASSEMBLY

    Click here

  8. INSTALL NO. 2 AIR DUCT (for RHD)


    1. Engage the 3 claws to install a new No. 2 air duct.

    2. Install the bolt.

      Torque:
      9.8 N*m  { 100 kgf*cm, 87 in.*lbf }

  9. INSTALL PARKING BRAKE MOUNTING BRACKET (for RHD)


    1. *a Bolt
      *b Screw

      Install the parking brake mounting bracket with the bolt and screw.

      Torque:
      Bolt
      10 N*m  { 102 kgf*cm, 7 ft.*lbf }

  10. INSTALL NO. 1 AIR DUCT (for LHD)


    1. Engage the 3 claws to install a new No. 1 air duct.

    2. Install the 2 bolts.

      Torque:
      9.8 N*m  { 100 kgf*cm, 87 in.*lbf }

  15. INSTALL TURN SIGNAL SWITCH ASSEMBLY WITH SPIRAL CABLE SUB-ASSEMBLY

    Note


    • Do not replace the spiral cable with sensor sub-assembly with the auxiliary battery connected and the power switch on (IG).

    • Do not rotate the spiral cable with sensor sub-assembly without the steering wheel assembly installed with the auxiliary battery connected and the power switch on (IG).

    • Ensure that the steering wheel assembly is installed and aligned straight when inspecting the steering sensor.


    1. Engage the 3 claws to install the turn signal switch assembly with spiral cable sub-assembly to the steering column assembly.

    2. Connect each connector to the turn signal switch assembly with spiral cable sub-assembly.

  16. INSTALL UPPER STEERING COLUMN COVER


    1. Engage the 2 claws and 4 clips to connect the upper steering column cover.

    2. Engage the claw to install the upper steering column cover.

  17. INSTALL LOWER STEERING COLUMN COVER SUB-ASSEMBLY

    Note

    If the lower steering column cover sub-assembly is installed in the incorrect order, the parts may break.


    1. Install in this Direction

      Engage the 3 claws as shown in the illustration.

    2. Engage the 2 claws.

    3. Install the 2 screws.
