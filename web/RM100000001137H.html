CHARGE LID OPENER UNIT INSTALLATION

PROCEDURE


  1. INSTALL BATTERY CHARGER CONNECTOR OPENING LID SUB-ASSEMBLY


    1. Install in this Direction

      Engage the 5 guides as shown in the illustration.

    2. Install the battery charger connector opening lid sub-assembly with the 3 nuts.

      Torque:
      7.5 N*m  { 76 kgf*cm, 66 in.*lbf }

  2. INSTALL BATTERY SERVICE OPENING LID SUB-ASSEMBLY


    1. Install in this Direction

      Engage the 4 guides and 2 claws to install the battery service opening lid sub-assembly as shown in the illustration.

  3. INSTALL CONNECTOR COVER


    1. Engage the clamp to install the connector cover.

  7. INSTALL FUEL FILLER OPENING LID LOCK BRACKET


    1. Engage the fuel tank drain plug shield to the fuel filler opening lid lock bracket.

    2. Engage the guide.

    3. *A for Type A
      *B for Type B
      *C for Type C
      *a Bolt A
      *b Bolt B

      Install the fuel filler opening lid lock bracket with the 4 bolts.

      Torque:
      Bolt A, Bolt B(for Type A)
      12 N*m  { 122 kgf*cm, 9 ft.*lbf }
      Bolt B(for Type B,C)
      10 N*m  { 102 kgf*cm, 7 ft.*lbf }

    4. Engage the 4 clamps.

    5. Connect the 2 connectors.

  8. CONNECT AC CHARGER INLET CABLE WITH CABLE EV CHARGER LOCK ASSEMBLY (w/ CABLE EV CHARGER LOCK ASSEMBLY)


    1. *A for Type A
      *B for Type B
      Nut
      Bolt

      Connect the AC charger inlet cable with cable EV charger lock assembly with the 4 nuts.

      Torque:
      8.0 N*m  { 82 kgf*cm, 71 in.*lbf }

    2. Install the bolt.

      Torque:
      for Type A
      10 N*m  { 102 kgf*cm, 7 ft.*lbf }
      for Type B
      7.0 N*m  { 71 kgf*cm, 62 in.*lbf }

    3. Engage the 3 clamps.

    4. Connect the connector.

  9. CONNECT AC CHARGER INLET CABLE (w/o CABLE EV CHARGER LOCK ASSEMBLY)


    1. *A for Type A
      *B for Type B
      Nut
      Bolt

      Connect the AC charger inlet cable with the 4 nuts.

      Torque:
      8.0 N*m  { 82 kgf*cm, 71 in.*lbf }

    2. Install the bolt.

      Torque:
      for Type A
      10 N*m  { 102 kgf*cm, 7 ft.*lbf }
      for Type B
      7.0 N*m  { 71 kgf*cm, 62 in.*lbf }

    3. Engage the 3 clamps.
