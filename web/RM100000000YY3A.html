SPEED LIMITER SYSTEM, Diagnostic DTC:U012200

DTC Code DTC Name
U012200 Lost Communication with Vehicle Dynamics Control Module

DESCRIPTION

The hybrid vehicle control ECU communicates with each sensor and ECU via CAN communication.

If there are any malfunctions in the communication circuit, one or more CAN communication system DTCs are stored.

DTC No. Detection Item DTC Detection Condition Trouble Area
U012200 Lost Communication with Vehicle Dynamics Control Module While speed limiter is operating, communication stop between skid control ECU (brake booster with master cylinder assembly) and hybrid vehicle control ECU is detected.

  • CAN communication circuit

  • Skid control ECU (brake booster with master cylinder assembly)

  • Hybrid vehicle control ECU

CAUTION / NOTICE / HINT

Note

When this DTC is stored, speed limiter system operation will be prohibited. Even after DTCs are cleared, operation of the speed limiter system will remain prohibited until the following is performed.


  • Turn the power switch from off to on (IG), drive the vehicle at a speed of 15 km/h or more for at least 10 seconds, then turn the speed limiter system on.
