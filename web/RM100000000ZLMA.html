POWER DOOR LOCK CONTROL SYSTEM OPERATION CHECK


  1. CHECK POWER DOOR LOCK OPERATION

    Note

    The operation check below is based on the non-customized initial condition of the vehicle.


    1. Check basic functions.


      1. Check that all of the doors lock when the lock side of the door control switch is pressed.

      2. Check that all of the doors unlock when the unlock side of the door control switch is pressed.

      3. Check that all of the doors lock when the driver door key cylinder is turned to lock using the mechanical key.

      4. Check that all of the doors unlock when the driver door key cylinder is turned to unlock using the mechanical key.*1

      5. Check that only the driver door unlocks when the driver door lock cylinder is turned to unlock once using the key and all of the doors unlock when it is turned to unlock again.*2


        • *1: w/o Canister Pump Module

        • *2: w/ Canister Pump Module

    2. Check the key lock-in prevention function.

      Note

      In order to prevent the key from being locked in the vehicle, the following inspection should be performed with the driver door window open.


      1. Turn the power switch on (IG) or on (ACC).

      2. With the driver door open, check that all of the doors unlock immediately after the door lock knob for the driver door is pressed.

      3. With the driver door open, check that all of the doors unlock immediately after the lock side of the door control switch is pressed.

      4. With the driver door open, press the driver door lock knob and hold it for 2 seconds or more, then close the driver door and check that all of the doors unlock.

    3. Check the security function of the door lock control system.


      1. Close all of the doors and leave the driver door window open so that the door control switch can be operated from outside the vehicle. (Step 1)

      2. Open the driver door and remove the key from the vehicle. With the door still open, lock the door using the lock knob. Hold the outside handle of the driver door, open and close the door while holding the handle open (confirm that the lock knob remained in the lock position). Then, check that the doors do not unlock when the unlock side of the door control switch is pressed from outside the vehicle.*1

      3. Open the driver door and remove the key from the vehicle. With the door still open, lock the door using the door lock knob. Close the driver door. Then, check that the doors do not unlock when the unlock side of the door control switch is pressed from outside the vehicle.*2


        • *1: w/o Canister Pump Module

        • *2: w/ Canister Pump Module

      4. Starting from Step 1, with the key outside the vehicle, close and lock the driver door using the mechanical key. Then, check that the doors do not unlock when the unlock side of the door control switch is pressed from outside the vehicle.

      5. Starting from Step 1, with the key outside the vehicle, close and lock the driver door using wireless key operation or smart key operation. Then, check that the doors do not unlock when the unlock side of the door control switch is pressed from outside the vehicle.

        Tech Tips

        Check that the security function of the door lock control system is canceled under the following conditions:


        • The power switch is turned on (IG).

        • The driver door is unlocked using the key.

        • The unlock side of the door control switch is pressed after the door lock knob is unlocked manually.

        • The doors are unlocked by wireless operation.

        • The doors are unlocked by entry operation.

    4. Check the key-linked 2-step unlock function. (w/ Canister Pump Module)

      Tech Tips

      The key-linked 2-step unlock function can be customized. Make sure that function is ON before this procedure.

      1. Lock all doors.

      2. Check that only the driver door unlocks when the driver door lock cylinder is turned to unlock once using the key and all of the doors unlock when it is turned to unlock again.

    5. Check the shift linked automatic door lock function. (w/ Canister Pump Module)

      Tech Tips

      The shift linked automatic door lock function can be customized. Make sure that function is ON before this procedure.

      Click here


      1. With park (P) selected and the power switch on (READY), check that all doors lock automatically when the shift lever is moved to select another shift state.

    6. Check the speed-sensitive automatic door lock function. (w/ Canister Pump Module)

      Tech Tips

      The speed-sensitive automatic door lock function can be customized. Make sure that function is ON before this procedure.

      Click here


      1. When any door is unlocked and the vehicle is driven at approximately 20 km/h (12 mph) or more, check that all of the doors lock automatically.

    7. Check the shift linked automatic door unlock function. (w/ Canister Pump Module)

      Tech Tips

      The shift linked automatic door unlock function can be customized. Make sure that function is ON before this procedure.

      Click here


      1. With a shift state other than park (P) selected and the power switch on (READY), check that all doors unlock automatically when the P position switch (transmission shift main switch) is pushed.

    8. Check the driver door-linked automatic door unlock function. (w/ Canister Pump Module)

      Tech Tips

      The driver door-linked automatic door unlock function can be customized. Make sure that function is ON before this procedure.

      1. When the driver door is closed, turning the power switch from on (IG) to off and opening the driver door within approximately 43 seconds will automatically unlock all doors.

  2. CHECK DOUBLE LOCKING FUNCTION (w/ Double Locking System)

    Note


    • Never activate the double locking function when there are people in the vehicle because the doors cannot be opened from the inside. If the doors are locked by accident, unlock the door by using the wireless unlock operation or entry unlock operation.

    • The double locking function is not applicable to the back door.


    1. Check that the double locking function is set by using the wireless door lock operation.


      1. Open all windows.

      2. Turn the power switch off.

      3. Open and close the driver door, and make sure that all of the doors including the back door are closed securely.

      4. Press the electrical key transmitter sub-assembly lock switch twice within 5 seconds, and check that the hazard warning lights flash once as an answer-back.

      5. Try to unlock all of the doors with the inside handle of the vehicle, and check that none of the doors unlock.

    2. Check that the double locking function is set by using the entry lock operation.


      1. Open all windows.

      2. Turn the power switch off.

      3. Open and close the driver door, and make sure that all of the doors including the back door are closed securely.

      4. Touch the lock sensor on the outside door handle twice while holding the electrical key transmitter sub-assembly within 5 seconds, and check that the hazard warning lights flash once as an answer-back.

      5. Try to unlock all of the doors with the inside handle of the vehicle, and check that none of the doors unlock.

    3. Check that the double locking function is canceled.


      1. Unlock the door by using the wireless unlock operation or entry unlock operation while the double locking function is set, and check that the hazard warning lights flash twice as an answer-back.

      2. Check that the doors can be opened both by the inside of the handle and the outside of the handle.

        Tech Tips

        If the transmitter battery is depleted, only the driver door can be opened using the key. However, the theft deterrent system still remains on. The theft alarm will sound when the door is opened without using the electrical key transmitter sub-assembly.
