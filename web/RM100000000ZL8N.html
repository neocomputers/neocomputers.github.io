AIR CONDITIONING UNIT REASSEMBLY

PROCEDURE


  1. INSTALL NO. 2 CONDENSER ASSEMBLY


    1. Install in this Direction

      Install the No. 2 condenser assembly as shown in the illustration.

  2. INSTALL EVAPORATOR TEMPERATURE SENSOR

    Click here

  3. INSTALL NO. 1 COOLER EVAPORATOR SUB-ASSEMBLY


    1. Install the No. 1 cooler evaporator sub-assembly with evaporator temperature sensor to the upper heater case.

    2. Engage the clamp.

    3. Engage the 10 claws to install the upper heater case with No. 1 cooler evaporator sub-assembly to the lower heater case.

    4. Install the 2 screws.

    5. Sufficiently apply compressor oil to 2 new O-rings and the fitting surfaces of the No. 1 cooler evaporator sub-assembly.

      Compressor Oil
      ND-OIL 11 or equivalent

    6. Install the 2 O-rings to the No. 1 cooler evaporator sub-assembly.

      Note

      Keep the O-rings and O-ring fitting surfaces free of foreign matter.

    7. Using a 4 mm hexagon socket wrench, install the connector tube with the 2 hexagon bolts.

      Torque:
      3.5 N*m  { 36 kgf*cm, 31 in.*lbf }

  4. INSTALL COOLER PIPE GROMMET


    1. Install the cooler pipe grommet.

  5. INSTALL DRAIN HOSE


    1. Install the drain hose.

  6. INSTALL DISCHARGE TEMPERATURE SENSOR

    Click here

  7. INSTALL COOLER PACKING

    Click here

  8. INSTALL INTERNAL CONDENSER TEMPERATURE SENSOR

    Click here

  9. INSTALL COOLER PACKING

    Click here

  10. INSTALL NO. 1 DISCHARGE TUBE


    1. Remove the vinyl tape from the No. 1 discharge tube.

    2. Sufficiently apply compressor oil to 2 new O-rings and the fitting surfaces of the No. 1 discharge tube.

      Compressor Oil
      ND-OIL 11 or equivalent

    3. Install the 2 O-rings to the No. 1 discharge tube.

      Note

      Keep the O-rings and O-ring fitting surfaces free of foreign matter.

    4. for LHD:


      1. *a Clamp
        *b Guide
        Bolt
        Nut
        Install in this Direction

        Install the No. 1 discharge tube with thermistor with the bolt and nut.

        Torque:
        5.4 N*m  { 55 kgf*cm, 48 in.*lbf }

      2. Engage each guide and each clamp.

    5. for RHD:


      1. *a Clamp
        *b Guide
        Bolt
        Nut
        Install in this Direction

        Install the No. 1 discharge tube with thermistor with the bolt and nut.

        Torque:
        5.4 N*m  { 55 kgf*cm, 48 in.*lbf }

      2. Engage each guide and each clamp.

  11. INSTALL GROMMET


    1. *a Reference Point

      Install the grommet as shown in the illustration.

      Note

      Install the grommet with the arrow facing down.

  12. INSTALL HEATER RADIATOR UNIT SUB-ASSEMBLY


    1. Install in this Direction

      Install the heater radiator unit sub-assembly as shown in the illustration.

  13. INSTALL HEATER CLAMP


    1. Engage the 4 claws to install the heater clamp.

  14. INSTALL HEATER GROMMET


    1. *a Reference Point

      Install the heater grommet as shown in the illustration.

      Note

      Install the heater grommet with the arrow facing up.

  15. INSTALL NO. 3 AIR CONDITIONING RADIATOR DAMPER SERVO SUB-ASSEMBLY


    1. for LHD:


      1. *a Reference Point

        Using the reference points, install the No. 3 air conditioning radiator damper servo sub-assembly with the 2 screws.

    2. for RHD:


      1. *a Reference Point

        Using the reference points, install the No. 3 air conditioning radiator damper servo sub-assembly with the 2 screws.

  16. INSTALL NO. 2 AIR CONDITIONING RADIATOR DAMPER SERVO SUB-ASSEMBLY


    1. for Single Air Conditioning System:


      1. Align each gear on the air conditioning radiator assembly as shown in the illustration, and then check that the gears of the No. 2 air conditioning radiator damper servo sub-assembly are aligned as shown in the illustration.

        *a Reference Point - -

      2. Install the No. 2 air conditioning radiator damper servo sub-assembly with the 3 screws.

    2. for Dual Air Conditioning System:


      1. Align each gear on the air conditioning radiator assembly as shown in the illustration, and then check that the gears of the No. 2 air conditioning radiator damper servo sub-assembly are aligned as shown in the illustration.

        *a Reference Point - -
      2. *a Reference Point

        Using the reference points, install the No. 2 air conditioning radiator damper servo sub-assembly with the 3 screws.

  17. INSTALL NO. 1 AIR CONDITIONING RADIATOR DAMPER SERVO SUB-ASSEMBLY


    1. for LHD:


      1. *a Link

        Connect the 3 links of the No. 1 air conditioning radiator damper servo sub-assembly to the 3 links of the air conditioning radiator assembly as shown in the illustration.

      2. Install the No. 1 air conditioning radiator damper servo sub-assembly with the 2 screws.

    2. for RHD:


      1. *a Link

        Connect the 2 links of the No. 1 air conditioning radiator damper servo sub-assembly to the 2 links of the air conditioning radiator assembly as shown in the illustration.

      2. Install the No. 1 air conditioning radiator damper servo sub-assembly with the 2 screws.

  18. INSTALL DRAIN COOLER HOSE


    1. *a Hose Notch
      *b Rib

      Align the hose notch with the rib as shown in the illustration and install the drain cooler hose.

  19. INSTALL AIR CONDITIONING HARNESS ASSEMBLY


    1. for LHD:


      1. Engage each clamp.

      2. Connect each connector to install the air conditioning harness assembly.

    2. for RHD:


      1. Engage each clamp.

      2. Connect each connector to install the air conditioning harness assembly.

  20. INSTALL AIR CONDITIONING AMPLIFIER ASSEMBLY


    1. for LHD:


      1. Install in this Direction

        Engage the guide to temporarily install the air conditioning amplifier assembly as shown in the illustration.

      2. Install the air conditioning amplifier assembly with the screw.

      3. Connect the connector.

    2. for RHD:


      1. Install in this Direction

        Engage the guide to temporarily install the air conditioning amplifier assembly as shown in the illustration.

      2. Install the air conditioning amplifier assembly with the screw.

      3. Connect the connector.

  21. INSTALL BLOWER ASSEMBLY

    Click here

  22. INSTALL ASPIRATOR


    1. Engage the 2 claws to install the aspirator.

  23. INSTALL NO. 1 AIR DUCT (for RHD)


    1. Engage the 3 claws.

    2. Install a new No. 1 air duct with the screw.

  24. INSTALL NO. 2 AIR DUCT (for LHD)


    1. Engage the 3 claws.

    2. Install a new No. 2 air duct with the screw.
