HYBRID CONTROL SYSTEM Pattern Select Switch EV City Mode Circuit

DESCRIPTION

When a sufficient amount of electricity for EV driving is remaining in the HV battery, the operation mode can be switched to EV City mode.

EV City mode limits motor output and minimizes the operation of the gasoline engine. Therefore, the vehicle can be driven with only electric motor in city areas, etc.

When in EV City mode, the "EV CITY" indicator illuminates.
