INVERTER BATTERY INSTALLATION

PROCEDURE


  1. INSTALL INVERTER BATTERY


    1. Temporarily install the inverter battery with the 2 bolts.

    2. Fully tighten the 2 bolts in the order shown in the illustration.

      Torque:
      12.5 N*m  { 127 kgf*cm, 9 ft.*lbf }

    3. Engage the 2 clamps.

    4. Connect the inverter battery connector.
