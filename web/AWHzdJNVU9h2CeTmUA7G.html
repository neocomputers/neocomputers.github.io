ROOF ANTENNA INSTALLATION

PROCEDURE


  1. INSTALL ROOF ANTENNA ASSEMBLY


    1. When reusing the roof antenna assembly:


      1. Install a new seal.

    2. Install in this Direction (1)
      Install in this Direction (2)

      Push the roof antenna assembly in the direction indicated by the arrow (1) shown in the illustration to engage the guide.

    3. Push the roof antenna assembly in the direction indicated by the arrow (2) shown in the illustration to engage the 2 guides and 5 claws and install the roof antenna assembly.

  2. INSTALL ROOF ANTENNA ASSEMBLY WITH COVER


    1. Install in this Direction

      Install a new washer and holder as shown in the illustration.

    2. Install the roof antenna assembly with cover with the bolt.

      Torque:
      9.5 N*m  { 97 kgf*cm, 84 in.*lbf }

    3. Connect the connector

  3. INSTALL ROOF HEADLINING ASSEMBLY
