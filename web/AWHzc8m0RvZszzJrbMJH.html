BATTERY COOLING FILTER REMOVAL

PROCEDURE


  1. DISCONNECT REAR DOOR OPENING TRIM WEATHERSTRIP RH


    1. Disconnect the rear door opening trim weatherstrip RH.

  2. REMOVE FRONT DECK SIDE TRIM COVER RH


    1. Disengage the 3 claws.

    2. Disengage the 3 guides to remove the front deck side trim cover RH.

  3. DISCONNECT REAR DOOR OPENING TRIM WEATHERSTRIP LH

    Tech Tips

    Use the same procedure as for the RH side.

  4. REMOVE FRONT DECK SIDE TRIM COVER LH

    Tech Tips

    Use the same procedure as for the RH side.

  5. REMOVE NO. 1 HV BATTERY INTAKE FILTER

    Tech Tips

    If the message "Maintenance required for Traction battery cooling parts" is displayed on the multi-information display in the combination meter assembly, inspect the No. 1 HV battery intake filter.
