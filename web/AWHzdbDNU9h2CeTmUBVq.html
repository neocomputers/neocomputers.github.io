EVAPORATOR PRESSURE REGULATOR INSTALLATION

PROCEDURE


  1. INSTALL EVAPORATOR PRESSURE REGULATOR


    1. Remove the vinyl tape from the cooler refrigerant suction pipe A and cooler refrigerant suction pipe B.

    2. Sufficiently apply compressor oil to 2 new O-rings and the fitting surfaces of the cooler refrigerant suction pipe A and cooler refrigerant suction pipe B.

      Compressor Oil
      ND-OIL 11 or equivalent

    3. Install the 2 O-rings to the cooler refrigerant suction pipe A and cooler refrigerant suction pipe B.

      Note

      Keep the O-rings and O-ring fitting surfaces free of foreign matter.

    4. *a Reference Point

      Connect the cooler refrigerant suction pipe A and cooler refrigerant suction pipe B as shown in the illustration.

      Note

      Install the evaporator pressure regulator with the arrow facing front.

    5. Install the evaporator pressure regulator with the 2 bolts.

      Torque:
      9.8 N*m  { 100 kgf*cm, 87 in.*lbf }

  2. INSTALL NO. 2 COOLER PIPE PACKING


    1. Remove any remaining No. 2 cooler pipe packing from the evaporator pressure regulator and cooler refrigerant suction pipe A.

    2. Remove the release paper from a new No. 2 cooler pipe packing.

    3. *1 No. 2 Cooler Pipe Packing
      *2 Evaporator Pressure Regulator
      *a View B
      *b Installation Angle (120°)

      Install the No. 2 cooler pipe packing as shown in the illustration.

      Dimension Measurement
      A 60.0 to 70.0 mm (2.36 to 2.76 in.)
