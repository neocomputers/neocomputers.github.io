SOLAR CHARGING SYSTEM, Diagnostic DTC:U010087, U029387

DTC Code DTC Name
U010087 Lost Communication With ECM/PCM "A" Missing Message
U029387 Lost Communication with Hybrid/EV Powertrain Control Module Missing Message

DESCRIPTION

The solar energy control unit communicates with the ECM, hybrid vehicle control ECU, combination meter assembly and certification ECU (smart key ECU assembly) via CAN communication.

DTC No. Detection Item DTC Detection Condition Trouble Area Warning Indicate
U010087 Lost Communication With ECM/PCM "A" Missing Message

A CAN communication error between the ECM and solar energy control unit occurs. (CAN communication system malfunction)

(1 trip detection logic)

 CAN communication system

Solar Charging Warning Light:

Does not come on
U029387 Lost Communication with Hybrid/EV Powertrain Control Module Missing Message

A CAN communication error between the hybrid vehicle control ECU and solar energy control unit occurs. (CAN communication system malfunction)

(1 trip detection logic)

 CAN communication system

Solar Charging Warning Light:

Does not come on
