ELECTRONICALLY CONTROLLED BRAKE SYSTEM, Diagnostic DTC:C1436

DTC Code DTC Name
C1436 Malfunction in Yaw Rate Sensor

DESCRIPTION

The airbag sensor assembly has a built-in yaw rate and acceleration sensor and detects the vehicle condition using 2 circuits (GL1, GL2).

When the skid control ECU (brake booster with master cylinder assembly) detects improper installation of the yaw rate and acceleration sensor (airbag sensor assembly) or an abnormality in the difference between the yaw rate sensor value and the control value estimated based on the acceleration sensor, steering angle sensor and speed sensor signals, DTC C1436 is stored.

Either of the following is detected:


  1. With the vehicle stationary, the yaw rate sensor output value is not 0 deg/s.

  2. Abnormal comparison value.

  • Yaw rate sensor (airbag sensor assembly) installed improperly
