REAR SEAT ASSEMBLY INSTALLATION

CAUTION / NOTICE / HINT

CAUTION:

Wear protective gloves. Sharp areas on the parts may injure your hands.

PROCEDURE


  1. INSTALL REAR SEAT CUSHION LOCK HOOK


    1. Install in this Direction

      Engage the 4 claws to install 2 new rear seat cushion lock hooks as shown in the illustration.

      Tech Tips

      Use the same procedure for the RH side and LH side.

  2. INSTALL REAR SEAT CUSHION ASSEMBLY LH


    1. Place the rear seat cushion assembly LH in the cabin.

      Note

      Be careful not to damage the vehicle body.

    2. *a Front Side Rear Seat Cushion Frame Hook
      *b Rear Side Rear Seat Cushion Frame Hook
      Install in this Direction (1)
      Install in this Direction (2)

      Engage the rear seat cushion frame hook on the rear side of the rear seat cushion assembly LH as shown in the illustration.

    3. Engage the rear seat cushion frame hook on the front side of the rear seat cushion assembly LH as shown in the illustration.

    4. *a Rear Seat Cushion Frame Hook Outer Side
      Install in this Direction

      Engage the rear seat cushion frame hook on the outer side of the rear seat cushion assembly LH as shown in the illustration to install the rear seat cushion assembly LH.

      Note

      Confirm that the rear seat cushion assembly LH is securely installed.

  3. INSTALL REAR SEAT CUSHION ASSEMBLY RH

    Tech Tips

    Use the same procedure as for the LH side.

  4. INSTALL REAR SEATBACK ASSEMBLY LH


    1. Place the rear seatback assembly LH in the cabin.

      Note

      Be careful not to damage the vehicle body.

    2. Engage the 2 guides.

    3. Install the rear seatback assembly LH with the 2 bolts.

      Torque:
      36.8 N*m  { 375 kgf*cm, 27 ft.*lbf }

    4. Engage the 2 fasteners.

    5. Pull back the rear seatback assembly LH.

  5. INSTALL REAR SEATBACK ASSEMBLY RH

    Note

    To prevent the damage to the damper, do not subject it to strong impacts or apply excessive force to the damper such as by leaning on the rear seatback assembly RH.


    1. Place the rear seatback assembly RH in the cabin.

      Note

      Be careful not to damage the vehicle body.

    2. Engage the 2 guides.

    3. Install the rear seatback assembly RH with the 2 bolts.

      Torque:
      36.8 N*m  { 375 kgf*cm, 27 ft.*lbf }

    4. Engage the fastener.

  6. INSTALL REAR SEATBACK HINGE COVER


    1. Engage the 3 claws to install rear seatback hinge cover.

    2. Pull back the rear seatback assembly RH.

  7. INSTALL REAR SEAT HEADREST ASSEMBLY (for LH Side)


    1. Install the rear seat headrest assembly.

  8. INSTALL REAR SEAT HEADREST ASSEMBLY (for RH Side)


    1. Install the rear seat headrest assembly.
