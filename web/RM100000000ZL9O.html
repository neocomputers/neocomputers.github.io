FRONT EVAPORATOR TEMPERATURE SENSOR INSTALLATION

PROCEDURE


  1. INSTALL EVAPORATOR TEMPERATURE SENSOR


    1. *a Fixed Part
      *b Sensor Part

      Install the evaporator temperature sensor as shown in the illustration.

      Installation Position
      Part Length
      A 50.0 mm (1.97 in.)
      B 61.1 mm (2.41 in.)

      Note


      • Be sure to insert the evaporator temperature sensor only once because reinserting it into the same position will not allow it to be firmly secured.

      • When reusing the No. 1 cooler evaporator sub-assembly, insert the evaporator temperature sensor one row next to the one that has been used previously (X in the illustration).

      • After inserting the evaporator temperature sensor, do not apply excessive force to the wire.

      • Directly insert the evaporator temperature sensor until the edge of the plastic case "a" comes into contact with the No. 1 cooler evaporator sub-assembly "b".
