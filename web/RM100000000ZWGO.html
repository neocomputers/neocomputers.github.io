  1. CUSTOMIZE POWER MIRROR CONTROL SYSTEM

    Tech Tips

    The following items can be customized.

    Note


    • When the customer requests a change in a function, first make sure that the function can be customized.

    • Record the current settings before customizing.


    1. Customizing with the GTS


      1. Connect the GTS to the DLC3.

      2. Turn the power switch on (IG).

      3. Turn the GTS on.

      4. Enter the following menus: Customize Setting / Others.

      5. Select the setting by referring to the table below.


        Others
        Tester Display Description Default Setting ECU
        Auto Fold Mirror Function that changes the condition under which the outer mirrors automatically retract* Door Lock 01:ACC,10:Door Lock,11:OFF Main body ECU (Multiplex network body ECU)
