POWER WINDOW CONTROL SYSTEM DIAGNOSIS SYSTEM


  1. DESCRIPTION


    1. Power window control system data and Diagnostic Trouble Codes (DTCs) can be read through the vehicle Data Link Connector 3 (DLC3). When the system seems to be malfunctioning, use the GTS to check for malfunctions and perform repairs.
