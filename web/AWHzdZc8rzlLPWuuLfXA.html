COMPRESSOR INSTALLATION

PROCEDURE


  1. ADJUST COMPRESSOR OIL


    1. When replacing the compressor with motor assembly with a new one, gradually discharge the inert gas from the service valve, and drain a total of 80 cc (2.7 fl. oz) of the compressor oil from the positions shown in the illustration before installation.

      Note


      • If a new compressor with motor assembly is installed without removing some oil, there will be too much oil in the system due to the oil remaining in the pipes of the vehicle. Excessive oil in the system prevents heat exchange in the refrigeration cycle and causes ineffective cooling.

      • If the amount of oil remaining in the old compressor with motor assembly is too small, check the air conditioning system for oil leaks.

      • Be sure to use ND-OIL 11 or equivalent compressor oil. If any compressor oil other than ND-OIL 11 is used, compressor with motor assembly insulation performance may decrease, resulting in leakage of electric power.

  2. INSTALL COMPRESSOR WITH MOTOR ASSEMBLY


    1. for Type A:


      1. Using an E8 "TORX" socket wrench, temporarily install the compressor with motor assembly with the 2 stud bolts.

        Torque:
        9.8 N*m  { 100 kgf*cm, 87 in.*lbf }

      2. Install the compressor with motor assembly with the bolt and 2 nuts.

        Torque:
        25 N*m  { 255 kgf*cm, 18 ft.*lbf }

        Tech Tips

        Tighten the bolt and nuts in the order shown in the illustration.

    2. for Type B:


      1. Install the compressor with motor assembly with the 3 bolts.

        Torque:
        25 N*m  { 255 kgf*cm, 18 ft.*lbf }

        Tech Tips

        Tighten the 3 bolts in the order shown in the illustration.

    3. Connect the bracket with the bolt.

      Torque:
      8.0 N*m  { 82 kgf*cm, 71 in.*lbf }

    4. Connect the 2 connectors.

    5. *a Green-colored Lock
      Slide

      Connect the connector and slide the green-colored lock as shown in the illustration to lock it securely.

      CAUTION:

      Make sure to wear insulated gloves.

      Note

      Make sure that the connector is connected securely.

  3. CONNECT NO. 1 DISCHARGE HOSE SUB-ASSEMBLY


    1. Remove the vinyl tape from the No. 1 discharge hose sub-assembly.

    2. Sufficiently apply compressor oil to a new O-ring and the fitting surface of the compressor with motor assembly.

      Compressor Oil
      ND-OIL 11 or equivalent

    3. Install the O-ring to the No. 1 discharge hose sub-assembly.

      Note

      Keep the O-ring and O-ring fitting surface free of foreign matter.

    4. Connect the No. 1 discharge hose sub-assembly to the compressor with motor assembly with the bolt.

      Torque:
      9.8 N*m  { 100 kgf*cm, 87 in.*lbf }

  4. CONNECT DISCHARGE HOSE SUB-ASSEMBLY


    1. Remove the vinyl tape from the discharge hose sub-assembly.

    2. Sufficiently apply compressor oil to a new O-ring and the fitting surface of the compressor with motor assembly.

      Compressor Oil
      ND-OIL 11 or equivalent

    3. Install the O-ring to the discharge hose sub-assembly.

      Note

      Keep the O-ring and O-ring fitting surface free of foreign matter.

    4. Connect the discharge hose sub-assembly to the compressor with motor assembly with the bolt.

      Torque:
      9.8 N*m  { 100 kgf*cm, 87 in.*lbf }

  5. INSTALL INLET NO. 1 AIR CLEANER


    1. Install the inlet No. 1 air cleaner with the 2 bolts.

      Torque:
      4.0 N*m  { 41 kgf*cm, 35 in.*lbf }

  6. INSTALL SUCTION HOSE SUB-ASSEMBLY


    1. Remove the vinyl tape from the suction hose sub-assembly.

    2. Sufficiently apply compressor oil to 2 new O-rings and the fitting surfaces of the suction hose sub-assembly.

      Compressor Oil
      ND-OIL 11 or equivalent

    3. Install the 2 O-rings to the suction hose sub-assembly.

      Note

      Keep the O-rings and O-ring fitting surfaces free of foreign matter.

    4. Install the suction hose sub-assembly with the 2 bolts.

      Torque:
      9.8 N*m  { 100 kgf*cm, 87 in.*lbf }
