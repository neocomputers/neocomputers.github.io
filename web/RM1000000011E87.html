BATTERY CURRENT SENSOR INSTALLATION

PROCEDURE


  1. INSTALL BATTERY STATE SENSOR ASSEMBLY


    1. Engage the 2 claws to install the battery state sensor assembly to the battery current sensor holder.

    2. Install the battery state sensor assembly to the auxiliary battery and tighten the nut.

      Torque:
      5.4 N*m  { 55 kgf*cm, 48 in.*lbf }

    3. Connect the engine wire to the battery state sensor assembly with the nut.

      Torque:
      7.6 N*m  { 77 kgf*cm, 67 in.*lbf }

      Note

      When disconnecting the engine wire, some systems need to be initialized after the engine wire is reconnected.

      Click here

    4. Connect the battery state sensor assembly connector.

    5. Engage the 2 claws to connect the wire harness to the battery current sensor holder.
