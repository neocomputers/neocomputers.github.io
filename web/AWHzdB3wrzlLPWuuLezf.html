MILLIMETER WAVE RADAR SENSOR REASSEMBLY

CAUTION / NOTICE / HINT

Note


  • Do not damage the millimeter wave radar sensor assembly.

  • If the No. 1 millimeter wave radar sensor bracket has been removed/installed, be sure to perform adjustment.

PROCEDURE


  1. INSTALL NO. 1 MILLIMETER WAVE RADAR SENSOR BRACKET


    1. Temporarily install the No. 1 millimeter wave radar sensor bracket with the 2 screws.

    2. Tighten the 2 screws to install the No. 1 millimeter wave radar sensor bracket.
