BACK-UP LIGHT BULB INSTALLATION

CAUTION / NOTICE / HINT

Tech Tips


  • Use the same procedure for the RH side and LH side.

  • The following procedure is for the LH side.

PROCEDURE


  1. INSTALL BACK-UP LIGHT BULB


    1. Install a new back-up light bulb to the No. 3 luggage room wire.

    2. Install in this Direction

      Turn the No. 3 luggage room wire with the back-up light bulb as shown in the illustration to connect them as a unit.

  2. INSTALL NO. 2 FLOOR UNDER COVER (for LH Side)


    1. Install in this Direction

      Engage the 2 clips to temporarily install the No. 2 floor under cover as shown in the illustration.

    2. Install the No. 2 floor under cover with the 3 clips.

    3. Install the clip.

    4. Connect in this Direction

      Engage the 2 claws as shown in the illustration.

    5. Connect the rear bumper assembly with the clip.

  3. INSTALL NO. 1 FLOOR UNDER COVER (for RH Side)


    1. Install in this Direction

      Engage the clip to temporarily install the No. 1 floor under cover as shown in the illustration.

    2. Install the No. 1 floor under cover with the 2 clips.

    3. Install the clip.

    4. Connect in this Direction

      Connect the rear bumper assembly with the 3 clips as shown in the illustration.
