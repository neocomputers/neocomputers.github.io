NAVIGATION SYSTEM(for Navigation Receiver Type), Diagnostic DTC:B1579

DTC Code DTC Name
B1579 Voice Recognition Microphone Disconnected

DESCRIPTION

The navigation receiver assembly and telephone microphone assembly are connected to each other using the microphone connection detection signal lines.

This DTC is stored when a microphone connection detection signal line is disconnected.

DTC No. Detection Item DTC Detection Condition Trouble Area
B1579 Voice Recognition Microphone Disconnected Microphone signal is lost

  • Telephone microphone assembly

  • Navigation receiver assembly

  • Harness or connector

*a Telephone Microphone Assembly
*b Navigation Receiver Assembly
