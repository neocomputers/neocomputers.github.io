RADIO RECEIVER INSTALLATION

PROCEDURE


  1. INSTALL RADIO AND DISPLAY RECEIVER ASSEMBLY (for 7 Inch Display)

  2. INSTALL NO. 2 RADIO BRACKET (for 7 Inch Display)


    1. Install the No. 2 radio bracket with the 3 screws.

  3. INSTALL NO. 1 RADIO BRACKET (for 7 Inch Display)


    1. Install the No. 1 radio bracket with the 3 screws.

  4. INSTALL RADIO RECEIVER ASSEMBLY WITH BRACKET (for 7 Inch Display)


    1. Connect each connector.

    2. Install in this Direction

      Engage the 2 guides to temporarily install the radio receiver assembly with bracket as shown in the illustration.

    3. Install the radio receiver assembly with bracket with the 4 bolts.

  5. INSTALL RADIO AND DISPLAY RECEIVER ASSEMBLY (for 8 Inch Display)


    1. Connect each connector.

    2. Install in this Direction

      Engage the 2 guides to temporarily install the radio and display receiver assembly as shown in the illustration.

    3. Install the radio and display receiver assembly with the 4 bolts.
