BLIND SPOT MONITOR SENSOR INSTALLATION

CAUTION / NOTICE / HINT

Note


  • Avoid any impact to the blind spot monitor sensor.

  • Do not drop the blind spot monitor sensor. If it is dropped, replace it with a new one.

Tech Tips


  • The blind spot monitor beam axis inspection is performed to confirm whether the sensor is transmitting radio waves.

  • The blind spot monitor beam axis confirmation is performed to confirm whether the sensor's beam axis is correct, and perform adjustment of the beam axis by using reflector.

  • The blind spot monitor sensor installation condition inspection is performed to confirm whether the sensor is placed vertically to the ground (+/-5°) by using a jig, and that the sensor is 16 to 24° from the line parallel to the vehicle center line.

PROCEDURE


  1. INSTALL BLIND SPOT MONITOR BRACKET LH


    1. Install the blind spot monitor bracket LH with the 3 nuts.

      Torque:
      10 N*m  { 102 kgf*cm, 7 ft.*lbf }

    2. Engage the clamp.

  2. INSTALL BLIND SPOT MONITOR BRACKET RH


    1. Install the blind spot monitor bracket RH with the 3 nuts.

      Torque:
      10 N*m  { 102 kgf*cm, 7 ft.*lbf }

    2. Engage the clamp.

  3. INSTALL BLIND SPOT MONITOR SENSOR LH


    1. Connect the connector.

    2. Install the blind spot monitor sensor LH with the 3 nuts.

      Torque:
      10 N*m  { 102 kgf*cm, 7 ft.*lbf }

  4. INSTALL BLIND SPOT MONITOR SENSOR RH


    1. Connect the connector.

    2. Install the blind spot monitor sensor RH with the 3 nuts.

      Torque:
      10 N*m  { 102 kgf*cm, 7 ft.*lbf }
