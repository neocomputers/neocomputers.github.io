AIR CONDITIONING SYSTEM, Diagnostic DTC:B14BD

DTC Code DTC Name
B14BD Refrigerant Overabundance Filling Malfunction

DESCRIPTION

This DTC is stored when the amount of refrigerant is a certain value or more when in refrigerant filling mode. The heat pump ECU assembly judges whether the amount of refrigerant is appropriate or not using the output value of the discharge temperature sensor. If the amount of refrigerant is excessive, the heat pump ECU assembly stops the operation of the compressor with motor assembly. Also, when the power switch is turned off and then turned on (IG), the compressor with motor assembly remains stopped.
