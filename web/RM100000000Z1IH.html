CRUISE CONTROL SYSTEM, Diagnostic DTC:U012287

DTC Code DTC Name
U012287 Lost Communication with Vehicle Dynamics Control Module Missing Message

DESCRIPTION

The hybrid vehicle control ECU communicates several signals with each sensor and ECU via CAN communication.

If there are any malfunctions in the communication circuit, one or more CAN communication system DTCs are stored.

DTC No. Detection Item DTC Detection Condition Trouble Area
U012287 Lost Communication with Vehicle Dynamics Control Module Missing Message While the vehicle speed is 40 km/h or 25 mph or more and the cruise control main switch (ON-OFF button) is on, signals cannot be received from the skid control ECU (brake booster with master cylinder assembly) for 2.58 seconds or more.

  • CAN communication system

  • Hybrid vehicle control ECU

  • Skid control ECU (Brake booster with master cylinder assembly)

CAUTION / NOTICE / HINT

Refer to troubleshooting in CAN Communication System.

PROCEDURE


  1. CHECK FOR DTCS (DTC U012287)


    1. Connect the GTS to the DLC3.

    2. Turn the power switch on (IG).

    3. Clear the DTCs.

      Click here


      Powertrain > Cruise Control > Clear DTCs

    4. Perform the following to make sure that the DTC detection conditions are met.

      Tech Tips

      If the detection conditions are not met, the malfunction cannot be detected.


      1. Drive the vehicle at a speed for which cruise control system operation is possible.

      2. Turn the cruise control system on using the cruise control main switch (ON-OFF).

      3. Push the cruise control main switch to -SET to begin control of vehicle speed using the cruise control system.

    5. Check for DTCs.

      Click here


      Powertrain > Cruise Control > Trouble Codes
