WATER PUMP INSTALLATION

PROCEDURE


  1. INSTALL ENGINE WATER PUMP ASSEMBLY


    1. Install a new gasket to the engine water pump assembly.

      Tech Tips

      Be sure to clean the contact surfaces.

    2. Install the engine water pump assembly to the timing chain cover sub-assembly with the 5 bolts.

      Torque:
      Bolt (A)
      25.5 N*m  { 260 kgf*cm, 19 ft.*lbf }
      Bolt (B)
      21 N*m  { 214 kgf*cm, 15 ft.*lbf }
      Bolt Length
      Item Length
      Bolt (A) 55 mm (2.17 in.)
      Bolt (B) 30 mm (1.18 in.)

    3. Connect the engine water pump assembly connector.

  2. INSTALL ENGINE ASSEMBLY WITH TRANSAXLE
