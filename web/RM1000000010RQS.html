AUTOMATIC HEADLIGHT BEAM LEVEL CONTROL SYSTEM, Diagnostic DTC:B2415

DTC Code DTC Name
B2415 Vehicle Speed Sensor

DESCRIPTION

The No. 1 headlight ECU sub-assembly LH receives signals indicating the vehicle speed signal from the brake booster with master cylinder assembly (skid control ECU) using CAN communication. The No. 1 headlight ECU sub-assembly LH stores DTC B2415.

DTC No. Detection Item DTC Detection Condition Trouble Area Note
B2415 Vehicle Speed Sensor Malfunction in vehicle speed signal

  • No. 1 headlight ECU sub-assembly LH

  • Electronically controlled brake system

 -

WIRING DIAGRAM

*1 Brake Booster with Master Cylinder Assembly (Skid Control ECU)
*2 No. 1 Headlight ECU Sub-assembly LH
*3 CAN Communication Line
