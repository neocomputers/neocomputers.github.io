  32. REMOVE REAR 3 POINT TYPE SEAT OUTER BELT ASSEMBLY LH (for LH Side)


    1. Remove the bolt to disconnect the floor anchor of the rear 3 point type seat outer belt assembly LH.

    2. *a Locking Button
      *b Protective Tape
      *c Release

      Using a screwdriver, pull out the locking button as shown in the illustration to release the lock and disconnect the pretensioner connector.

      Tech Tips

      Tape the screwdriver tip before use.

    3. Remove the 3 bolts.

    4. Disengage the 3 guides to remove the rear 3 point type seat outer belt assembly LH.

  33. REMOVE REAR 3 POINT TYPE SEAT OUTER BELT ASSEMBLY RH (for RH Side)


    1. Remove the bolt to disconnect the floor anchor of the rear 3 point type seat outer belt assembly RH.

    2. Remove the 3 bolts.

    3. Disengage the 3 guides.

    4. *a Locking Button
      *b Protective Tape
      *c Release

      Disengage the clamp.

    5. Using a screwdriver, pull out the locking button as shown in the illustration to release the lock and disconnect the pretensioner connector.

      Tech Tips

      Tape the screwdriver tip before use.

    6. Remove the rear 3 point type seat outer belt assembly RH.
