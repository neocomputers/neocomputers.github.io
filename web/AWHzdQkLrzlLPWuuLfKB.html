ENTRY AND START SYSTEM(for Entry Function) DIAGNOSIS SYSTEM


  1. DESCRIPTION


    1. Entry and start system (for Entry Function) data and Diagnostic Trouble Codes (DTCs) can be read through the vehicle Data Link Connector 3 (DLC3). In some cases, a malfunction may be occurring in the entry and start system. When the system seems to be malfunctioning, use the GTS to check for malfunctions and perform repairs.
