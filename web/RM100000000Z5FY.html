RAIN SENSOR INSTALLATION

PROCEDURE


  1. INSTALL RAIN SENSOR TAPE

    Tech Tips

    The rain sensor tape is reusable. Only replace the tape if it is damaged or contaminated with foreign matter.


    1. Remove the rain sensor tape.

    2. Clean the rain sensor sensing portion with a piece of cloth.

    3. Peel off the smaller release sheet, and then attach the rain sensor tape to the rain sensor sensing portion as shown in the illustration.

      Tech Tips

      Use your fingers to push out any air bubbles from under the tape.

      Standard Clearance
      Area Measurement
      A 14.4 mm (0.567 in.)
      B 7.25 mm (0.285 in.)

  2. INSTALL RAIN SENSOR


    1. Clean the windshield glass with a piece of cloth.

      Note


      • Make sure that there is no rain sensor tape residue remaining on the windshield glass. If there is, remove the residue.

      • If there is any rain sensor tape residue remaining on the windshield glass, replace the tape.

    2. When installing a new rain sensor or when the rain sensor tape has been replaced:


      1. Peel off the release sheet.

        Tech Tips

        Do not touch the silicone surface.

    3. Connect the connector.

    4. *a Stopper
      Lock
      Install in this Direction

      Gradually attach the rain sensor to the windshield glass surface as shown in the illustration to prevent air bubbles from forming between them.

      Tech Tips

      Do not touch the silicone or glass surfaces.

    5. Push in the stopper to install the rain sensor as shown in the illustration.

  3. INSTALL RAIN SENSOR COVER


    1. Engage the guide and 2 claws to install the rain sensor cover.
