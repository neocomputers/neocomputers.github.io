REAR SEAT OUTER BELT ASSEMBLY INSTALLATION

CAUTION / NOTICE / HINT

Tech Tips


  • Use the same procedure for the RH side and LH side.

  • The following procedure is for the LH side.

PROCEDURE


  1. INSPECT REAR 3 POINT TYPE SEAT OUTER BELT ASSEMBLY

    Click here

  2. INSTALL REAR 3 POINT TYPE SEAT OUTER BELT ASSEMBLY LH (for LH Side)


    1. Bolt (A)
      Bolt (B)

      Engage the 3 guides and temporarily install the rear 3 point type seat outer belt assembly LH with the 3 bolts.

    2. Uniformly tighten the 3 bolts in the order shown in the illustration to install rear 3 point type seat outer belt assembly LH.

      Torque:
      Bolt (A)
      12.5 N*m  { 127 kgf*cm, 9 ft.*lbf }
      Bolt (B)
      42 N*m  { 428 kgf*cm, 31 ft.*lbf }
    3. *a Locking Button
      *b Lock

      Connect the pretensioner connector and lock the locking button as shown in the illustration.

      Note

      Securely lock the locking button.

    4. Check that the ELR locks.

      Note

      This check should be performed with the rear 3 point type seat outer belt assembly LH installed to the vehicle.


      1. With the rear 3 point type seat outer belt assembly LH installed to the vehicle, check that the belt locks when it is pulled out quickly.

    5. *a Protruding Part

      Install the floor anchor of the rear 3 point type seat outer belt assembly LH with the bolt.

      Torque:
      42 N*m  { 428 kgf*cm, 31 ft.*lbf }

      Note

      Do not allow the anchor part of the rear 3 point type seat outer belt assembly LH to overlap the protruding parts of the floor panel.

  3. INSTALL REAR 3 POINT TYPE SEAT OUTER BELT ASSEMBLY RH (for RH Side)


    1. *a Locking Button
      *b Lock

      Connect the pretensioner connector and lock the locking button as shown in the illustration.

      Note

      Securely lock the locking button.

    2. Engage the clamp.

    3. Bolt (A)
      Bolt (B)

      Engage the 3 guides and temporarily install the rear 3 point type seat outer belt assembly RH with the 3 bolts.

    4. Uniformly tighten the 3 bolts in the order shown in the illustration to install rear 3 point type seat outer belt assembly RH.

      Torque:
      Bolt (A)
      12.5 N*m  { 127 kgf*cm, 9 ft.*lbf }
      Bolt (B)
      42 N*m  { 428 kgf*cm, 31 ft.*lbf }

    5. Check that the ELR locks.

      Note

      This check should be performed with the rear 3 point type seat outer belt assembly RH installed to the vehicle.


      1. With the rear 3 point type seat outer belt assembly RH installed to the vehicle, check that the belt locks when it is pulled out quickly.

    6. *a Protruding Part

      Install the floor anchor of the rear 3 point type seat outer belt assembly RH with the bolt.

      Torque:
      42 N*m  { 428 kgf*cm, 31 ft.*lbf }

      Note

      Do not allow the anchor part of the rear 3 point type seat outer belt assembly RH to overlap the protruding parts of the floor panel.
