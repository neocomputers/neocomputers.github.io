  2. HANDLING PRECAUTION FOR SPEED LIMITER SYSTEM


    1. Turn the speed limiter system off using the speed limiter switch when not using the speed limiter system.

    2. Be careful as the vehicle speed increases when driving downhill with the speed limiter system controlling vehicle speed.

    3. The RESUME/ACCEL operation changes according to the speed limiter system status. When the speed limiter system is controlling vehicle speed, the ACCEL function operates. When the speed limiter system is not controlling vehicle speed, the RESUME function operates.

    4. When the speed limiter system is controlling vehicle speed, if the speed limiter indicator turns off and a warning message is displayed, turn the speed limiter system off using the speed limiter switch to reset the speed limiter system. After resetting the speed limiter system, if the speed limiter system cannot be turned on or the speed limiter system is canceled immediately after being turned on, the speed limiter system may be malfunctioning.

    5. Do not use the speed limiter system where the road conditions are as follows:


      • Steep downhill road

      • Roads with sharp turns

      • Icy or snowy roads

      • Slippery roads

    6. Do not use the speed limiter system when the vehicle is towing a trailer, etc.
