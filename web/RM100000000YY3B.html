SPEED LIMITER SYSTEM Speed Limiter System does not Operate

DESCRIPTION

When the speed limiter is turned on using the speed limiter switch, the hybrid vehicle control ECU illuminates the speed limiter indicator and activates the speed limiter system. Each function of the speed limiter system can be activated by operating the cruise control main switch. When the cruise control system is operating, the speed limiter system will not operate.
